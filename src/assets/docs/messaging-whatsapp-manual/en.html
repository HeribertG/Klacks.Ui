Set up WhatsApp Business

Prerequisites

To send and receive WhatsApp messages through Klacks, you need access to the WhatsApp Business API from Meta. It is managed through the Meta Developer Portal.

Note: The WhatsApp Business API requires a verified business identity. The first 1,000 conversations per month are free of charge.

Step 1 — Set up WhatsApp Business API

  1. Create an account on developers.facebook.com (Meta Developer Portal).
  2. Create a new app and select the type Business.
  3. Add the WhatsApp product to your app.
  4. Register a phone number for WhatsApp messaging.
  5. Verify your business identity in the Meta Business Suite.
  6. Note down the following values from the Developer Portal:
    • Access Token — under WhatsApp → API Setup
    • Phone Number ID — the ID of the registered number
    • Business Account ID — from the Meta Business Suite

Step 2 — Configure WhatsApp in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Select WhatsApp as the provider type.
  4. Fill in the fields as follows:

  2. Test the connection using the Test button in the provider list.

Step 3 — Send messages via the chatbot (Klacksy)

Once the WhatsApp provider is configured and enabled, the chatbot Klacksy can send messages. You do not need to know phone numbers — simply use the name of the employee or client: 

"Send a WhatsApp to Max Muster: Your appointment is tomorrow at 2:00 PM."
"Message Anna Beispiel via WhatsApp: The shift has been swapped."
"Notify Peter Müller via WhatsApp that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's stored mobile number and uses the configured WhatsApp provider. The process is fully transparent to you — you work with names, Klacksy takes care of the rest.

Prerequisite: The recipient must have a mobile number stored in Klacks (under Address → Contact Details). The number must be registered with WhatsApp.

Step 4 — Receive incoming messages (Webhook)

To display incoming WhatsApp messages in Klacks, a webhook must be configured in the Meta Developer Portal.

  1. In the Meta Developer Portal, go to your app → WhatsApp → Configuration.
  2. Enter the following as the webhook URL: 
    https://{your-domain}/api/messaging/webhook/whatsapp
  3. Subscribe to the messages field.
  4. Incoming WhatsApp messages will now appear in real time in the Messaging Inbox.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails Access token invalid or expired Create a new permanent token in the Meta Developer Portal
Message not delivered Phone Number ID or Business Account ID incorrect Check the IDs in the Meta Developer Portal under WhatsApp → API Setup
Recipient does not receive message Recipient does not have WhatsApp on this number Ensure the mobile number is registered with WhatsApp
Error 403 — Permission denied Business identity not verified Verify your business in the Meta Business Suite
Incoming messages missing Webhook not configured or URL not reachable Check the webhook URL and SSL certificate in the Meta Developer Portal
Message limit reached Monthly quota (1,000 conversations) exhausted Wait for the next month or request a higher limit from Meta
