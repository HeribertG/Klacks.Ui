WhatsApp einrichten

Voraussetzungen

Um Nachrichten über WhatsApp mit Klacks zu senden und zu empfangen, benötigen Sie ein Meta-Entwicklerkonto und eine Meta-App mit aktiviertem WhatsApp-Produkt. Klacks verwendet die WhatsApp Cloud API der Meta-Business-Plattform für den Versand und Meta-Webhooks für den Empfang.

Hinweis: Für die Einrichtung und zum Testen fallen keine Kosten an. Beim Anlegen der App stellt Meta automatisch eine kostenlose Test-Telefonnummer bereit.

Wichtig — die Absendernummer ist nicht Ihre private Nummer. Eine Telefonnummer, die bereits in der normalen WhatsApp-App verwendet wird, kann nicht für die Cloud API registriert werden, und eine registrierte Nummer lässt sich nicht mehr mit WhatsApp Messenger nutzen. Verwenden Sie deshalb die von Meta bereitgestellte Test-Nummer oder eine eigene, ausschliesslich geschäftlich genutzte Nummer. Ihr privates WhatsApp auf dem Mobiltelefon dient als Empfänger zum Testen — nicht als Absender.

Schritt 1 — Meta-App erstellen

  1. Öffnen Sie developers.facebook.com/apps und klicken Sie auf Create app.
  2. Wählen Sie als Anwendungsfall Other und als App-Typ Business.
  3. Klicken Sie im Dashboard beim Produkt WhatsApp auf Set up. Dabei wird automatisch eine Test-Telefonnummer erzeugt und registriert.
  4. Wechseln Sie in der linken Navigation zu WhatsApp → API Setup.
  5. Notieren Sie sich die Phone number ID und erzeugen Sie über Generate access token ein Zugriffstoken.
  6. Notieren Sie sich unter App settings → Basic das App Secret — es wird für die Signaturprüfung eingehender Nachrichten benötigt.

Achtung — zwei ähnliche IDs: Im API-Setup-Panel stehen die Phone number ID und die WhatsApp Business Account ID direkt untereinander. Klacks benötigt die Phone number ID. Mit der falschen ID meldet der Verbindungstest trotzdem Erfolg, aber jeder Versand schlägt fehl.

Achtung — Token-Laufzeit: Das über Generate access token erzeugte Token ist ein temporäres Test-Token und läuft nach kurzer Zeit ab. Für den Dauerbetrieb erzeugen Sie im Meta-Business-Manager ein permanentes Token über einen Systembenutzer.

Schritt 2 — Empfängernummer freischalten

Die Test-Nummer darf nur an vorher freigeschaltete Empfänger senden. Fügen Sie im API Setup-Panel unter To → Manage phone number list Ihre WhatsApp-Nummer hinzu. Meta sendet einen Bestätigungscode an diese Nummer, den Sie eingeben müssen.

Ohne diesen Schritt lehnt Meta jeden Versand an diese Nummer ab. Sobald Sie später eine eigene, verifizierte Geschäftsnummer verwenden, entfällt die Freischaltung.

Schritt 4 — Das 24-Stunden-Fenster

WhatsApp unterscheidet sich hier grundlegend von Telegram oder Slack. Freie Textnachrichten darf ein Unternehmen nur senden, solange ein Kundendienst-Fenster offen ist. Dieses Fenster öffnet der Empfänger, indem er Ihre WhatsApp-Nummer anschreibt. Es bleibt 24 Stunden offen und verlängert sich mit jeder weiteren Nachricht des Empfängers.

Ausserhalb dieses Fensters lässt Meta ausschliesslich vorab genehmigte Nachrichtenvorlagen zu. Klacks versendet derzeit ausschliesslich freie Textnachrichten und kann damit keine Konversation von sich aus eröffnen.

Was das für Sie bedeutet: Bitten Sie Ihre Mitarbeitenden einmalig, eine Nachricht an die Klacks-WhatsApp-Nummer zu senden. Danach ist der Versand für 24 Stunden möglich, und jede Antwort verlängert das Fenster. Ist es geschlossen, meldet der Versand einen Fehler — das ist kein Konfigurationsproblem, sondern eine Vorgabe von WhatsApp.

Wenn Sie Mitarbeitende unabhängig von diesem Fenster erreichen müssen, sind Telegram oder Signal die besseren Anbieter — dort gibt es diese Einschränkung nicht.

Schritt 5 — Nachrichten über den Chatbot (Klacksy) senden

Sobald der WhatsApp-Anbieter konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten über WhatsApp versenden. Verwenden Sie den Namen des Mitarbeiters: 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht: Die Schicht wurde getauscht."

Als Empfänger dient die Telefonnummer im internationalen Format ohne führende Null und ohne Pluszeichen (z.B. 41791234567 für 079 123 45 67). Der Versand ist für Sie vollständig transparent — Sie arbeiten mit Namen, Klacksy kümmert sich um den Rest.

Voraussetzung: Die WhatsApp-Nummer muss mit dem entsprechenden Klacks-Kontakt verknüpft sein (unter Adresse → Kontaktdaten), und das 24-Stunden-Fenster aus Schritt 4 muss offen sein.

Schritt 6 — Eingehende Nachrichten empfangen (Webhooks)

Um eingehende WhatsApp-Nachrichten in Klacks anzuzeigen, muss der Webhook der Meta-App konfiguriert werden. Speichern und aktivieren Sie den Anbieter in Klacks, bevor Sie die Callback-URL eintragen — Meta prüft die URL sofort mit einer Verifizierungsanfrage, die Klacks anhand des Verify-Tokens automatisch beantwortet.

  1. Öffnen Sie Ihre Meta-App und navigieren Sie zu WhatsApp → Configuration.
  2. Klicken Sie bei Webhook auf Edit und tragen Sie ein:
    • Callback URL: die in Klacks angezeigte Webhook-URL 
      https://{ihre-domain}/api/messaging/webhook/whatsapp
    • Verify token: exakt derselbe Wert, den Sie in Schritt 3 im Feld Verify-Token eingetragen haben
  3. Klicken Sie auf Verify and save.
  4. Abonnieren Sie unter Webhook fields das Feld messages.
  5. Eingehende Nachrichten erscheinen nun in Echtzeit in der Messaging-Inbox. Klacks prüft dabei die Signatur jeder Anfrage (X-Hub-Signature-256) mit dem hinterlegten App-Secret.

Die Callback-URL muss von aussen über HTTPS erreichbar sein. Bei einer Installation im Firmennetz ohne öffentliche Adresse funktioniert der Versand, aber es können keine Nachrichten empfangen werden.
