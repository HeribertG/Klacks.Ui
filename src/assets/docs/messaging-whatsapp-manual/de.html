WhatsApp Business einrichten

Voraussetzungen

Um WhatsApp-Nachrichten über Klacks zu senden und zu empfangen, benötigen Sie einen Zugang zur WhatsApp Business API von Meta. Diese wird über das Meta Developer Portal verwaltet.

Hinweis: Die WhatsApp Business API erfordert eine verifizierte Business-Identität. Die ersten 1.000 Konversationen pro Monat sind kostenfrei.

Schritt 1 — WhatsApp Business API einrichten

  1. Erstellen Sie ein Konto auf developers.facebook.com (Meta Developer Portal).
  2. Erstellen Sie eine neue App und wählen Sie den Typ Business.
  3. Fügen Sie das Produkt WhatsApp zu Ihrer App hinzu.
  4. Registrieren Sie eine Telefonnummer für den WhatsApp-Versand.
  5. Verifizieren Sie Ihre Business-Identität in der Meta Business Suite.
  6. Notieren Sie sich folgende Werte aus dem Developer Portal:
    • Access Token — unter WhatsApp → API Setup
    • Telefonnummer-ID — die ID der registrierten Nummer
    • Business Account ID — aus der Meta Business Suite

Schritt 2 — WhatsApp in Klacks konfigurieren

  1. Navigieren Sie zu Einstellungen → Messaging-Anbieter.
  2. Klicken Sie auf Hinzufügen.
  3. Wählen Sie als Anbietertyp WhatsApp.
  4. Füllen Sie die Felder wie folgt aus:

Schritt 3 — Nachrichten über den Chatbot (Klacksy) senden

Sobald der WhatsApp-Anbieter konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten versenden. Sie müssen keine Telefonnummern kennen — verwenden Sie einfach den Namen des Mitarbeiters oder Klienten: 

"Sende eine WhatsApp an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht per WhatsApp: Die Schicht wurde getauscht."
"Benachrichtige Peter Müller über WhatsApp, dass sein Dienst am Montag ausfällt."

Klacksy sucht automatisch die hinterlegte Mobilnummer des Empfängers und verwendet den konfigurierten WhatsApp-Anbieter. Der Versand ist für Sie vollständig transparent — Sie arbeiten mit Namen, Klacksy kümmert sich um den Rest.

Voraussetzung: Beim Empfänger muss eine Mobilnummer in Klacks hinterlegt sein (unter Adresse → Kontaktdaten). Die Nummer muss bei WhatsApp registriert sein.

Schritt 4 — Eingehende Nachrichten empfangen (Webhook)

Um eingehende WhatsApp-Nachrichten in Klacks anzuzeigen, muss im Meta Developer Portal ein Webhook konfiguriert werden.

  1. Gehen Sie im Meta Developer Portal zu Ihrer App → WhatsApp → Configuration.
  2. Tragen Sie als Webhook-URL ein: 
    https://{ihre-domain}/api/messaging/webhook/whatsapp
  3. Abonnieren Sie das Feld messages.
  4. Eingehende WhatsApp-Nachrichten erscheinen nun in Echtzeit in der Messaging-Inbox.

Fehlerbehebung

ProblemMögliche UrsacheLösung
Verbindungstest schlägt fehl Access Token ungültig oder abgelaufen Erstellen Sie einen neuen permanenten Token im Meta Developer Portal
Nachricht wird nicht zugestellt Telefonnummer-ID oder Business Account ID falsch Prüfen Sie die IDs im Meta Developer Portal unter WhatsApp → API Setup
Empfänger erhält keine Nachricht Empfänger hat kein WhatsApp auf dieser Nummer Stellen Sie sicher, dass die Mobilnummer bei WhatsApp registriert ist
Fehler 403 — Berechtigung verweigert Business-Identität nicht verifiziert Verifizieren Sie Ihr Unternehmen in der Meta Business Suite
Eingehende Nachrichten fehlen Webhook nicht konfiguriert oder URL nicht erreichbar Prüfen Sie die Webhook-URL und SSL-Zertifikat im Meta Developer Portal
Nachrichtenlimit erreicht Monatliches Kontingent (1.000 Konversationen) erschöpft Warten Sie auf den nächsten Monat oder beantragen Sie ein höheres Limit bei Meta
