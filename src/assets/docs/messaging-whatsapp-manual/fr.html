Configurer WhatsApp Business

Conditions préalables

Pour envoyer et recevoir des messages WhatsApp via Klacks, vous avez besoin d'un accès à l'API WhatsApp Business de Meta. Celle-ci est gérée via le portail Meta Developer.

Remarque : L'API WhatsApp Business nécessite une identité commerciale vérifiée. Les 1 000 premières conversations par mois sont gratuites.

Étape 1 — Configurer l'API WhatsApp Business

  1. Créez un compte sur developers.facebook.com (portail Meta Developer).
  2. Créez une nouvelle application et sélectionnez le type Business.
  3. Ajoutez le produit WhatsApp à votre application.
  4. Enregistrez un numéro de téléphone pour l'envoi WhatsApp.
  5. Vérifiez votre identité commerciale dans la Meta Business Suite.
  6. Notez les valeurs suivantes du portail Developer :
    • Access Token — sous WhatsApp → API Setup
    • Phone Number ID — l'identifiant du numéro enregistré
    • Business Account ID — depuis la Meta Business Suite

Étape 2 — Configurer WhatsApp dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Sélectionnez WhatsApp comme type de fournisseur.
  4. Remplissez les champs comme suit :

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur WhatsApp configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les numéros de téléphone — utilisez simplement le nom de l'employé ou du client : 

"Envoie un WhatsApp à Max Muster : Votre rendez-vous est demain à 14h00."
"Envoie un message à Anna Beispiel via WhatsApp : Le service a été échangé."
"Préviens Peter Müller par WhatsApp que son service de lundi est annulé."

Klacksy recherche automatiquement le numéro de mobile enregistré du destinataire et utilise le fournisseur WhatsApp configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : Le destinataire doit avoir un numéro de mobile enregistré dans Klacks (sous Adresse → Coordonnées). Le numéro doit être enregistré sur WhatsApp.

Étape 4 — Recevoir des messages entrants (Webhook)

Pour afficher les messages WhatsApp entrants dans Klacks, un webhook doit être configuré dans le portail Meta Developer.

  1. Dans le portail Meta Developer, accédez à votre application → WhatsApp → Configuration.
  2. Saisissez l'URL du webhook : 
    https://{votre-domaine}/api/messaging/webhook/whatsapp
  3. Abonnez-vous au champ messages.
  4. Les messages WhatsApp entrants apparaissent désormais en temps réel dans la Boîte de réception.

Dépannage

ProblèmeCause possibleSolution
Le test de connexion échoue Access Token invalide ou expiré Créez un nouveau jeton permanent dans le portail Meta Developer
Le message n'est pas délivré Phone Number ID ou Business Account ID incorrect Vérifiez les identifiants dans le portail Meta Developer sous WhatsApp → API Setup
Le destinataire ne reçoit pas le message Le destinataire n'a pas WhatsApp sur ce numéro Assurez-vous que le numéro de mobile est enregistré sur WhatsApp
Erreur 403 — Permission refusée Identité commerciale non vérifiée Vérifiez votre entreprise dans la Meta Business Suite
Messages entrants manquants Webhook non configuré ou URL inaccessible Vérifiez l'URL du webhook et le certificat SSL dans le portail Meta Developer
Limite de messages atteinte Quota mensuel (1 000 conversations) épuisé Attendez le mois suivant ou demandez une limite plus élevée auprès de Meta
