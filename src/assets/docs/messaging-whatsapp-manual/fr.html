Configurer WhatsApp

Conditions préalables

Pour envoyer et recevoir des messages via WhatsApp avec Klacks, vous avez besoin d'un compte développeur Meta et d'une application Meta avec le produit WhatsApp activé. Klacks utilise la WhatsApp Cloud API de la plateforme Meta Business pour l'envoi et les webhooks Meta pour la réception.

Remarque : la configuration et les tests sont gratuits. Lors de la création de l'application, Meta met automatiquement à disposition un numéro de téléphone de test gratuit.

Important — le numéro d'expéditeur n'est pas votre numéro privé. Un numéro de téléphone déjà utilisé dans l'application WhatsApp habituelle ne peut pas être enregistré pour la Cloud API, et un numéro enregistré ne peut plus être utilisé avec WhatsApp Messenger. Utilisez donc le numéro de test fourni par Meta ou votre propre numéro utilisé exclusivement à des fins professionnelles. Votre WhatsApp privé sur votre téléphone mobile sert de destinataire pour les tests — et non d'expéditeur.

Étape 1 — Créer une application Meta

  1. Ouvrez developers.facebook.com/apps et cliquez sur Create app.
  2. Choisissez Other comme cas d'utilisation et Business comme type d'application.
  3. Dans le tableau de bord, accédez au produit WhatsApp et cliquez sur Set up. Un numéro de téléphone de test est alors automatiquement créé et enregistré.
  4. Dans la navigation de gauche, accédez à WhatsApp → API Setup.
  5. Notez le Phone number ID et générez un token d'accès via Generate access token.
  6. Sous App settings → Basic, notez le App Secret — il est nécessaire à la vérification de signature des messages entrants.

Attention — deux ID similaires : Dans le panneau API Setup, le Phone number ID et le WhatsApp Business Account ID figurent directement l'un en dessous de l'autre. Klacks a besoin du Phone number ID. Avec le mauvais ID, le test de connexion signale malgré tout une réussite, mais chaque envoi échoue.

Attention — durée de validité du token : Le token généré via Generate access token est un token de test temporaire et expire au bout de peu de temps. Pour une exploitation permanente, générez dans le Meta Business Manager un token permanent via un utilisateur système.

Étape 2 — Autoriser le numéro du destinataire

Le numéro de test ne peut envoyer qu'à des destinataires préalablement autorisés. Dans le panneau API Setup, ajoutez votre numéro WhatsApp sous To → Manage phone number list. Meta envoie un code de confirmation à ce numéro, que vous devez saisir.

Sans cette étape, Meta refuse tout envoi vers ce numéro. Dès que vous utiliserez plus tard votre propre numéro professionnel vérifié, cette autorisation ne sera plus nécessaire.

Étape 4 — La fenêtre de 24 heures

Sur ce point, WhatsApp se distingue fondamentalement de Telegram ou de Slack. Une entreprise ne peut envoyer des messages texte libres que tant qu'une fenêtre de service client est ouverte. Cette fenêtre est ouverte par le destinataire, lorsqu'il écrit à votre numéro WhatsApp. Elle reste ouverte pendant 24 heures et se prolonge à chaque nouveau message du destinataire.

En dehors de cette fenêtre, Meta n'autorise que des modèles de messages approuvés au préalable. Klacks n'envoie actuellement que des messages texte libres et ne peut donc pas ouvrir de conversation de sa propre initiative.

Ce que cela signifie pour vous : Demandez une fois à vos collaborateurs d'envoyer un message au numéro WhatsApp de Klacks. L'envoi est ensuite possible pendant 24 heures, et chaque réponse prolonge la fenêtre. Si elle est fermée, l'envoi signale une erreur — il ne s'agit pas d'un problème de configuration, mais d'une règle imposée par WhatsApp.

Si vous devez joindre vos collaborateurs indépendamment de cette fenêtre, Telegram ou Signal sont les meilleurs fournisseurs — cette restriction n'y existe pas.

Étape 5 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur WhatsApp configuré et activé, le chatbot Klacksy peut envoyer des messages via WhatsApp. Utilisez le nom de l'employé : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »

Le destinataire est identifié par le numéro de téléphone au format international sans zéro initial et sans signe plus (p. ex. 41791234567 pour 079 123 45 67). Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : Le numéro WhatsApp doit être associé au contact Klacks correspondant (sous Adresse → Coordonnées), et la fenêtre de 24 heures de l'étape 4 doit être ouverte.

Étape 6 — Recevoir des messages entrants (webhooks)

Pour afficher les messages WhatsApp entrants dans Klacks, le webhook de l'application Meta doit être configuré. Enregistrez et activez le fournisseur dans Klacks avant de saisir la Callback URL — Meta vérifie l'URL immédiatement avec une requête de vérification, à laquelle Klacks répond automatiquement à l'aide du Verify Token.

  1. Ouvrez votre application Meta et accédez à WhatsApp → Configuration.
  2. Au niveau de Webhook, cliquez sur Edit et saisissez :
    • Callback URL : l'URL de webhook affichée dans Klacks 
      https://{votre-domaine}/api/messaging/webhook/whatsapp
    • Verify token : exactement la même valeur que celle que vous avez saisie à l'étape 3 dans le champ Verify Token
  3. Cliquez sur Verify and save.
  4. Abonnez-vous, sous Webhook fields, au champ messages.
  5. Les messages entrants apparaîtront désormais en temps réel dans la boîte de réception de messagerie. Klacks vérifie la signature de chaque requête (X-Hub-Signature-256) à l'aide de l'App Secret enregistré.

La Callback URL doit être accessible de l'extérieur via HTTPS. Dans le cas d'une installation sur un réseau d'entreprise sans adresse publique, l'envoi fonctionne, mais aucun message ne peut être reçu.
