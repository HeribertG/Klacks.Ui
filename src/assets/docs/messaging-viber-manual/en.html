Setting up a Viber Bot

Prerequisites

To send and receive messages via Viber, you need a Viber bot, which you create through the Viber partner portal. Viber is particularly popular in Eastern Europe and the Middle East.

Note: Viber has commercialized bot usage — depending on country and message volume, paid models may apply. Check the current conditions on partners.viber.com.

Step 1 — Create a Viber bot

  1. Sign up on partners.viber.com.
  2. Create a new bot in the partner portal.
  3. Note down the auth token from the bot dashboard.
  4. Choose a sender name (e.g. Klacks Bot).

Step 2 — Configure Viber in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:
FieldDescriptionExample
NameUnique internal nameviber-bot
Display NameShown in the user interfaceViber
Provider TypeSelect ViberViber
Auth TokenThe auth token from the bot dashboard4a5e6f7g8h9i...
Sender NameName shown to the recipientKlacks Bot
Webhook URLAutomatically filled with the URL of your Klacks instance (not editable)https://example.com/api/messaging/webhook/viber
EnabledTurns the provider on/offYes
  1. Click Save. Klacks registers the webhook with Viber automatically (set_webhook).
  2. Test the connection using the Test button in the provider list.

Important: The displayed webhook URL must be publicly reachable via HTTPS — otherwise the webhook registration fails when saving.

Step 3 — Send messages via the chatbot (Klacksy)

Once the Viber provider is configured and enabled, the chatbot Klacksy can send messages. You do not need to know any Viber user IDs — simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2:00 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Müller that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's stored Viber user ID and uses the configured Viber provider. The process is fully transparent for you — you work with names, Klacksy takes care of the rest.

Important: Viber bots can only message users who have subscribed to the bot (started a 1:1 chat with it). The recipient must therefore send a message to the bot first. Their Viber user ID becomes known through the incoming message (visible in the messaging inbox) and is stored for the recipient under Address → Contact Details.

Step 4 — Receive incoming messages

Incoming Viber messages are received automatically through the webhook registered when saving — no further configuration is required.

  1. The user searches for the bot in Viber and sends it a message.
  2. The message appears in real time in the messaging inbox.
  3. Copy the sender's Viber user ID into the employee's contact details so that Klacksy can message them directly in the future.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails Auth token wrong Check the token in the bot dashboard on partners.viber.com
Webhook registration fails when saving Klacks instance not publicly reachable via HTTPS Make sure the webhook URL is publicly reachable and a valid SSL certificate is in place
Message is not delivered Recipient has not subscribed to the bot The recipient must first send a message to the bot in Viber
Recipient not found Viber user ID not stored Enter the user ID from the messaging inbox under Address → Contact Details
Incoming messages missing Webhook not registered Save the provider again so that Klacks re-registers the webhook
