Setting up a Viber Bot

Prerequisites

To send and receive messages via Viber, you need a Viber Bot Account. Viber is particularly popular in Eastern Europe and the Middle East.

Note: Service messages via Viber are subject to charges. For more information, visit partners.viber.com.

Step 1 — Create a Viber Bot Account

  1. Sign up at partners.viber.com.
  2. Create a new Bot Account in the Viber Admin Panel.
  3. Note down the Auth Token assigned to you after creation.
  4. Set a sender name (e.g. Klacks Bot).

Step 2 — Configure Viber in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:
FieldDescriptionExample
NameUnique internal nameviber-bot
Display NameShown in the user interfaceViber
Provider TypeSelect ViberViber
Auth TokenThe Auth Token from the Viber Admin Panel4a7f8b2c...
Sender NameName displayed to the recipientKlacks Bot
EnabledTurns the provider on/offYes
  1. Click Save.
  2. Test the connection using the Test button in the provider list.

Step 3 — Send messages via the chatbot (Klacksy)

Once the Viber provider is configured and enabled, the chatbot Klacksy can send messages. You don't need to know any phone numbers — simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Müller that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's mobile number and uses the configured Viber provider. The process is fully transparent to you — you work with names, Klacksy takes care of the rest.

Prerequisite: The recipient must have a mobile number stored in Klacks (under Address → Contact Details).

Step 4 — Receive incoming messages (Webhook)

To display incoming Viber messages in Klacks, a webhook must be configured in the Viber Admin Panel.

  1. Go to Settings → Messaging Providers.
  2. Note the automatically generated webhook secret of your Viber provider.
  3. Configure the webhook URL in your Viber Admin Panel: 
    https://{your-domain}/api/messaging/webhook/viber
  4. Incoming messages will now appear in real time in the Messaging Inbox.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails Auth Token incorrect Check the token in the Viber Admin Panel
Message not delivered Recipient has no Viber account Make sure the recipient uses Viber
Recipient does not receive the message Mobile number not correctly stored Check the mobile number in the contact details
Incoming messages missing Webhook not configured Check the webhook URL in the Viber Admin Panel
Account balance depleted Service message budget exhausted Top up your balance in the Viber Admin Panel
