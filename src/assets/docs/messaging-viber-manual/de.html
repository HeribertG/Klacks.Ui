Viber Bot einrichten

Voraussetzungen

Um Nachrichten über Viber zu senden und zu empfangen, benötigen Sie einen Viber Bot Account. Viber ist besonders beliebt in Osteuropa und dem Nahen Osten.

Hinweis: Service Messages über Viber sind kostenpflichtig. Weitere Informationen finden Sie auf partners.viber.com.

Schritt 1 — Viber Bot Account erstellen

  1. Registrieren Sie sich auf partners.viber.com.
  2. Erstellen Sie einen neuen Bot Account im Viber Admin Panel.
  3. Notieren Sie sich den Auth Token, der Ihnen nach der Erstellung zugewiesen wird.
  4. Legen Sie einen Absendernamen fest (z.B. Klacks Bot).

Schritt 2 — Viber in Klacks konfigurieren

  1. Navigieren Sie zu Einstellungen → Messaging-Anbieter.
  2. Klicken Sie auf Hinzufügen.
  3. Füllen Sie die Felder wie folgt aus:

  2. Testen Sie die Verbindung über den Test-Button in der Anbieter-Liste.

Schritt 3 — Nachrichten über den Chatbot (Klacksy) senden

Sobald der Viber-Anbieter konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten versenden. Sie müssen keine Telefonnummern kennen — verwenden Sie einfach den Namen des Mitarbeiters oder Klienten: 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht: Die Schicht wurde getauscht."
"Benachrichtige Peter Müller, dass sein Dienst am Montag ausfällt."

Klacksy sucht automatisch die hinterlegte Mobilnummer des Empfängers und verwendet den konfigurierten Viber-Anbieter. Der Versand ist für Sie vollständig transparent — Sie arbeiten mit Namen, Klacksy kümmert sich um den Rest.

Voraussetzung: Beim Empfänger muss eine Mobilnummer in Klacks hinterlegt sein (unter Adresse → Kontaktdaten).

Schritt 4 — Eingehende Nachrichten empfangen (Webhook)

Um eingehende Viber-Nachrichten in Klacks anzuzeigen, muss im Viber Admin Panel ein Webhook konfiguriert werden.

  1. Gehen Sie zu Einstellungen → Messaging-Anbieter.
  2. Notieren Sie das automatisch generierte Webhook-Secret Ihres Viber-Anbieters.
  3. Konfigurieren Sie im Viber Admin Panel die Webhook-URL: 
    https://{ihre-domain}/api/messaging/webhook/viber
  4. Eingehende Nachrichten erscheinen nun in Echtzeit in der Messaging-Inbox.
