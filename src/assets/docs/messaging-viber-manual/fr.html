Configurer un bot Viber

Conditions préalables

Pour envoyer et recevoir des messages via Viber, vous avez besoin d'un compte Bot Viber. Viber est particulièrement populaire en Europe de l'Est et au Moyen-Orient.

Remarque : les messages de service via Viber sont payants. Pour plus d'informations, consultez partners.viber.com.

Étape 1 — Créer un compte Bot Viber

  1. Inscrivez-vous sur partners.viber.com.
  2. Créez un nouveau compte Bot dans le panneau d'administration Viber.
  3. Notez le Auth Token qui vous est attribué après la création.
  4. Définissez un nom d'expéditeur (p. ex. Klacks Bot).

Étape 2 — Configurer Viber dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  1. Cliquez sur Enregistrer.
  2. Testez la connexion à l'aide du bouton Tester dans la liste des fournisseurs.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur Viber configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les numéros de téléphone — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement le numéro de mobile du destinataire et utilise le fournisseur Viber configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : Le destinataire doit avoir un numéro de mobile enregistré dans Klacks (sous Adresse → Coordonnées).

Étape 4 — Recevoir des messages entrants (Webhook)

Pour afficher les messages Viber entrants dans Klacks, un webhook doit être configuré dans le panneau d'administration Viber.

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Notez le secret du webhook généré automatiquement pour votre fournisseur Viber.
  3. Configurez l'URL du webhook dans le panneau d'administration Viber : 
    https://{votre-domaine}/api/messaging/webhook/viber
  4. Les messages entrants apparaîtront désormais en temps réel dans la boîte de réception de messagerie.
