Configurer un bot Viber

Conditions préalables

Pour envoyer et recevoir des messages via Viber, vous avez besoin d'un bot Viber, que vous créez via le portail partenaires de Viber. Viber est particulièrement populaire en Europe de l'Est et au Moyen-Orient.

Remarque : Viber a commercialisé l'utilisation des bots — selon le pays et le volume de messages, des modèles payants peuvent s'appliquer. Vérifiez les conditions actuelles sur partners.viber.com.

Étape 1 — Créer un bot Viber

  1. Inscrivez-vous sur partners.viber.com.
  2. Créez un nouveau bot dans le portail partenaires.
  3. Notez l'auth token depuis le tableau de bord du bot.
  4. Choisissez un nom d'expéditeur (p. ex. Klacks Bot).

Étape 2 — Configurer Viber dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  1. Cliquez sur Enregistrer. Klacks enregistre alors automatiquement le webhook auprès de Viber (set_webhook).
  2. Testez la connexion à l'aide du bouton Tester dans la liste des fournisseurs.

Important : L'URL de webhook affichée doit être accessible publiquement via HTTPS — sinon l'enregistrement du webhook échoue lors de la sauvegarde.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur Viber configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les ID utilisateur Viber — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement l'ID utilisateur Viber enregistré du destinataire et utilise le fournisseur Viber configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Important : Les bots Viber ne peuvent écrire qu'aux utilisateurs qui se sont abonnés au bot (conversation 1:1 démarrée avec le bot). Le destinataire doit donc d'abord envoyer un message au bot. Son ID utilisateur Viber devient alors connu via le message entrant (visible dans la boîte de réception de messagerie) et est enregistré chez le destinataire sous Adresse → Coordonnées.

Étape 4 — Recevoir les messages entrants

Les messages Viber entrants sont reçus automatiquement via le webhook enregistré lors de la sauvegarde — aucune configuration supplémentaire n'est nécessaire.

  1. L'utilisateur recherche le bot dans Viber et lui envoie un message.
  2. Le message apparaît en temps réel dans la boîte de réception de messagerie.
  3. Reportez l'ID utilisateur Viber de l'expéditeur dans les coordonnées de l'employé afin que Klacksy puisse lui écrire directement à l'avenir.
