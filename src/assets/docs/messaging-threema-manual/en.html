Setting up Threema Gateway

Prerequisites

To send messages via Threema, you need an account with the Threema Gateway. Threema is a Swiss provider, widely used in Switzerland and privacy-friendly (Swiss DPA).

Important: The Threema integration is designed for sending only. Receiving incoming messages would require the gateway's end-to-end mode and is not supported. Sending is a paid service — every sent message consumes credits.

Step 1 — Create a Threema Gateway account

  1. Sign up on gateway.threema.ch.
  2. Request a Gateway ID in basic mode (e.g. *MYGATEWAY). It always starts with an asterisk (*) and must be approved by Threema.
  3. Purchase credits — without a balance, no messages can be sent.
  4. Note down the API secret from the gateway dashboard.

Note: Treat the API secret like a password. Do not share it publicly and store it securely.

Step 2 — Configure Threema in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:

  1. Click Save.
  2. Test the connection using the Test button in the provider list. The test verifies the credentials via the gateway's credits query.

Step 3 — Send messages via the chatbot (Klacksy)

Once the Threema provider is configured and enabled, the chatbot Klacksy can send messages. You do not need to know any Threema IDs — simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2:00 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Müller that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's stored Threema ID and uses the configured Threema provider. The process is fully transparent for you — you work with names, Klacksy takes care of the rest.

Prerequisite: The recipient's 8-character Threema ID must be stored in Klacks (under Address → Contact Details). Employees can find their Threema ID in the Threema app under "My Profile".

Incoming Messages

The Threema integration does not support receiving — replies to sent messages are not transmitted to Klacks. Receiving would require the end-to-end mode of the Threema Gateway; the Klacks integration uses basic mode. The messaging inbox therefore does not show any incoming messages for this provider.
