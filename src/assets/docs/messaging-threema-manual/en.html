Setting up Threema Gateway

Prerequisites

To send and receive messages via Threema, you need an account with the Threema Gateway. Threema is a Swiss provider offering end-to-end encryption and full GDPR compliance.

Note: Threema Gateway is a paid service — charges apply per message sent. For more information, visit gateway.threema.ch.

Step 1 — Create a Threema Gateway account

  1. Sign up at gateway.threema.ch.
  2. Create a Gateway ID (e.g. *MYGATEWAY). It always starts with an asterisk (*).
  3. Note down the API secret assigned to you after creation.
  4. Choose the desired mode (Basic or End-to-End) for your Gateway ID.

Step 2 — Configure Threema in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:

EnabledTurns the provider on/offYes
  1. Click Save.
  2. Test the connection using the Test button in the provider list.

Step 3 — Send messages via the chatbot (Klacksy)

Once the Threema provider is configured and enabled, the chatbot Klacksy can send messages. You don't need to know any Threema IDs — simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Müller that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's Threema ID and uses the configured Threema provider. The process is fully transparent to you — you work with names, Klacksy takes care of the rest.

Prerequisite: The recipient must have a Threema ID stored in Klacks (under Address → Contact Details).

Step 4 — Receive incoming messages (Webhook)

To display incoming Threema messages in Klacks, a webhook must be configured in the Threema Gateway.

  1. Go to Settings → Messaging Providers.
  2. Note the automatically generated webhook secret of your Threema provider.
  3. Configure the webhook URL in your Threema Gateway dashboard: 
    https://{your-domain}/api/messaging/webhook/threema
  4. Incoming messages will now appear in real time in the Messaging Inbox.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails Gateway ID or API secret incorrect Check the credentials in the Gateway dashboard
Message not delivered Recipient has no valid Threema ID Make sure the Threema ID is correctly stored
Recipient does not receive the message Threema ID not found Check whether the ID exists in the Threema directory
Incoming messages missing Webhook not configured Check the webhook URL in the Gateway dashboard
Account balance depleted Credits exhausted Top up credits in the Threema Gateway
