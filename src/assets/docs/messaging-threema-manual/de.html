Threema Gateway einrichten

Voraussetzungen

Um Nachrichten über Threema zu senden und zu empfangen, benötigen Sie ein Konto beim Threema Gateway. Threema ist ein Schweizer Anbieter mit Ende-zu-Ende-Verschlüsselung und vollständiger DSGVO-Konformität.

Hinweis: Threema Gateway ist ein kostenpflichtiger Dienst — es fallen Kosten pro gesendeter Nachricht an. Weitere Informationen finden Sie auf gateway.threema.ch.

Schritt 1 — Threema Gateway Account erstellen

  1. Registrieren Sie sich auf gateway.threema.ch.
  2. Erstellen Sie eine Gateway-ID (z.B. *MYGATEWAY). Diese beginnt immer mit einem Stern (*).
  3. Notieren Sie sich das API-Secret, das Ihnen nach der Erstellung zugewiesen wird.
  4. Wählen Sie den gewünschten Modus (Basic oder End-to-End) für Ihre Gateway-ID.

Schritt 2 — Threema in Klacks konfigurieren

  1. Navigieren Sie zu Einstellungen → Messaging-Anbieter.
  2. Klicken Sie auf Hinzufügen.
  3. Füllen Sie die Felder wie folgt aus:

Schritt 3 — Nachrichten über den Chatbot (Klacksy) senden

Sobald der Threema-Anbieter konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten versenden. Sie müssen keine Threema-IDs kennen — verwenden Sie einfach den Namen des Mitarbeiters oder Klienten: 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht: Die Schicht wurde getauscht."
"Benachrichtige Peter Müller, dass sein Dienst am Montag ausfällt."

Klacksy sucht automatisch die hinterlegte Threema-ID des Empfängers und verwendet den konfigurierten Threema-Anbieter. Der Versand ist für Sie vollständig transparent — Sie arbeiten mit Namen, Klacksy kümmert sich um den Rest.

Voraussetzung: Beim Empfänger muss eine Threema-ID in Klacks hinterlegt sein (unter Adresse → Kontaktdaten).

Schritt 4 — Eingehende Nachrichten empfangen (Webhook)

Um eingehende Threema-Nachrichten in Klacks anzuzeigen, muss im Threema Gateway ein Webhook konfiguriert werden.

  1. Gehen Sie zu Einstellungen → Messaging-Anbieter.
  2. Notieren Sie das automatisch generierte Webhook-Secret Ihres Threema-Anbieters.
  3. Konfigurieren Sie im Threema Gateway-Dashboard die Webhook-URL: 
    https://{ihre-domain}/api/messaging/webhook/threema
  4. Eingehende Nachrichten erscheinen nun in Echtzeit in der Messaging-Inbox.
