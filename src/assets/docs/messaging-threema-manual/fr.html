Configurer Threema Gateway

Conditions préalables

Pour envoyer et recevoir des messages via Threema, vous avez besoin d'un compte auprès du Threema Gateway. Threema est un fournisseur suisse offrant un chiffrement de bout en bout et une conformité totale au RGPD.

Remarque : Threema Gateway est un service payant — des frais s'appliquent par message envoyé. Pour plus d'informations, consultez gateway.threema.ch.

Étape 1 — Créer un compte Threema Gateway

  1. Inscrivez-vous sur gateway.threema.ch.
  2. Créez un Gateway-ID (p. ex. *MYGATEWAY). Il commence toujours par un astérisque (*).
  3. Notez le secret API qui vous est attribué après la création.
  4. Choisissez le mode souhaité (Basic ou End-to-End) pour votre Gateway-ID.

Étape 2 — Configurer Threema dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  2. Testez la connexion à l'aide du bouton Tester dans la liste des fournisseurs.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur Threema configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les Threema-ID — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement le Threema-ID du destinataire et utilise le fournisseur Threema configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : Le destinataire doit avoir un Threema-ID enregistré dans Klacks (sous Adresse → Coordonnées).

Étape 4 — Recevoir des messages entrants (Webhook)

Pour afficher les messages Threema entrants dans Klacks, un webhook doit être configuré dans le Threema Gateway.

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Notez le secret du webhook généré automatiquement pour votre fournisseur Threema.
  3. Configurez l'URL du webhook dans le tableau de bord du Threema Gateway : 
    https://{votre-domaine}/api/messaging/webhook/threema
  4. Les messages entrants apparaîtront désormais en temps réel dans la boîte de réception de messagerie.

ProblèmeCause possibleSolution
Le test de connexion échoue Gateway-ID ou secret API incorrect Vérifiez les identifiants dans le tableau de bord Gateway
Le message n'est pas livré Le destinataire n'a pas de Threema-ID valide Assurez-vous que le Threema-ID est correctement enregistré
Le destinataire ne reçoit pas le message Threema-ID introuvable Vérifiez si l'ID existe dans le répertoire Threema
Les messages entrants manquent Webhook non configuré Vérifiez l'URL du webhook dans le tableau de bord Gateway
