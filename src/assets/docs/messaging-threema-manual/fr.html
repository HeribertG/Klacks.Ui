Configurer Threema Gateway

Conditions préalables

Pour envoyer des messages via Threema, vous avez besoin d'un compte auprès du Threema Gateway. Threema est un fournisseur suisse, très répandu en Suisse et respectueux de la protection des données (LPD suisse).

Important : L'intégration Threema est conçue uniquement pour l'envoi. La réception de messages entrants nécessiterait le mode end-to-end de la passerelle et n'est pas prise en charge. L'envoi est payant — chaque message envoyé consomme des crédits.

Étape 1 — Créer un compte Threema Gateway

  1. Inscrivez-vous sur gateway.threema.ch.
  2. Demandez un Gateway ID en mode basic (p. ex. *MYGATEWAY). Il commence toujours par un astérisque (*) et doit être approuvé par Threema.
  3. Achetez des crédits — sans solde, aucun message ne peut être envoyé.
  4. Notez le secret API depuis le tableau de bord de la passerelle.

Remarque : traitez le secret API comme un mot de passe. Ne le partagez pas publiquement et conservez-le en lieu sûr.

Étape 2 — Configurer Threema dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  2. Testez la connexion à l'aide du bouton Tester dans la liste des fournisseurs. Le test vérifie les identifiants via la requête de crédits de la passerelle.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur Threema configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les Threema ID — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement le Threema ID enregistré du destinataire et utilise le fournisseur Threema configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : Le Threema ID à 8 caractères du destinataire doit être enregistré dans Klacks (sous Adresse → Coordonnées). L'employé trouve son Threema ID dans son application Threema sous « Mon profil ».

Messages entrants

L'intégration Threema ne prend pas en charge la réception — les réponses aux messages envoyés ne sont pas transmises à Klacks. La réception nécessiterait le mode end-to-end du Threema Gateway ; l'intégration Klacks utilise le mode basic. La boîte de réception de messagerie n'affiche donc aucun message entrant pour ce fournisseur.
