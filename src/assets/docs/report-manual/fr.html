Manuel du Report Designer

Structure du rapport

Un rapport se compose de trois zones :

  • En-tête – imprimé en haut de chaque page
  • Corps – contient les tableaux de données
  • Pied de page – imprimé en bas de chaque page

Chaque zone peut être modifiée via l'onglet Design dans l'éditeur de rapport.

Zone d'en-tête

L'en-tête comporte trois zones : Gauche, Centre et Droite.

Chaque zone peut contenir :

  • Champs – champs de base de données remplis automatiquement
  • Texte libre – texte saisi manuellement
  • Images – par ex. un logo d'entreprise (télécharger via le gestionnaire d'images)

Les lignes peuvent être ajoutées ou supprimées via la barre d'outils.

Tableaux de données

Le corps contient un ou plusieurs tableaux.

ActionDescription
Ajouter une colonneVia l'icône + ou par glisser-déposer depuis la liste des champs
Largeur de colonneAjuster en faisant glisser le bord de la colonne
Ordre des colonnesRéorganiser par glisser-déposer
Supprimer une colonneDans l'éditeur de colonne via l'icône de suppression

Chaque tableau est lié à un DataSet (par ex. planning, adresses).

Champs fusionnés (Merged Fields)

Les champs fusionnés permettent plusieurs liaisons de données dans une seule colonne.

  • Dans l'éditeur de colonne, cliquer Ajouter un champ pour ajouter d'autres champs à la même colonne
  • Les valeurs sont affichées empilées ou avec un séparateur
  • Le séparateur peut être configuré dans le dialogue du champ (par ex. virgule, espace, saut de ligne)

Pied de tableau

Un pied de page peut être affiché sous chaque tableau.

  • Champs SUM : Les colonnes numériques peuvent être automatiquement additionnées
  • Libellé : Le libellé de la somme peut être affiché ou masqué
  • Activation via l'éditeur de colonne dans l'onglet Pied de page

Lignes de texte libre

Les lignes de texte libre peuvent être insérées avant ou après les tableaux de données.

PropriétéDescription
PositionChoisir Avant les données ou Après les données
ContenuTout texte, par ex. notes, conditions ou champs de signature
StylePolice, taille et alignement configurables

Mise en forme

Chaque cellule et chaque texte libre peut être formaté individuellement :

OptionDescription
PolicePolices sélectionnables pour la cellule
TailleTaille en points (pt)
Gras / Italique / SoulignéVia les boutons B / I / U

AlignementGauche, Centré ou Droite

Bordures de cellules

Les lignes de bordure peuvent être configurées individuellement pour chaque cellule.

PropriétéOptions
CôtésHaut, Droite, Bas, Gauche (individuellement ou tous)
Style de ligneFin, Moyen, Épais, Pointillé, Double
Couleur de ligneLibrement sélectionnable

Les bordures sont configurées dans l'éditeur de colonne sous Bordures.

Mise en page

Les paramètres d'impression peuvent être ajustés dans l'onglet Général :

  • Orientation : Portrait ou Paysage
  • Format de papier : A4, A3, B4 (JIS), B5 (JIS) ou Letter
  • Marges de page : Haut, Droite, Bas, Gauche en mm

Options d'affichage (Designer)

Dans l'onglet Design, des options supplémentaires sont disponibles pour la source de données Planning (Schedule) :

  • Regrouper les entrées par jour : Plusieurs entrées le même jour sont combinées en une seule ligne
  • Afficher la période complète : Tous les jours de la période sont affichés, même s'il n'y a pas d'entrées

Paramètres

Les paramètres sont demandés lors de l'exécution d'un rapport. Leurs valeurs sont disponibles dans les filtres de lignes et les formules, et peuvent en plus restreindre la requête de la source de données. Ils se définissent dans l'onglet Paramètres.

ChampSignification
CléNom technique. Doit commencer par une lettre et ne peut contenir que des lettres, des chiffres et des traits de soulignement. Unique par rapport.
DésignationLibellé affiché lors de l'exécution.
TypeTexte, Nombre, Date, Oui/Non ou Liste.
Valeur par défautUtilisée lorsque rien n'est saisi à l'exécution.
Valeurs de la listeUniquement pour le type « Liste » : les valeurs autorisées, séparées par des virgules.
Agit surDétermine si la valeur est également transmise à la source de données.
Champ obligatoireLe rapport ne peut pas être exécuté sans valeur.

Paramètres dans les filtres et les formules

Chaque paramètre est disponible dans le script sous sa clé précédée du préfixe param_ — la clé region devient donc param_region. Le préfixe empêche qu'un paramètre masque une valeur de ligne portant le même nom. Le nom actuel est affiché sous chaque paramètre.

La valeur est convertie dans le type choisi avant l'évaluation :

  • Nombre : comme nombre ; une saisie invalide devient 0
  • Oui/Non : vrai pour 1, true, wahr ou yes, faux sinon
  • Texte, Date, Liste : comme texte

Lier un paramètre à la source de données

Le réglage Agit sur permet à un paramètre de restreindre les données chargées :

RéglageEffet
filtres et formules uniquementLa valeur n'est utilisée que dans le script (par défaut).
groupe de la requêteLa valeur remplace le groupe pour lequel les données sont chargées.
personne de la requêteLa valeur remplace la personne pour laquelle les données sont chargées.
date de début de la requêteLa valeur remplace le début de la période.
date de fin de la requêteLa valeur remplace la fin de la période.

Les dates liées doivent être saisies au format AAAA-MM-JJ ou JJ.MM.AAAA. Une valeur d'une autre forme est ignorée, afin que la requête ne renvoie pas silencieusement un résultat vide. Une valeur vide laisse le réglage d'origine inchangé.
