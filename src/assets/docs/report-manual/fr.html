Manuel du Report Designer

Structure du rapport

Un rapport se compose de trois zones :

  • En-tête – imprimé en haut de chaque page
  • Corps – contient les tableaux de données
  • Pied de page – imprimé en bas de chaque page

Chaque zone peut être modifiée via l'onglet Design dans l'éditeur de rapport.

Zone d'en-tête

L'en-tête comporte trois zones : Gauche, Centre et Droite.

Chaque zone peut contenir :

  • Champs – champs de base de données remplis automatiquement
  • Texte libre – texte saisi manuellement
  • Images – par ex. un logo d'entreprise (télécharger via le gestionnaire d'images)

Les lignes peuvent être ajoutées ou supprimées via la barre d'outils.

Tableaux de données

Le corps contient un ou plusieurs tableaux.

ActionDescription
Ajouter une colonneVia l'icône + ou par glisser-déposer depuis la liste des champs
Largeur de colonneAjuster en faisant glisser le bord de la colonne
Ordre des colonnesRéorganiser par glisser-déposer
Supprimer une colonneDans l'éditeur de colonne via l'icône de suppression

Chaque tableau est lié à un DataSet (par ex. planning, adresses).

Champs fusionnés (Merged Fields)

Les champs fusionnés permettent plusieurs liaisons de données dans une seule colonne.

  • Dans l'éditeur de colonne, cliquer Ajouter un champ pour ajouter d'autres champs à la même colonne
  • Les valeurs sont affichées empilées ou avec un séparateur
  • Le séparateur peut être configuré dans le dialogue du champ (par ex. virgule, espace, saut de ligne)

Pied de tableau

Un pied de page peut être affiché sous chaque tableau.

  • Champs SUM : Les colonnes numériques peuvent être automatiquement additionnées
  • Libellé : Le libellé de la somme peut être affiché ou masqué
  • Activation via l'éditeur de colonne dans l'onglet Pied de page

Lignes de texte libre

Les lignes de texte libre peuvent être insérées avant ou après les tableaux de données.

PropriétéDescription
PositionChoisir Avant les données ou Après les données
ContenuTout texte, par ex. notes, conditions ou champs de signature
StylePolice, taille et alignement configurables

Mise en forme

Chaque cellule et chaque texte libre peut être formaté individuellement :

OptionDescription
PolicePolices sélectionnables pour la cellule
TailleTaille en points (pt)
Gras / Italique / SoulignéVia les boutons B / I / U
Couleur du texteCouleur librement sélectionnable
AlignementGauche, Centré ou Droite

Bordures de cellules

Les lignes de bordure peuvent être configurées individuellement pour chaque cellule.

PropriétéOptions
CôtésHaut, Droite, Bas, Gauche (individuellement ou tous)
Style de ligneFin, Moyen, Épais, Pointillé, Double
Couleur de ligneLibrement sélectionnable

Les bordures sont configurées dans l'éditeur de colonne sous Bordures.

Mise en page

Les paramètres d'impression peuvent être ajustés dans l'onglet Général :

  • Orientation : Portrait ou Paysage
  • Marges de page : Haut, Droite, Bas, Gauche en mm

Sources de données

Sources de données disponibles pour les rapports :

Source de donnéesDescription
Planning (Schedule)Équipes et horaires de travail
Adresses (Liste)Toutes les adresses sous forme de tableau
Adresse (Détail)Adresse unique
AbsencesAperçu des absences
Équipes (Shifts)Tableau des équipes
GroupesAperçu des groupes

La source de données est sélectionnée dans l'onglet « Source de données » et détermine les champs disponibles.
