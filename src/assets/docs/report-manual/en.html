Report Designer Manual

Report Structure

A report consists of three areas:

  • Header – printed at the top of every page
  • Body – contains the data tables
  • Footer – printed at the bottom of every page

Each area can be edited via the Design tab in the report editor.

Header Area

The header has three zones: Left, Center, and Right.

Each zone can contain:

  • Fields – database fields that are filled automatically
  • Free text – manually entered text
  • Images – e.g. a company logo (upload via the image manager)

Rows can be added or removed via the toolbar.

Body Tables

The body contains one or more tables.

ActionDescription
Add columnVia the + icon or drag & drop from the field list
Column widthAdjust by dragging the column border
Column orderRearrange via drag & drop
Remove columnIn the column editor via the delete icon

Each table is linked to a DataSet (e.g. schedule, addresses).

Merged Fields

Merged Fields allow multiple data bindings in a single column.

  • In the column editor, click Add Field to add more fields to the same column
  • Values are displayed stacked or with a separator
  • The separator can be configured in the field dialog (e.g. comma, space, line break)

Table Footer

A footer can be displayed below each table.

  • SUM fields: Numeric columns can be automatically summed
  • Label: The sum label can be shown or hidden
  • Activation via the column editor in the Footer tab

Free Text Rows

Free text rows can be inserted before or after the data tables.

PropertyDescription
PositionChoose Before Data or After Data
ContentAny text, e.g. notes, conditions, or signature fields
StylingFont, size, and alignment are configurable

Cell Borders

Border lines can be configured individually for each cell.

PropertyOptions
SidesTop, Right, Bottom, Left (individually or all)
Line styleThin, Medium, Thick, Dashed, Double
Line colorFreely selectable

Borders are configured in the column editor under Borders.

Page Setup

Print settings can be adjusted in the General tab:

  • Orientation: Portrait or Landscape
  • Paper size: A4, A3, B4 (JIS), B5 (JIS), or Letter
  • Page margins: Top, Right, Bottom, Left in mm

Display Options (Designer)

In the Design tab, additional options are available for the Schedule data source:

  • Merge entries per day: Multiple entries on the same day are combined into a single row
  • Show full period: All days of the period are displayed, even if there are no entries

Parameters

Parameters are asked for when a report is run. Their values are available to row filters and formulas, and can additionally narrow down the data source query. They are defined on the Parameters tab.

FieldMeaning
KeyTechnical name. Has to start with a letter and may only contain letters, digits and underscores. Unique per report.
LabelCaption shown when the report is run.
TypeText, Number, Date, Yes/No or Choice.
Default valueUsed when nothing is entered at run time.
ChoicesOnly for type "Choice": the permitted values, separated by commas.
Applies toDecides whether the value is also passed to the data source.
RequiredThe report cannot be run without a value.

Parameters in filters and formulas

Every parameter is available in the script under its key with the prefix param_ — the key region becomes param_region. The prefix keeps a parameter from shadowing a row value of the same name. The current name is shown below each parameter.

The value is converted to the selected type before evaluation:

  • Number: as a number; invalid input becomes 0
  • Yes/No: true for 1, true, wahr or yes, false otherwise
  • Text, Date, Choice: as text

Binding a parameter to the data source

Applies to lets a parameter narrow down which data is loaded in the first place:

SettingEffect
filters and formulas onlyThe value is used in the script only (default).
query groupThe value replaces the group data is loaded for.
query personThe value replaces the person data is loaded for.
query start dateThe value replaces the start of the period.
query end dateThe value replaces the end of the period.

Bound date values have to be entered as YYYY-MM-DD or DD.MM.YYYY. A value in any other shape is ignored, so the query does not silently come back empty. An empty value leaves the original setting untouched.
