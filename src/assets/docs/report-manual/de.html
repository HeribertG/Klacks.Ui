Report Designer Handbuch

Report-Struktur

Ein Report besteht aus drei Bereichen:

  • Header – wird auf jeder Seite oben gedruckt
  • Body – enthält die Datentabellen
  • Footer – wird auf jeder Seite unten gedruckt

Jeder Bereich kann über den Tab Design im Report-Editor bearbeitet werden.

Header-Bereich

Der Header hat drei Zonen: Links, Mitte und Rechts.

Jede Zone kann enthalten:

  • Felder – Datenbank-Felder, die automatisch befüllt werden
  • Freitext – manuell eingegebener Text
  • Bilder – z.B. ein Firmenlogo (über den Bild-Manager hochladen)

Zeilen können über die Toolbar hinzugefügt oder entfernt werden.

Body-Tabellen

Der Body enthält eine oder mehrere Tabellen.

AktionBeschreibung
Spalte hinzufügenÜber das + Symbol oder per Drag & Drop aus der Feldliste
SpaltenbreitePer Drag am Spaltenrand anpassen
SpaltenreihenfolgePer Drag & Drop verschieben
Spalte entfernenIm Spalten-Editor über das Löschen-Symbol

Jede Tabelle ist mit einem DataSet verknüpft (z.B. Arbeitsplan, Adressen).

Felder zusammenlegen (Merged Fields)

Merged Fields erlauben mehrere Daten-Bindings in einer einzigen Spalte.

  • Im Spalten-Editor Feld hinzufügen klicken, um weitere Felder zur selben Spalte hinzuzufügen
  • Die Werte werden untereinander oder mit einem Separator angezeigt
  • Der Separator ist im Feld-Dialog konfigurierbar (z.B. Komma, Leerzeichen, Zeilenumbruch)

Tabellen-Fusszeile

Unter jeder Tabelle kann eine Fusszeile angezeigt werden.

  • SUM-Felder: Numerische Spalten können automatisch summiert werden
  • Label: Die Beschriftung der Summe kann ein- oder ausgeblendet werden
  • Aktivierung über den Spalten-Editor im Tab Fusszeile

Freitext-Zeilen

Freitext-Zeilen können vor oder nach den Datentabellen eingefügt werden.

EigenschaftBeschreibung
PositionVor Daten oder Nach Daten wählbar
InhaltBeliebiger Text, z.B. Hinweise, Bedingungen oder Unterschriftsfelder
StylingSchriftart, Grösse und Ausrichtung konfigurierbar

Formatierung

Jede Zelle und jeder Freitext kann individuell formatiert werden:

OptionBeschreibung
SchriftartWählbare Schriftarten für die Zelle
SchriftgrösseGrösse in Punkt (pt)
Fett / Kursiv / UnterstrichenÜber die B / I / U Schaltflächen
TextfarbeFrei wählbare Farbe
AusrichtungLinks, Zentriert oder Rechts

Zellen-Rahmen

Für jede Zelle können die Rahmenlinien einzeln konfiguriert werden.

EigenschaftOptionen
SeitenOben, Rechts, Unten, Links (einzeln oder alle)
LinienstilDünn, Mittel, Dick, Gestrichelt, Doppelt
LinienfarbeFrei wählbar

Rahmen werden im Spalten-Editor unter Rahmen eingestellt.

Seiteneinstellungen

Im Tab Allgemein können die Druckeinstellungen angepasst werden:

  • Ausrichtung: Hochformat (Portrait) oder Querformat (Landscape)
  • Papiergrösse: A4, A3, B4 (JIS), B5 (JIS) oder Letter
  • Seitenränder: Oben, Rechts, Unten, Links in mm

Darstellungsoptionen (Designer)

Im Tab Design stehen bei der Datenquelle Arbeitsplan (Schedule) zusätzliche Optionen zur Verfügung:

  • Einträge pro Tag zusammenfassen: Mehrere Einträge am selben Tag werden in einer Zeile zusammengefasst
  • Volle Periode anzeigen: Alle Tage der Periode werden angezeigt, auch wenn keine Einträge vorhanden sind

Die Datenquelle wird im Tab «Datenquelle» gewählt und bestimmt die verfügbaren Felder.

Parameter

Parameter werden beim Ausführen eines Reports abgefragt. Ihre Werte stehen in Zeilenfiltern und Formeln zur Verfügung und können zusätzlich die Abfrage der Datenquelle einschränken. Angelegt werden sie im Tab Parameter.

FeldBedeutung
SchlüsselTechnischer Name. Muss mit einem Buchstaben beginnen und darf nur Buchstaben, Ziffern und Unterstriche enthalten. Pro Report eindeutig.
BezeichnungBeschriftung, die beim Ausführen angezeigt wird.
TypText, Zahl, Datum, Ja/Nein oder Auswahl.
StandardwertWird verwendet, wenn beim Ausführen nichts eingegeben wird.
AuswahlwerteNur beim Typ «Auswahl»: die zulässigen Werte, durch Komma getrennt.
Wirkt aufLegt fest, ob der Wert zusätzlich an die Datenquelle übergeben wird.
PflichtfeldDer Report kann ohne einen Wert nicht ausgeführt werden.

Parameter in Filtern und Formeln

Jeder Parameter ist im Skript unter dem Schlüssel mit dem Präfix param_ verfügbar — aus dem Schlüssel region wird also param_region. Das Präfix verhindert, dass ein Parameter einen gleichnamigen Zeilenwert verdeckt. Der aktuelle Name wird unter jedem Parameter angezeigt.

Der Wert wird vor der Auswertung in den gewählten Typ umgewandelt:

  • Zahl: als Zahl; eine ungültige Eingabe wird zu 0
  • Ja/Nein: wahr bei 1, true, wahr oder yes, sonst falsch
  • Text, Datum, Auswahl: als Text

Parameter an die Datenquelle binden

Über Wirkt auf schränkt ein Parameter zusätzlich ein, welche Daten überhaupt geladen werden:

EinstellungWirkung
nur Filter und FormelnDer Wert wird ausschliesslich im Skript verwendet (Standard).
Gruppe der AbfrageDer Wert ersetzt die Gruppe, für die Daten geladen werden.
Person der AbfrageDer Wert ersetzt die Person, für die Daten geladen werden.
Startdatum der AbfrageDer Wert ersetzt den Beginn des Zeitraums.
Enddatum der AbfrageDer Wert ersetzt das Ende des Zeitraums.

Gebundene Datumswerte müssen als JJJJ-MM-TT oder TT.MM.JJJJ eingegeben werden. Ein Wert in anderer Form wird ignoriert, damit die Abfrage nicht unbemerkt leer bleibt. Ein leerer Wert lässt die ursprüngliche Einstellung unverändert.
