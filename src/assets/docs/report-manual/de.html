Report Designer Handbuch

Report-Struktur

Ein Report besteht aus drei Bereichen:

  • Header – wird auf jeder Seite oben gedruckt
  • Body – enthält die Datentabellen
  • Footer – wird auf jeder Seite unten gedruckt

Jeder Bereich kann über den Tab Design im Report-Editor bearbeitet werden.

Header-Bereich

Der Header hat drei Zonen: Links, Mitte und Rechts.

Jede Zone kann enthalten:

  • Felder – Datenbank-Felder, die automatisch befüllt werden
  • Freitext – manuell eingegebener Text
  • Bilder – z.B. ein Firmenlogo (über den Bild-Manager hochladen)

Zeilen können über die Toolbar hinzugefügt oder entfernt werden.

Body-Tabellen

Der Body enthält eine oder mehrere Tabellen.

AktionBeschreibung
Spalte hinzufügenÜber das + Symbol oder per Drag & Drop aus der Feldliste
SpaltenbreitePer Drag am Spaltenrand anpassen
SpaltenreihenfolgePer Drag & Drop verschieben
Spalte entfernenIm Spalten-Editor über das Löschen-Symbol

Jede Tabelle ist mit einem DataSet verknüpft (z.B. Arbeitsplan, Adressen).

Felder zusammenlegen (Merged Fields)

Merged Fields erlauben mehrere Daten-Bindings in einer einzigen Spalte.

  • Im Spalten-Editor Feld hinzufügen klicken, um weitere Felder zur selben Spalte hinzuzufügen
  • Die Werte werden untereinander oder mit einem Separator angezeigt
  • Der Separator ist im Feld-Dialog konfigurierbar (z.B. Komma, Leerzeichen, Zeilenumbruch)

Tabellen-Fusszeile

Unter jeder Tabelle kann eine Fusszeile angezeigt werden.

  • SUM-Felder: Numerische Spalten können automatisch summiert werden
  • Label: Die Beschriftung der Summe kann ein- oder ausgeblendet werden
  • Aktivierung über den Spalten-Editor im Tab Fusszeile

Freitext-Zeilen

Freitext-Zeilen können vor oder nach den Datentabellen eingefügt werden.

EigenschaftBeschreibung
PositionVor Daten oder Nach Daten wählbar
InhaltBeliebiger Text, z.B. Hinweise, Bedingungen oder Unterschriftsfelder
StylingSchriftart, Grösse und Ausrichtung konfigurierbar

Formatierung

Jede Zelle und jeder Freitext kann individuell formatiert werden:

OptionBeschreibung
SchriftartWählbare Schriftarten für die Zelle
SchriftgrösseGrösse in Punkt (pt)
Fett / Kursiv / UnterstrichenÜber die B / I / U Schaltflächen
TextfarbeFrei wählbare Farbe
AusrichtungLinks, Zentriert oder Rechts

Zellen-Rahmen

Für jede Zelle können die Rahmenlinien einzeln konfiguriert werden.

EigenschaftOptionen
SeitenOben, Rechts, Unten, Links (einzeln oder alle)
LinienstilDünn, Mittel, Dick, Gestrichelt, Doppelt
LinienfarbeFrei wählbar

Rahmen werden im Spalten-Editor unter Rahmen eingestellt.

Seiteneinstellungen

Im Tab Allgemein können die Druckeinstellungen angepasst werden:

  • Ausrichtung: Hochformat (Portrait) oder Querformat (Landscape)
  • Seitenränder: Oben, Rechts, Unten, Links in mm

Datenquellen

Verfügbare Datenquellen für Reports:

DatenquelleBeschreibung
Arbeitsplan (Schedule)Schichten und Arbeitszeiten
Adressen (Liste)Alle Adressen als Tabelle
Adresse (Detail)Einzelne Adresse
AbwesenheitenAbwesenheitsübersicht
Schichten (Shifts)Schichttabelle
GruppenGruppenübersicht
Container TemplateVorlage für Container-Reports

Die Datenquelle wird im Tab «Datenquelle» gewählt und bestimmt die verfügbaren Felder.
