Configurer la messagerie Zalo

Conditions préalables

Pour envoyer des messages via Zalo, vous avez besoin d'un Zalo Official Account (OA) sur oa.zalo.me ainsi que d'une application sur developers.zalo.me. Zalo est le premier messager au Vietnam.

Important : L'intégration Zalo est conçue uniquement pour l'envoi. De plus, des restrictions de la plateforme Zalo s'appliquent :

  • Le token d'accès expire après env. 25 heures et doit être renouvelé en dehors de Klacks puis saisi à nouveau.
  • Les messages ne peuvent être envoyés qu'aux utilisateurs ayant préalablement interagi avec l'Official Account (fenêtre d'interaction).

Étape 1 — Configurer un Zalo Official Account et une application

  1. Créez un Official Account sur oa.zalo.me.
  2. Créez une application sur developers.zalo.me.
  3. Liez l'Official Account à l'application.
  4. Obtenez un token d'accès via le flux OAuth de la console développeur Zalo.

Remarque : traitez le token d'accès comme un mot de passe. Ne le partagez pas publiquement et conservez-le en lieu sûr.

Étape 2 — Configurer Zalo dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  1. Cliquez sur Enregistrer.
  2. Testez la connexion à l'aide du bouton Tester dans la liste des fournisseurs.

Important : Le token d'accès expire après env. 25 heures. Klacks ne le renouvelle pas automatiquement — vous devez le renouveler en externe via le flux refresh token de Zalo et le saisir à nouveau dans Klacks. Attention : le refresh token est à usage unique — chaque renouvellement fournit une nouvelle paire de tokens.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur Zalo configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les ID utilisateur Zalo — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement l'ID utilisateur Zalo enregistré du destinataire et utilise le fournisseur Zalo configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : L'ID utilisateur Zalo du destinataire doit être enregistré dans Klacks (sous Adresse → Coordonnées). Le destinataire doit avoir préalablement interagi avec l'Official Account (p. ex. suivre l'OA ou lui envoyer un message) — en dehors de la fenêtre d'interaction, Zalo rejette l'envoi.

Messages entrants

L'intégration Zalo ne prend pas en charge la réception — les réponses aux messages envoyés ne sont pas transmises à Klacks. La boîte de réception de messagerie n'affiche donc aucun message entrant pour ce fournisseur.
