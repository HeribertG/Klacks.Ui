Configurer Zalo

Conditions préalables

Pour envoyer et recevoir des messages via Zalo avec Klacks, vous avez besoin d'un Zalo Official Account et d'une application enregistrée dans le portail Zalo Developer. Zalo est le messageur dominant au Vietnam avec environ 75 millions d'utilisateurs.

Remarque : une vérification OA (Official Account) est requise pour envoyer des messages aux utilisateurs.

Étape 1 — Créer un Zalo Official Account et une application

  1. Créez un Official Account sur oa.zalo.me.
  2. Complétez le processus de vérification OA.
  3. Enregistrez une application dans le portail Zalo Developer (developers.zalo.me).
  4. Notez l'App-ID (App ID) dans les paramètres de l'application.
  5. Notez le Secret Key dans les paramètres de l'application.
  6. Notez l'OA-ID (Official Account ID) depuis le tableau de bord OA.

Étape 2 — Configurer Zalo dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  2. Testez la connexion à l'aide du bouton Tester dans la liste des fournisseurs.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur Zalo configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les numéros de téléphone — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement le numéro de téléphone du destinataire et utilise le fournisseur Zalo configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : Le destinataire doit avoir un numéro de mobile enregistré dans Klacks (sous Adresse → Coordonnées).

Étape 4 — Recevoir des messages entrants (Webhook)

Pour afficher les messages Zalo entrants dans Klacks, un webhook doit être configuré.

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Notez le secret du webhook généré automatiquement pour votre fournisseur Zalo.
  3. Configurez l'URL du webhook dans le portail Zalo Developer : 
    https://{votre-domaine}/api/messaging/webhook/zalo
  4. Les messages entrants apparaîtront désormais en temps réel dans la boîte de réception de messagerie.

Dépannage

ProblèmeCause possibleSolution
Le test de connexion échoue App-ID, Secret Key ou OA-ID incorrect Vérifiez les identifiants dans le portail Zalo Developer
Le message n'est pas livré OA non vérifié Assurez-vous que la vérification OA est terminée
Le destinataire ne reçoit pas le message Numéro de mobile non enregistré ou destinataire non utilisateur de Zalo Vérifiez si le destinataire utilise Zalo et que le numéro est correct
Les messages entrants manquent Webhook non configuré Vérifiez l'URL du webhook dans le portail Zalo Developer
Accès OA refusé Jeton d'accès expiré ou autorisations manquantes Renouvelez le jeton et vérifiez les autorisations de l'application dans le portail Developer
