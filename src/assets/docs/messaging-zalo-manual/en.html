Setting up Zalo Messaging

Prerequisites

To send messages via Zalo, you need a Zalo Official Account (OA) on oa.zalo.me and an app on developers.zalo.me. Zalo is the leading messenger in Vietnam.

Important: The Zalo integration is designed for sending only. In addition, Zalo platform restrictions apply:

  • The access token expires after approx. 25 hours and must be renewed outside of Klacks and re-entered.
  • Messages can only be sent to users who have previously interacted with the Official Account (interaction window).

Step 1 — Set up a Zalo Official Account and app

  1. Create an Official Account on oa.zalo.me.
  2. Create an app on developers.zalo.me.
  3. Link the Official Account to the app.
  4. Obtain an access token via the OAuth flow of the Zalo developer console.

Note: Treat the access token like a password. Do not share it publicly and store it securely.

Step 2 — Configure Zalo in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:
FieldDescriptionExample
NameUnique internal namezalo-oa
Display NameShown in the user interfaceZalo
Provider TypeSelect ZaloZalo
Access TokenThe token obtained via the OAuth flowzalo-oa-access-token...
OA IDThe ID of your Official Account (informational, used for identification)987654321...
EnabledTurns the provider on/offYes
  1. Click Save.
  2. Test the connection using the Test button in the provider list.

Important: The access token expires after approx. 25 hours. Klacks does not renew it automatically — you must renew it externally via Zalo's refresh token flow and re-enter it in Klacks. Note: the refresh token is single-use — each renewal yields a new token pair.

Step 3 — Send messages via the chatbot (Klacksy)

Once the Zalo provider is configured and enabled, the chatbot Klacksy can send messages. You do not need to know any Zalo user IDs — simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2:00 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Müller that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's stored Zalo user ID and uses the configured Zalo provider. The process is fully transparent for you — you work with names, Klacksy takes care of the rest.

Prerequisite: The recipient's Zalo user ID must be stored in Klacks (under Address → Contact Details). The recipient must have previously interacted with the Official Account (e.g. followed the OA or sent it a message) — outside the interaction window, Zalo rejects the message.

Incoming Messages

The Zalo integration does not support receiving — replies to sent messages are not transmitted to Klacks. The messaging inbox therefore does not show any incoming messages for this provider.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails Access token expired (approx. 25 hours validity) Renew the token via the refresh token flow and re-enter it
Message is not delivered User has not interacted with the Official Account The recipient must follow the OA or send it a message
Recipient not found Zalo user ID not stored Enter the user ID under Address → Contact Details
Token renewal fails Refresh token already used (single-use) Run the OAuth flow in the Zalo developer console again
Sending rejected with a permission error OA not linked to the app Check the link between the app and the Official Account on developers.zalo.me
