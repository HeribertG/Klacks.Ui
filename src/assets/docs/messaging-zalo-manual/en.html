Setting up Zalo

Prerequisites

To send and receive messages via Zalo through Klacks, you need a Zalo Official Account and a registered app in the Zalo Developer Portal. Zalo is the dominant messenger in Vietnam with approximately 75 million users.

Note: OA verification (Official Account) is required to send messages to users.

Step 1 — Create a Zalo Official Account and app

  1. Create an Official Account at oa.zalo.me.
  2. Complete the OA verification process.
  3. Register an app in the Zalo Developer Portal (developers.zalo.me).
  4. Note down the App ID from the app settings.
  5. Note down the Secret Key from the app settings.
  6. Note down the OA ID (Official Account ID) from the OA dashboard.

Step 2 — Configure Zalo in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:

EnabledTurns the provider on/offYes
  1. Click Save.
  2. Test the connection using the Test button in the provider list.

Step 3 — Send messages via the chatbot (Klacksy)

Once the Zalo provider is configured and enabled, the chatbot Klacksy can send messages. You don't need to know any phone numbers — simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Müller that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's phone number and uses the configured Zalo provider. The process is fully transparent to you — you work with names, Klacksy takes care of the rest.

Prerequisite: The recipient must have a mobile number stored in Klacks (under Address → Contact Details).

Step 4 — Receive incoming messages (Webhook)

To display incoming Zalo messages in Klacks, a webhook must be configured.

  1. Go to Settings → Messaging Providers.
  2. Note the automatically generated webhook secret of your Zalo provider.
  3. Configure the webhook URL in the Zalo Developer Portal: 
    https://{your-domain}/api/messaging/webhook/zalo
  4. Incoming messages will now appear in real time in the Messaging Inbox.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails App ID, Secret Key or OA ID incorrect Check the credentials in the Zalo Developer Portal
Message not delivered OA not verified Make sure the OA verification is completed
Recipient does not receive message Mobile number not registered or recipient not a Zalo user Check if the recipient uses Zalo and the number is correct
Incoming messages missing Webhook not configured Check the webhook URL in the Zalo Developer Portal
OA access denied Access token expired or permissions missing Renew the token and check the app permissions in the Developer Portal
