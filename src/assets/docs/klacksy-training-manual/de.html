Klacksy Training - Anleitung

Was ist das Training-Tool?

Das Training-Tool steuert die In-Page-Navigation des Chatbots Klacksy. Wenn ein Benutzer "Klacksy zeig mir die Adressen" sagt oder schreibt, navigiert Klacksy zur passenden Seite und scrollt zum entsprechenden Abschnitt.

Damit das funktioniert, braucht Klacksy fuer jeden Anker auf einer Seite eine Liste von Synonymen in jeder Sprache (z. B. "Adressen", "Kunden", "Kontakte" fuer das Ziel addresses).

Tab "Ziele"

Liste aller im Frontend gefundenen Anker (HTML-Attribute data-klacksy-target). Status-Filter:

  • pending: Anker existiert, aber noch keine Synonyme
  • generated: Synonyme wurden automatisch generiert, brauchen Pruefung
  • reviewed: Synonyme von einem Admin freigegeben
  • needs-review: Markiert fuer erneute Pruefung

Anklicken eines Ziels oeffnet den Synonym-Editor darunter. Dort koennen Synonyme hinzugefuegt, geloescht und mit "Als ueberprueft speichern" freigegeben werden.

Tab "Rueckmeldungen"

Zeigt User-Eingaben, die Klacksy nicht zuordnen konnte (kein passendes Synonym gefunden). Anhand dieser Liste laesst sich erkennen, welche Synonyme noch fehlen.

Tab "Metriken"

Uebersicht ueber alle Ziele nach Status. Hilft, den Trainings-Fortschritt zu verfolgen.

Build-Pipeline (CLI)

Wenn Templates neue data-klacksy-target-Anker bekommen haben, muessen das Manifest und die Initial-Synonyme regeneriert werden. Die folgenden Befehle laufen auch automatisch in CI und im Husky-Pre-Commit: 

cd C:\SourceCode\Klacks.Ui

# 1. Templates scannen → navigation-targets.json mit allen Anchors
npm run scan:targets

# 2a. Initial-Synonyme generieren (alle 4 Core + 22 Plugin-Locales, ~2.5 h)
npm run generate:synonyms

# 2b. Nur Core-Locales (de/en/fr/it) — schnell, ca. 9 min
npm run generate:synonyms -- --core-only

# 2c. Nur fehlende Plugin-Locales nachfuellen — ca. 45 min
npm run generate:synonyms -- --plugins-only

# 3. Wake-Word-Konsistenz pruefen
npm run wake-word-lint

Wichtig: Bei npm run muss -- stehen, damit die Optionen an das Skript weitergereicht werden. Ohne -- verschluckt npm das Flag und das Skript laeuft im Standard-Modus.

Alternative ohne npm: npx tsx tools/generate-synonyms.ts --core-only.

API-Key

Der LLM-API-Key wird in dieser Reihenfolge gesucht:

  1. Env-Variable SYNONYM_LLM_API_KEY
  2. DB-Tabelle llm_providers (Provider deepseek, is_enabled = true) — automatisch via psql-Aufruf
  3. Sonst Fehlermeldung

Standard-Provider ist DeepSeek. Anderer Provider via SYNONYM_LLM_PROVIDER_ID=anthropic (oder ein anderer eingerichteter LLM-Provider in den Settings).

Schritt 1 - scan:targets

Durchsucht alle Angular-Templates nach data-klacksy-target-Attributen und erzeugt das Manifest Application/Skills/Definitions/navigation-targets.json. Jeder neue Anker erscheint danach im Tab "Ziele" mit Status pending.

Schritt 2 - generate:synonyms

Erzeugt fuer jeden neuen Anker initiale Synonyme aus dem data-klacksy-label-key und der Kategorie. Status danach: generated (muss vom Admin reviewed werden).

Das Skript schreibt Manifest-Checkpoints alle 5 Targets, sodass ein Abbruch keine bereits generierten Daten verliert.

Schritt 3 - wake-word-lint

Prueft die Konsistenz der Wake-Word-Variante (Hallo Klacksy / Hey Klacksy / ...) ueber alle Sprachen. Verhindert, dass Synonyme das Wake-Word ueberschreiben.

Voice-Mode

Das Mikrofon-Symbol im Chat aktiviert den Voice-Mode. Sobald aktiv:

  • Mikrofon hoert mit, transkribiert kontinuierlich
  • Bei kurzer Stille → automatisches Senden der bisherigen Transkription

Wichtig: Sobald du in das Textfeld zu tippen beginnst, wird der Voice-Mode automatisch beendet — sonst wuerde das Mikrofon deinen getippten Text mit eigenen Transkriptionen ueberschreiben und vorzeitig senden.

Typischer Trainings-Loop

  1. Anker in Template ergaenzen: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. API neu starten (Cache wird beim Start neu eingelesen)
  4. Tab "Ziele" oeffnen → neue Targets erscheinen mit Status generated
  5. Synonyme pruefen/ergaenzen → "Als ueberprueft speichern" → Status reviewed
  6. Mit Klacksy testen, z. B. "Klacksy zeig mir die Adressen"
  7. Falls Klacksy nicht matcht → Tab "Rueckmeldungen" → fehlendes Synonym ergaenzen
  8. Tab "Metriken" ueberwachen, bis alles reviewed ist
