Addestramento Klacksy - Manuale

Cos'è lo strumento di addestramento?

Lo strumento di addestramento controlla la navigazione in-page del chatbot Klacksy. Quando un utente dice o scrive "Klacksy mostrami gli indirizzi", Klacksy naviga alla pagina corrispondente e scorre fino alla sezione pertinente.

Per funzionare, Klacksy ha bisogno di una lista di sinonimi in ogni lingua per ciascuna ancora di una pagina (ad esempio "indirizzi", "clienti", "contatti" per l'obiettivo addresses).

Scheda "Obiettivi"

Lista di tutte le ancore trovate nel frontend (attributo HTML data-klacksy-target). Filtro di stato:

  • pending: l'ancora esiste, nessun sinonimo ancora
  • generated: sinonimi generati automaticamente, da rivedere
  • reviewed: sinonimi approvati da un amministratore
  • needs-review: contrassegnato per nuova revisione

Cliccando su un obiettivo si apre l'editor dei sinonimi sottostante. I sinonimi possono essere aggiunti, rimossi e approvati con "Salva come rivisto".

Scheda "Feedback"

Mostra gli input degli utenti che Klacksy non è riuscito ad associare (nessun sinonimo corrispondente trovato). Questa lista aiuta a individuare i sinonimi mancanti.

Scheda "Metriche"

Panoramica di tutti gli obiettivi per stato. Aiuta a monitorare i progressi dell'addestramento.

Pipeline di build (CLI)

Quando i template ricevono nuove ancore data-klacksy-target, il manifest e i sinonimi iniziali devono essere rigenerati. I seguenti comandi vengono eseguiti automaticamente anche in CI e nel pre-commit Husky: 

cd C:\SourceCode\Klacks.Ui

# 1. Scansiona i template → navigation-targets.json con tutte le ancore
npm run scan:targets

# 2a. Genera tutti i sinonimi (4 core + 22 plugin locales, circa 2,5 h)
npm run generate:synonyms

# 2b. Solo locali core (de/en/fr/it) — veloce, circa 9 min
npm run generate:synonyms -- --core-only

# 2c. Compila le locali plugin mancanti — circa 45 min
npm run generate:synonyms -- --plugins-only

# 3. Verifica la coerenza della wake-word
npm run wake-word-lint

Importante: Con npm run è necessario aggiungere -- affinché le opzioni vengano inoltrate allo script. Senza, npm "divora" il flag e lo script viene eseguito in modalità predefinita.

Alternativa senza npm: npx tsx tools/generate-synonyms.ts --core-only.

Chiave API

La chiave API LLM viene risolta in questo ordine:

  1. Variabile d'ambiente SYNONYM_LLM_API_KEY
  2. Tabella DB llm_providers (provider deepseek, is_enabled = true) — automaticamente tramite chiamata psql
  3. Altrimenti viene generato un errore

Il provider predefinito è DeepSeek. Per usare un altro provider: SYNONYM_LLM_PROVIDER_ID=anthropic (o qualunque altro provider LLM configurato nelle impostazioni).

Passo 1 - scan:targets

Scansiona tutti i template Angular alla ricerca di attributi data-klacksy-target e crea il manifest Application/Skills/Definitions/navigation-targets.json. Ogni nuova ancora appare poi nella scheda "Obiettivi" con stato pending.

Passo 2 - generate:synonyms

Genera sinonimi iniziali per ciascuna nuova ancora a partire dalla data-klacksy-label-key e dalla categoria. Stato successivo: generated (deve essere rivisto dall'amministratore).

Lo script salva checkpoint del manifest ogni 5 obiettivi, in modo che un'interruzione non perda i dati già generati.

Passo 3 - wake-word-lint

Verifica la coerenza delle varianti della wake-word (Ciao Klacksy / Hey Klacksy / ...) in tutte le lingue. Impedisce ai sinonimi di sovrascrivere la wake-word.

Modalità vocale

L'icona del microfono nella chat attiva la modalità vocale. Una volta attiva:

  • Il microfono ascolta in continuo e trascrive
  • Dopo un breve silenzio → la trascrizione corrente viene inviata automaticamente

Importante: Non appena inizi a digitare nel campo di testo, la modalità vocale viene disattivata automaticamente — altrimenti il microfono sovrascriverebbe il testo digitato con la propria trascrizione e lo invierebbe prematuramente.

Tipico ciclo di addestramento

  1. Aggiungere un'ancora nel template: 
    <div data-klacksy-target="addresses"
     data-klacksy-label-key="nav.addresses"
     data-klacksy-route="/workplace/client">
  2. npm run scan:targets && npm run generate:synonyms
  3. Riavviare l'API (la cache viene riletta all'avvio)
  4. Aprire la scheda "Obiettivi" → i nuovi obiettivi appaiono con stato generated
  5. Verificare/aggiungere sinonimi → "Salva come rivisto" → stato reviewed
  6. Testare con Klacksy, ad esempio "Klacksy mostrami gli indirizzi"
  7. Se Klacksy non associa → scheda "Feedback" → aggiungere il sinonimo mancante
  8. Monitorare la scheda "Metriche" finché tutto è reviewed
