Configurer un bot Telegram

Conditions préalables

Pour envoyer et recevoir des messages Telegram via Klacks, vous avez besoin d'un bot Telegram. Les bots sont créés via le BotFather officiel et sont gratuits.

Étape 1 — Créer un bot Telegram

  1. Ouvrez Telegram et recherchez @BotFather.
  2. Démarrez une conversation avec le BotFather et envoyez la commande /newbot.
  3. Choisissez un nom pour votre bot (p. ex. Klacks Notifications).
  4. Choisissez un nom d'utilisateur pour le bot (doit se terminer par bot, p. ex. klacks_notify_bot).
  5. Le BotFather vous fournira un token de bot. Copiez ce token — il sera nécessaire à l'étape suivante.

Remarque : traitez le token de bot comme un mot de passe. Ne le partagez pas publiquement et conservez-le en lieu sûr.

Étape 2 — Configurer le bot dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  1. Cliquez sur Enregistrer.
  2. Testez la connexion à l'aide du bouton Tester dans la liste des fournisseurs.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le bot Telegram configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les identifiants de chat — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement le nom d'utilisateur Telegram du destinataire et utilise le bot configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : Le destinataire doit avoir un nom d'utilisateur Telegram enregistré dans Klacks (sous Adresse → Coordonnées).

Étape 4 — Recevoir des messages entrants (Webhook)

Pour afficher les messages Telegram entrants dans Klacks, un webhook doit être configuré.

  1. Assurez-vous que votre instance Klacks est accessible publiquement via HTTPS.
  2. Saisissez l'URL de webhook suivante dans les paramètres du fournisseur : 
    https://{votre-domaine}/api/messaging/webhook/telegram
  3. Klacks enregistre automatiquement le webhook auprès de Telegram dès que le fournisseur est enregistré et activé.
  4. Les messages entrants apparaîtront désormais en temps réel dans la boîte de réception de messagerie.

Dépannage

ProblèmeCause possibleSolution
Le test de connexion échoue Token de bot invalide Vérifiez le token auprès du BotFather avec /mybots
Le message n'est pas livré Le destinataire n'a pas démarré le bot Le destinataire doit ouvrir le bot dans Telegram et envoyer /start
Destinataire introuvable Nom d'utilisateur Telegram non enregistré Saisissez le nom d'utilisateur Telegram sous Adresse → Coordonnées
Les messages entrants manquent URL du webhook non accessible Vérifiez que votre domaine est accessible via HTTPS et que l'URL est correcte
L'enregistrement du webhook a échoué Pas de certificat SSL valide Telegram exige un certificat SSL valide (pas d'auto-signé)
