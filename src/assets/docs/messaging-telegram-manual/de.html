Telegram-Bot einrichten

Voraussetzungen

Um Telegram-Nachrichten über Klacks zu senden und zu empfangen, benötigen Sie einen Telegram-Bot. Bots werden über den offiziellen BotFather erstellt und sind kostenlos.

Schritt 1 — Telegram-Bot erstellen

  1. Öffnen Sie Telegram und suchen Sie nach @BotFather.
  2. Starten Sie einen Chat mit dem BotFather und senden Sie den Befehl /newbot.
  3. Vergeben Sie einen Namen für Ihren Bot (z.B. Klacks Benachrichtigungen).
  4. Vergeben Sie einen Benutzernamen für den Bot (muss auf bot enden, z.B. klacks_notify_bot).
  5. Der BotFather gibt Ihnen ein Bot Token aus. Kopieren Sie dieses Token — es wird im nächsten Schritt benötigt.

Hinweis: Behandeln Sie das Bot Token wie ein Passwort. Teilen Sie es nicht öffentlich und speichern Sie es sicher.

Schritt 2 — Bot in Klacks konfigurieren

  1. Navigieren Sie zu Einstellungen → Messaging-Anbieter.
  2. Klicken Sie auf Hinzufügen.
  3. Füllen Sie die Felder wie folgt aus:

  1. Klicken Sie auf Speichern.
  2. Testen Sie die Verbindung über den Test-Button in der Anbieter-Liste.

Schritt 3 — Nachrichten über den Chatbot (Klacksy) senden

Sobald der Telegram-Bot konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten versenden. Sie müssen keine Chat-IDs kennen — verwenden Sie einfach den Namen des Mitarbeiters oder Klienten: 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht: Die Schicht wurde getauscht."
"Benachrichtige Peter Müller, dass sein Dienst am Montag ausfällt."

Klacksy sucht automatisch den hinterlegten Telegram-Benutzernamen des Empfängers und verwendet den konfigurierten Bot. Der Versand ist für Sie vollständig transparent — Sie arbeiten mit Namen, Klacksy kümmert sich um den Rest.

Voraussetzung: Beim Empfänger muss ein Telegram-Benutzername in Klacks hinterlegt sein (unter Adresse → Kontaktdaten).

Schritt 4 — Eingehende Nachrichten empfangen (Webhook)

Um eingehende Telegram-Nachrichten in Klacks anzuzeigen, muss ein Webhook konfiguriert werden.

  1. Stellen Sie sicher, dass Ihre Klacks-Instanz über HTTPS öffentlich erreichbar ist.
  2. Tragen Sie die folgende Webhook-URL in den Anbieter-Einstellungen ein: 
    https://{ihre-domain}/api/messaging/webhook/telegram
  3. Klacks registriert den Webhook automatisch bei Telegram, sobald der Anbieter gespeichert und aktiviert wird.
  4. Eingehende Nachrichten erscheinen nun in Echtzeit in der Messaging-Inbox.
