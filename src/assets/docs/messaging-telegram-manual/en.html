Setting up a Telegram Bot

Prerequisites

To send and receive Telegram messages through Klacks, you need a Telegram bot. Bots are created via the official BotFather and are free of charge.

Step 1 — Create a Telegram bot

  1. Open Telegram and search for @BotFather.
  2. Start a chat with the BotFather and send the command /newbot.
  3. Choose a name for your bot (e.g. Klacks Notifications).
  4. Choose a username for the bot (must end with bot, e.g. klacks_notify_bot).
  5. The BotFather will provide a bot token. Copy this token — it will be needed in the next step.

Note: Treat the bot token like a password. Do not share it publicly and store it securely.

Step 2 — Configure the bot in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:
FieldDescriptionExample
NameUnique internal nametelegram-bot
Display NameShown in the user interfaceTelegram
Provider TypeSelect TelegramTelegram
Bot TokenThe token from BotFather123456:ABC-DEF1234ghIkl-zyx57W2v...
Webhook URLURL for incoming messages (see Step 4)https://example.com/api/messaging/webhook/telegram
EnabledTurns the provider on/offYes
  1. Click Save.
  2. Test the connection using the Test button in the provider list.

Step 3 — Send messages via the chatbot (Klacksy)

Once the Telegram bot is configured and enabled, the chatbot Klacksy can send messages. You don't need to know any chat IDs — simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Müller that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's Telegram username and uses the configured bot. The process is fully transparent to you — you work with names, Klacksy takes care of the rest.

Prerequisite: The recipient must have a Telegram username stored in Klacks (under Address → Contact Details).

Step 4 — Receive incoming messages (Webhook)

To display incoming Telegram messages in Klacks, a webhook must be configured.

  1. Make sure your Klacks instance is publicly reachable via HTTPS.
  2. Enter the following webhook URL in the provider settings: 
    https://{your-domain}/api/messaging/webhook/telegram
  3. Klacks automatically registers the webhook with Telegram once the provider is saved and enabled.
  4. Incoming messages will now appear in real time in the Messaging Inbox.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails Bot token invalid Check the token with BotFather using /mybots
Message not delivered Recipient has not started the bot The recipient must open the bot in Telegram and send /start
Recipient not found Telegram username not stored Enter the Telegram username under Address → Contact Details
Incoming messages missing Webhook URL not reachable Check that your domain is reachable via HTTPS and the URL is correct
Webhook registration failed No valid SSL certificate Telegram requires a valid SSL certificate (no self-signed)
