Configurer Slack

Conditions prealables

Pour envoyer et recevoir des messages via Slack avec Klacks, vous avez besoin d'un espace de travail Slack et d'une application Slack avec les autorisations appropriees.

Remarque : le plan gratuit de Slack permet jusqu'a 10 000 messages dans l'historique. Le plan Pro est recommande pour une utilisation complete de l'API.

Etape 1 — Creer une application Slack

  1. Ouvrez api.slack.com/apps et cliquez sur Create New App.
  2. Selectionnez From scratch et saisissez un nom (p. ex. Klacks Bot).
  3. Selectionnez l'espace de travail dans lequel l'application doit etre installee.
  4. Naviguez vers OAuth & Permissions et ajoutez les Bot Token Scopes suivants :
    • chat:write — pour envoyer des messages
    • users:read — pour lire les informations utilisateur
  5. Cliquez sur Install to Workspace et confirmez les autorisations.
  6. Notez le Bot User OAuth Token (commence par xoxb-).
  7. Naviguez vers Basic Information et notez le Signing Secret.

Etape 2 — Configurer Slack dans Klacks

  1. Accedez a Parametres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

Etape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur Slack configure et active, le chatbot Klacksy peut envoyer des messages via Slack. Utilisez le nom de l'employe ou un nom de canal : 

« Envoie un message a Max Muster : Votre rendez-vous est demain a 14h. »
« Envoie un message a Anna Beispiel : Le service a ete echange. »
« Poste dans #team-updates : Les plannings de la semaine prochaine sont prets. »

Klacksy recherche automatiquement l'utilisateur Slack associe et envoie le message. Pour les messages de canal, il poste directement dans le canal specifie. Le processus est entierement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition prealable : L'utilisateur Slack doit etre associe au contact Klacks correspondant (sous Adresse → Coordonnees). Pour les messages de canal, l'application doit etre ajoutee au canal concerne.

Etape 4 — Recevoir des messages entrants (Webhook)

Pour afficher les messages Slack entrants dans Klacks, les Event Subscriptions doivent etre configurees.

  1. Accedez a Parametres → Fournisseurs de messagerie.
  2. Notez le secret du webhook genere automatiquement pour votre fournisseur Slack.
  3. Configurez l'URL de requete dans l'application Slack sous Event Subscriptions : 
    https://{votre-domaine}/api/messaging/webhook/slack
  4. Les messages entrants apparaitront desormais en temps reel dans la boite de reception de messagerie.

Depannage

ProblemeCause possibleSolution
Le test de connexion echoue Bot Token ou Signing Secret incorrect Verifiez les identifiants dans la configuration de l'application Slack
Le message n'est pas livre Application non installee dans l'espace de travail Reinstallez l'application via OAuth & Permissions
Le destinataire ne recoit pas le message Utilisateur Slack non associe au contact Klacks Associez l'utilisateur Slack sous Adresse → Coordonnees
Le message de canal echoue Bot non ajoute au canal Ajoutez l'application au canal Slack (Canal → Integrations)
Les messages entrants manquent Event Subscriptions non configurees Verifiez l'URL de requete dans l'application Slack sous Event Subscriptions
