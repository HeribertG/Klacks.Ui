Configurer Slack

Conditions préalables

Pour envoyer et recevoir des messages via Slack avec Klacks, vous avez besoin d'un espace de travail Slack et d'une application Slack disposant des autorisations appropriées. Klacks utilise la Slack Web API pour l'envoi et l'Events API pour la réception.

Remarque : le plan Slack gratuit suffit pour l'intégration. Les applications Slack se créent sur api.slack.com et sont gratuites.

Étape 1 — Créer une application Slack

  1. Ouvrez api.slack.com/apps et cliquez sur Create New App.
  2. Choisissez From scratch et attribuez un nom (p. ex. Klacks Bot).
  3. Sélectionnez l'espace de travail dans lequel l'application doit être installée.
  4. Accédez à OAuth & Permissions et ajoutez les Bot Token Scopes suivants :
    • chat:write — pour envoyer des messages dans les canaux
    • im:write — pour envoyer des messages directs aux utilisateurs
  5. Cliquez sur Install to Workspace et confirmez les autorisations.
  6. Notez le Bot User OAuth Token (commence par xoxb-).
  7. Accédez à Basic Information et notez le Signing Secret.

Étape 2 — Configurer Slack dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur Slack configuré et activé, le chatbot Klacksy peut envoyer des messages via Slack. Utilisez le nom de l'employé ou un nom de canal : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Poste dans #team-updates : Les plannings de la semaine prochaine sont prêts. »

Le destinataire est identifié par un Channel ID (p. ex. C0123456789) ou un User ID (p. ex. U0123456789) — avec un User ID, un message direct est envoyé. Si aucun destinataire n'est indiqué, le canal par défaut configuré est utilisé. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : L'utilisateur Slack doit être associé au contact Klacks correspondant (sous Adresse → Coordonnées). Pour les messages de canal, le bot doit être invité dans le canal concerné (/invite @Klacks Bot).

Étape 4 — Recevoir des messages entrants (Events API)

Pour afficher les messages Slack entrants dans Klacks, l'Events API de l'application Slack doit être configurée. Enregistrez et activez le fournisseur dans Klacks avant de saisir la Request URL — Slack vérifie l'URL immédiatement avec une requête challenge, à laquelle Klacks répond automatiquement.

  1. Ouvrez votre application Slack sur api.slack.com/apps et accédez à Event Subscriptions.
  2. Activez Enable Events et saisissez comme Request URL l'URL de webhook affichée dans Klacks : 
    https://{votre-domaine}/api/messaging/webhook/slack
  3. Sous Subscribe to bot events, abonnez-vous aux événements message.im (messages directs) et message.channels (messages de canal).
  4. Enregistrez les modifications et, si vous y êtes invité, réinstallez l'application dans l'espace de travail.
  5. Les messages entrants apparaîtront désormais en temps réel dans la boîte de réception de messagerie. Klacks vérifie la signature de chaque requête à l'aide du Signing Secret enregistré.

Dépannage

ProblèmeCause possibleSolution
Le test de connexion échoue Token de bot invalide ou révoqué Vérifiez le token sous OAuth & Permissions et réinstallez l'application
Erreur channel_not_found ou not_in_channel Bot non ajouté au canal Invitez le bot dans le canal (/invite) ou vérifiez le Channel ID
Le message sans destinataire échoue Aucun canal par défaut configuré Saisissez un canal par défaut dans les paramètres du fournisseur
La vérification de la Request URL échoue Fournisseur non enregistré/activé dans Klacks ou Signing Secret incorrect Enregistrez et activez d'abord le fournisseur dans Klacks et vérifiez le Signing Secret
Les messages entrants manquent Événements de bot non abonnés Abonnez-vous à message.im et message.channels sous Event Subscriptions
