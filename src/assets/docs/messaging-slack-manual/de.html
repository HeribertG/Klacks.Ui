Slack einrichten

Voraussetzungen

Um Nachrichten über Slack mit Klacks zu senden und zu empfangen, benötigen Sie einen Slack-Workspace und eine Slack-App mit den entsprechenden Berechtigungen. Klacks verwendet die Slack Web API für den Versand und die Events API für den Empfang.

Hinweis: Der kostenlose Slack-Plan reicht für die Anbindung aus. Slack-Apps werden auf api.slack.com erstellt und sind kostenlos.

Schritt 1 — Slack-App erstellen

  1. Öffnen Sie api.slack.com/apps und klicken Sie auf Create New App.
  2. Wählen Sie From scratch und vergeben Sie einen Namen (z.B. Klacks Bot).
  3. Wählen Sie den Workspace aus, in dem die App installiert werden soll.
  4. Navigieren Sie zu OAuth & Permissions und fügen Sie folgende Bot Token Scopes hinzu:
    • chat:write — zum Senden von Nachrichten in Kanäle
    • im:write — zum Senden von Direktnachrichten an Benutzer
  5. Klicken Sie auf Install to Workspace und bestätigen Sie die Berechtigungen.
  6. Notieren Sie sich das Bot User OAuth Token (beginnt mit xoxb-).
  7. Navigieren Sie zu Basic Information und notieren Sie sich das Signing Secret.

Schritt 2 — Slack in Klacks konfigurieren

  1. Navigieren Sie zu Einstellungen → Messaging-Anbieter.
  2. Klicken Sie auf Hinzufügen.
  3. Füllen Sie die Felder wie folgt aus:

Schritt 3 — Nachrichten über den Chatbot (Klacksy) senden

Sobald der Slack-Anbieter konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten über Slack versenden. Verwenden Sie den Namen des Mitarbeiters oder einen Kanal-Namen: 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht: Die Schicht wurde getauscht."
"Poste in #team-updates: Die Dienstpläne für nächste Woche sind fertig."

Als Empfänger dient eine Channel-ID (z.B. C0123456789) oder eine User-ID (z.B. U0123456789) — bei einer User-ID wird eine Direktnachricht gesendet. Ist kein Empfänger angegeben, wird der konfigurierte Standard-Kanal verwendet. Der Versand ist für Sie vollständig transparent — Sie arbeiten mit Namen, Klacksy kümmert sich um den Rest.

Voraussetzung: Der Slack-Benutzer muss mit dem entsprechenden Klacks-Kontakt verknüpft sein (unter Adresse → Kontaktdaten). Für Kanal-Nachrichten muss der Bot in den jeweiligen Kanal eingeladen sein (/invite @Klacks Bot).

Schritt 4 — Eingehende Nachrichten empfangen (Events API)

Um eingehende Slack-Nachrichten in Klacks anzuzeigen, muss die Events API der Slack-App konfiguriert werden. Speichern und aktivieren Sie den Anbieter in Klacks, bevor Sie die Request-URL eintragen — Slack prüft die URL sofort mit einer Challenge-Anfrage, die Klacks automatisch beantwortet.

  1. Öffnen Sie Ihre Slack-App auf api.slack.com/apps und navigieren Sie zu Event Subscriptions.
  2. Aktivieren Sie Enable Events und tragen Sie als Request URL die in Klacks angezeigte Webhook-URL ein: 
    https://{ihre-domain}/api/messaging/webhook/slack
  3. Abonnieren Sie unter Subscribe to bot events die Events message.im (Direktnachrichten) und message.channels (Kanal-Nachrichten).
  4. Speichern Sie die Änderungen und installieren Sie die App bei Aufforderung erneut im Workspace.
  5. Eingehende Nachrichten erscheinen nun in Echtzeit in der Messaging-Inbox. Klacks prüft dabei die Signatur jeder Anfrage mit dem hinterlegten Signing-Secret.

Fehlerbehebung

ProblemMögliche UrsacheLösung
Verbindungstest schlägt fehl Bot-Token ungültig oder widerrufen Prüfen Sie das Token unter OAuth & Permissions und installieren Sie die App neu
Fehler channel_not_found oder not_in_channel Bot nicht zum Kanal hinzugefügt Laden Sie den Bot in den Kanal ein (/invite) oder prüfen Sie die Channel-ID
Nachricht ohne Empfänger schlägt fehl Kein Standard-Kanal konfiguriert Tragen Sie einen Standard-Kanal in den Anbieter-Einstellungen ein
Request-URL-Verifizierung schlägt fehl Anbieter in Klacks nicht gespeichert/aktiviert oder Signing-Secret falsch Speichern und aktivieren Sie den Anbieter zuerst in Klacks und prüfen Sie das Signing-Secret
Eingehende Nachrichten fehlen Bot-Events nicht abonniert Abonnieren Sie message.im und message.channels unter Event Subscriptions
