Slack einrichten

Voraussetzungen

Um Nachrichten uber Slack mit Klacks zu senden und zu empfangen, benotigen Sie einen Slack-Workspace und eine Slack App mit den entsprechenden Berechtigungen.

Hinweis: Der kostenlose Slack-Plan erlaubt bis zu 10.000 Nachrichten im Verlauf. Fur die volle API-Nutzung wird der Pro Plan empfohlen.

Schritt 1 — Slack App erstellen

  1. Offnen Sie api.slack.com/apps und klicken Sie auf Create New App.
  2. Wahlen Sie From scratch und vergeben Sie einen Namen (z.B. Klacks Bot).
  3. Wahlen Sie den Workspace aus, in dem die App installiert werden soll.
  4. Navigieren Sie zu OAuth & Permissions und fugen Sie folgende Bot Token Scopes hinzu:
    • chat:write — zum Senden von Nachrichten
    • users:read — zum Lesen von Benutzerinformationen
  5. Klicken Sie auf Install to Workspace und bestatigen Sie die Berechtigungen.
  6. Notieren Sie sich das Bot User OAuth Token (beginnt mit xoxb-).
  7. Navigieren Sie zu Basic Information und notieren Sie sich das Signing Secret.

Schritt 2 — Slack in Klacks konfigurieren

  1. Navigieren Sie zu Einstellungen → Messaging-Anbieter.
  2. Klicken Sie auf Hinzufugen.
  3. Fullen Sie die Felder wie folgt aus:

  2. Testen Sie die Verbindung uber den Test-Button in der Anbieter-Liste.

Schritt 3 — Nachrichten uber den Chatbot (Klacksy) senden

Sobald der Slack-Anbieter konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten uber Slack versenden. Verwenden Sie den Namen des Mitarbeiters oder einen Kanal-Namen: 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht: Die Schicht wurde getauscht."
"Poste in #team-updates: Die Dienstplane fur nachste Woche sind fertig."

Klacksy sucht automatisch den verknupften Slack-Benutzer und sendet die Nachricht. Bei Kanal-Nachrichten wird direkt in den angegebenen Kanal gepostet. Der Versand ist fur Sie vollstandig transparent — Sie arbeiten mit Namen, Klacksy kummert sich um den Rest.

Voraussetzung: Der Slack-Benutzer muss mit dem entsprechenden Klacks-Kontakt verknupft sein (unter Adresse → Kontaktdaten). Fur Kanal-Nachrichten muss die App dem jeweiligen Kanal hinzugefugt sein.

Schritt 4 — Eingehende Nachrichten empfangen (Webhook)

Um eingehende Slack-Nachrichten in Klacks anzuzeigen, mussen Event Subscriptions konfiguriert werden.

  1. Gehen Sie zu Einstellungen → Messaging-Anbieter.
  2. Notieren Sie das automatisch generierte Webhook-Secret Ihres Slack-Anbieters.
  3. Konfigurieren Sie in der Slack App unter Event Subscriptions die Request-URL: 
    https://{ihre-domain}/api/messaging/webhook/slack
  4. Eingehende Nachrichten erscheinen nun in Echtzeit in der Messaging-Inbox.

Fehlerbehebung

ProblemMogliche UrsacheLosung
Verbindungstest schlagt fehl Bot Token oder Signing Secret falsch Prufen Sie die Zugangsdaten in der Slack App-Konfiguration
Nachricht wird nicht zugestellt App nicht im Workspace installiert Installieren Sie die App erneut uber OAuth & Permissions
Empfanger erhalt keine Nachricht Slack-Benutzer nicht mit Klacks-Kontakt verknupft Verknupfen Sie den Slack-Benutzer unter Adresse → Kontaktdaten
Kanal-Nachricht schlagt fehl Bot nicht zum Kanal hinzugefugt Fugen Sie die App im Slack-Kanal hinzu (Kanal → Integrationen)
Eingehende Nachrichten fehlen Event Subscriptions nicht konfiguriert Prufen Sie die Request-URL in der Slack App unter Event Subscriptions
