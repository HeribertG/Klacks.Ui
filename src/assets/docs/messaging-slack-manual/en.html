Setting up Slack

Prerequisites

To send and receive messages via Slack through Klacks, you need a Slack workspace and a Slack App with the appropriate permissions.

Note: The free Slack plan allows up to 10,000 messages in history. The Pro plan is recommended for full API usage.

Step 1 — Create a Slack App

  1. Open api.slack.com/apps and click Create New App.
  2. Select From scratch and enter a name (e.g. Klacks Bot).
  3. Select the workspace where the app should be installed.
  4. Navigate to OAuth & Permissions and add the following Bot Token Scopes:
    • chat:write — to send messages
    • users:read — to read user information
  5. Click Install to Workspace and confirm the permissions.
  6. Note down the Bot User OAuth Token (starts with xoxb-).
  7. Navigate to Basic Information and note down the Signing Secret.

Step 2 — Configure Slack in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:

  1. Click Save.
  2. Test the connection using the Test button in the provider list.

Step 3 — Send messages via the chatbot (Klacksy)

Once the Slack provider is configured and enabled, the chatbot Klacksy can send messages via Slack. Use the name of the employee or a channel name: 

"Send a message to Max Muster: Your appointment is tomorrow at 2 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Post in #team-updates: The schedules for next week are ready."

Klacksy automatically looks up the linked Slack user and sends the message. For channel messages, it posts directly to the specified channel. The process is fully transparent to you — you work with names, Klacksy takes care of the rest.

Prerequisite: The Slack user must be linked to the corresponding Klacks contact (under Address → Contact Details). For channel messages, the app must be added to the respective channel.

Step 4 — Receive incoming messages (Webhook)

To display incoming Slack messages in Klacks, Event Subscriptions must be configured.

  1. Go to Settings → Messaging Providers.
  2. Note the automatically generated webhook secret of your Slack provider.
  3. Configure the request URL in the Slack App under Event Subscriptions: 
    https://{your-domain}/api/messaging/webhook/slack
  4. Incoming messages will now appear in real time in the Messaging Inbox.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails Bot Token or Signing Secret incorrect Check the credentials in the Slack App configuration
Message not delivered App not installed in workspace Reinstall the app via OAuth & Permissions
Recipient does not receive message Slack user not linked to Klacks contact Link the Slack user under Address → Contact Details
Channel message fails Bot not added to channel Add the app to the Slack channel (Channel → Integrations)
Incoming messages missing Event Subscriptions not configured Check the request URL in the Slack App under Event Subscriptions
