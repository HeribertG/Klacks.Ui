Compensatory rest

These settings control compensatory rest: if the statutory minimum rest period between two duties is not met, the missing rest must be made up as compensatory rest within a deadline. The values act as a company-wide default.

Compensatory rest enabled

Turns the compensatory rest check on or off. When disabled, the deadline is not applied.

  • Default: disabled.

Deadline (days)

Number of days within which compensatory rest must be granted after the minimum rest period was not met.

  • Integer value from 0 upwards.
  • Example: 14 means compensatory rest must take place within two weeks.

Source of the standard rest period

The standard rest-time threshold that triggers compensatory rest is derived from the minimum break in the scheduling defaults and can be edited there; it is not maintained in this card. Changing the minimum break there also affects compensatory rest.
