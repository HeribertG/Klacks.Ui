Repos compensateur

Ces paramètres régissent le repos compensateur : si la période de repos minimale légale entre deux services n'est pas respectée, le repos manquant doit être rattrapé sous forme de repos compensateur dans un délai imparti. Les valeurs s'appliquent comme valeur par défaut à l'échelle de l'entreprise.

Repos compensateur activé

Active ou désactive le contrôle du repos compensateur. Lorsque l'option est désactivée, le délai et la planification automatique ne sont pas appliqués.

  • Par défaut : désactivé.

Délai (jours)

Nombre de jours durant lesquels le repos compensateur doit être accordé après le non-respect de la période de repos minimale.

  • Valeur entière à partir de 0.
  • Exemple : 14 signifie que le repos compensateur doit avoir lieu dans les deux semaines.

Planifier automatiquement

Détermine si le système planifie de lui-même le repos compensateur dû dans le plan de service. Lorsque l'option est désactivée, le repos compensateur manquant est seulement signalé.

  • Par défaut : désactivé.

Origine de la période de repos standard

Le seuil de repos standard qui déclenche un repos compensateur est dérivé de la pause minimale dans les valeurs par défaut de planification et peut y être modifié ; il n'est pas géré dans cette carte. Modifier la pause minimale à cet endroit se répercute également sur le repos compensateur.
