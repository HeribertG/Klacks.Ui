Identity Provider Handbuch

Einleitung

Identity Provider ermöglichen die Authentifizierung von Benutzern über externe Verzeichnisdienste wie LDAP, Active Directory oder OAuth2/OpenID Connect.

Unterstützte Provider-Typen:

  • LDAP - Standard Lightweight Directory Access Protocol
  • Active Directory - Microsoft Active Directory
  • OAuth2 - OAuth 2.0 Authorization Framework
  • OpenID Connect - Identitätsschicht auf OAuth 2.0

Client-Import

Bei aktiviertem "Für Client-Import verwenden" werden folgende Daten importiert:

  • Name - sn (Nachname) oder displayName
  • Vorname - givenName
  • Titel - title (Jobtitel)
  • Firma - company
  • Adresse - street/streetAddress, postalCode, l (Stadt), st (Kanton), c (Land)
  • Geschlecht - Aus personalTitle (Herr/Frau) bei Active Directory

Hinweis: Bei OpenLDAP ist das Geschlecht standardmässig "Neutral" und kann manuell korrigiert werden.

Tipps

Synology NAS als LDAP-Server

Ein Synology NAS kann als LDAP-Server verwendet werden. Dazu muss das Paket "LDAP Server" oder ein Docker-Container mit OpenLDAP installiert werden.

  • Provider-Typ: "Active Directory" (für Fallback-Authentifizierung)
  • User Filter: (objectClass=inetOrgPerson)
  • Benutzer-DN-Format: cn=username,ou=users,dc=example,dc=com

Verbindung testen

Verwenden Sie den "Verbindung testen"-Button um die Konfiguration zu überprüfen. Bei erfolgreicher Verbindung werden die Anzahl gefundener Benutzer und einige Beispiel-Benutzernamen angezeigt.
