Manuale dei provider di identità

Introduzione

I provider di identità consentono l'autenticazione degli utenti tramite servizi di directory esterni come LDAP, Active Directory o OAuth2/OpenID Connect.

Tipi di provider supportati:

  • LDAP - Lightweight Directory Access Protocol standard
  • Active Directory - Microsoft Active Directory
  • OAuth2 - Framework di autorizzazione OAuth 2.0
  • OpenID Connect - Livello di identità su OAuth 2.0

Importazione clienti

Quando "Usa per importazione clienti" è abilitato, vengono importati i seguenti dati:

  • Nome - sn (cognome) o displayName
  • Nome - givenName
  • Titolo - title (titolo professionale)
  • Azienda - company
  • Indirizzo - street/streetAddress, postalCode, l (città), st (stato), c (paese)
  • Genere - Da personalTitle (Sig./Sig.ra) per Active Directory

Nota: Per OpenLDAP, il genere è predefinito "Neutro" e può essere corretto manualmente.

Suggerimenti

Synology NAS come server LDAP

Un NAS Synology può essere utilizzato come server LDAP. Installare il pacchetto "Server LDAP" o un container Docker con OpenLDAP.

  • Tipo provider: "Active Directory" (per autenticazione di fallback)
  • Filtro utente: (objectClass=inetOrgPerson)
  • Formato DN utente: cn=username,ou=users,dc=example,dc=com

Test connessione

Utilizzare il pulsante "Test connessione" per verificare la configurazione. In caso di connessione riuscita, verranno visualizzati il numero di utenti trovati e alcuni nomi utente di esempio.
