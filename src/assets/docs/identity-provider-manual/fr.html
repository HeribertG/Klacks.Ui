Manuel des fournisseurs d'identité

Introduction

Les fournisseurs d'identité permettent l'authentification des utilisateurs via des services d'annuaire externes tels que LDAP, Active Directory ou OAuth2/OpenID Connect.

Types de fournisseurs pris en charge:

  • LDAP - Lightweight Directory Access Protocol standard
  • Active Directory - Microsoft Active Directory
  • OAuth2 - Framework d'autorisation OAuth 2.0
  • OpenID Connect - Couche d'identité sur OAuth 2.0

Import de clients

Lorsque "Utiliser pour l'import de clients" est activé, les données suivantes sont importées:

  • Nom - sn (nom de famille) ou displayName
  • Prénom - givenName
  • Titre - title (titre professionnel)
  • Entreprise - company
  • Adresse - street/streetAddress, postalCode, l (ville), st (état), c (pays)
  • Genre - Depuis personalTitle (M./Mme) pour Active Directory

Note: Pour OpenLDAP, le genre est par défaut "Neutre" et peut être corrigé manuellement.

Conseils

Synology NAS comme serveur LDAP

Un NAS Synology peut être utilisé comme serveur LDAP. Installez le paquet "Serveur LDAP" ou un conteneur Docker avec OpenLDAP.

  • Type de fournisseur: "Active Directory" (pour l'authentification de secours)
  • Filtre utilisateur: (objectClass=inetOrgPerson)
  • Format DN utilisateur: cn=username,ou=users,dc=example,dc=com

Tester la connexion

Utilisez le bouton "Tester la connexion" pour vérifier la configuration. En cas de connexion réussie, le nombre d'utilisateurs trouvés et quelques noms d'utilisateurs exemples seront affichés.
