Identity Provider Manual

Introduction

Identity Providers enable user authentication through external directory services such as LDAP, Active Directory, or OAuth2/OpenID Connect.

Supported Provider Types:

  • LDAP - Standard Lightweight Directory Access Protocol
  • Active Directory - Microsoft Active Directory
  • OAuth2 - OAuth 2.0 Authorization Framework
  • OpenID Connect - Identity layer on top of OAuth 2.0

Client Import

When "Use for Client Import" is enabled, the following data is imported:

  • Name - sn (surname) or displayName
  • First Name - givenName
  • Title - title (job title)
  • Company - company
  • Address - street/streetAddress, postalCode, l (city), st (state), c (country)
  • Gender - From personalTitle (Mr/Mrs) for Active Directory

Note: For OpenLDAP, gender defaults to "Neutral" and can be manually corrected.

Tips

Synology NAS as LDAP Server

A Synology NAS can be used as an LDAP server. Install the "LDAP Server" package or a Docker container with OpenLDAP.

  • Provider Type: "Active Directory" (for fallback authentication)
  • User Filter: (objectClass=inetOrgPerson)
  • User DN Format: cn=username,ou=users,dc=example,dc=com

Test Connection

Use the "Test Connection" button to verify the configuration. On successful connection, the number of users found and some sample usernames will be displayed.
