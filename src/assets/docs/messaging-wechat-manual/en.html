Setting up WeChat

Prerequisites

To send and receive messages via WeChat through Klacks, you need a verified WeChat Official Account. WeChat is the dominant messenger in China with approximately 1.3 billion users.

Note: A Service Account is required for push messages. Verification of an Official Account can take several weeks.

Step 1 — Create a WeChat Official Account

  1. Sign up at mp.weixin.qq.com and create an Official Account.
  2. Select the account type Service Account (required for push messages).
  3. Complete the verification process (company documents required).
  4. Note down the App ID (AppID) from the developer settings.
  5. Note down the App Secret (AppSecret) from the developer settings.

Step 2 — Configure WeChat in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:
FieldDescriptionExample
NameUnique internal namewechat-main
Display NameShown in the user interfaceWeChat
Provider TypeSelect WeChatWeChat
App IDAppID from the WeChat developer settingswx1234567890abcdef
App SecretAppSecret from the WeChat developer settingsabc123def456...
EnabledTurns the provider on/offYes
  1. Click Save.
  2. Test the connection using the Test button in the provider list.

Step 3 — Send messages via the chatbot (Klacksy)

Once the WeChat provider is configured and enabled, the chatbot Klacksy can send messages. You don't need to know any IDs — simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Müller that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's WeChat OpenID and uses the configured WeChat provider. The process is fully transparent to you — you work with names, Klacksy takes care of the rest.

Prerequisite: The recipient must have a WeChat OpenID stored in Klacks (under Address → Contact Details).

Step 4 — Receive incoming messages (Webhook)

To display incoming WeChat messages in Klacks, a webhook must be configured.

  1. Go to Settings → Messaging Providers.
  2. Note the automatically generated webhook secret of your WeChat provider.
  3. Configure the webhook URL in the WeChat Official Account dashboard: 
    https://{your-domain}/api/messaging/webhook/wechat
  4. Incoming messages will now appear in real time in the Messaging Inbox.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails App ID or App Secret incorrect Check the credentials in the WeChat Official Account dashboard
Message not delivered Account not verified or not a Service Account Make sure the verification is completed and a Service Account is being used
Recipient does not receive message WeChat OpenID not stored or invalid Check if the recipient's OpenID is correctly stored in Klacks
Incoming messages missing Webhook not configured Check the webhook URL in the WeChat Official Account dashboard
Access token expired Token not automatically renewed Klacks renews the token automatically — check the App ID and App Secret
