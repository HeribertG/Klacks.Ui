Setting up WeChat Messaging

Prerequisites

To send messages via WeChat, you need a WeChat Official Account of type Service Account on mp.weixin.qq.com. WeChat is the dominant messenger in China.

Important: The WeChat integration is designed for sending only. In addition, WeChat platform restrictions apply:

  • Customer service messages only reach followers who have interacted with the account within the last 48 hours.
  • Verifying an Official Account involves high hurdles for companies outside China (including Chinese business documents); plan for this realistically.

Step 1 — Set up a WeChat Official Account

  1. Apply for a Service Account on mp.weixin.qq.com and complete the verification process.
  2. Open Settings → Basic Configuration and note down the AppID and AppSecret.
  3. Maintain the server IP whitelist: enter the public IP address of your Klacks server. Without this entry, WeChat rejects the token requests from Klacks.

Note: Treat the AppSecret like a password. Do not share it publicly and store it securely.

Step 2 — Configure WeChat in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:

  2. Test the connection using the Test button in the provider list.

Note: Klacks fetches the WeChat access token automatically and caches it — you do not need to maintain any token manually.

Step 3 — Send messages via the chatbot (Klacksy)

Once the WeChat provider is configured and enabled, the chatbot Klacksy can send messages. You do not need to know any OpenIDs — simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2:00 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Müller that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's stored OpenID and uses the configured WeChat provider. The process is fully transparent for you — you work with names, Klacksy takes care of the rest.

Prerequisite: The follower's OpenID must be stored in Klacks (under Address → Contact Details). The recipient must follow the Official Account and have interacted with it within the last 48 hours — otherwise WeChat rejects the message with the error "response out of time limit" (shown in the message log).

Incoming Messages

The WeChat integration does not support receiving — replies to sent messages are not transmitted to Klacks. The messaging inbox therefore does not show any incoming messages for this provider.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails App ID or App Secret wrong Check both values under Settings → Basic Configuration
Token request is rejected Klacks server IP not in the whitelist Enter the public IP of the Klacks server in the server IP whitelist
Error "response out of time limit" 48-hour window expired The follower must interact with the Official Account again (e.g. send a message)
Recipient not found OpenID not stored Enter the follower's OpenID under Address → Contact Details
