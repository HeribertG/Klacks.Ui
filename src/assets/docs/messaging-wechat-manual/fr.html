Configurer WeChat

Conditions préalables

Pour envoyer et recevoir des messages via WeChat avec Klacks, vous avez besoin d'un compte WeChat Official Account vérifié. WeChat est le messageur dominant en Chine avec environ 1,3 milliard d'utilisateurs.

Remarque : un Service Account est requis pour les messages push. La vérification d'un Official Account peut prendre plusieurs semaines.

Étape 1 — Créer un WeChat Official Account

  1. Inscrivez-vous sur mp.weixin.qq.com et créez un Official Account.
  2. Sélectionnez le type de compte Service Account (requis pour les messages push).
  3. Complétez le processus de vérification (documents d'entreprise requis).
  4. Notez l'App-ID (AppID) dans les paramètres développeur.
  5. Notez l'App-Secret (AppSecret) dans les paramètres développeur.

Étape 2 — Configurer WeChat dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  2. Testez la connexion à l'aide du bouton Tester dans la liste des fournisseurs.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur WeChat configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les identifiants — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement l'OpenID WeChat du destinataire et utilise le fournisseur WeChat configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : Le destinataire doit avoir un OpenID WeChat enregistré dans Klacks (sous Adresse → Coordonnées).

Étape 4 — Recevoir des messages entrants (Webhook)

Pour afficher les messages WeChat entrants dans Klacks, un webhook doit être configuré.

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Notez le secret du webhook généré automatiquement pour votre fournisseur WeChat.
  3. Configurez l'URL du webhook dans le tableau de bord WeChat Official Account : 
    https://{votre-domaine}/api/messaging/webhook/wechat
  4. Les messages entrants apparaîtront désormais en temps réel dans la boîte de réception de messagerie.

Dépannage

ProblèmeCause possibleSolution
Le test de connexion échoue App-ID ou App-Secret incorrect Vérifiez les identifiants dans le tableau de bord WeChat Official Account
Le message n'est pas livré Compte non vérifié ou pas un Service Account Assurez-vous que la vérification est terminée et qu'un Service Account est utilisé
Le destinataire ne reçoit pas le message OpenID WeChat non enregistré ou invalide Vérifiez si l'OpenID du destinataire est correctement enregistré dans Klacks
Les messages entrants manquent Webhook non configuré Vérifiez l'URL du webhook dans le tableau de bord WeChat Official Account
Jeton d'accès expiré Le jeton n'est pas renouvelé automatiquement Klacks renouvelle le jeton automatiquement — vérifiez l'App-ID et l'App-Secret
