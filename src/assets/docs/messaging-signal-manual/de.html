Signal-Messaging einrichten

Voraussetzungen

Um Signal-Nachrichten über Klacks zu senden und zu empfangen, benötigen Sie eine laufende Instanz der Signal-CLI REST API. Dabei handelt es sich um ein Open-Source-Projekt, das Signal über eine REST-Schnittstelle zugänglich macht.

  • Docker muss auf dem Server installiert sein
  • Eine Telefonnummer, die bei Signal registriert wird (dedizierte Nummer empfohlen)
  • Das Docker-Image: bbernhard/signal-cli-rest-api

Schritt 1 — Signal-CLI REST API einrichten

  1. Starten Sie den Signal-CLI-Container mit Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Registrieren Sie Ihre Telefonnummer über die API: 
    curl -X POST 'http://localhost:8080/v1/register/{nummer}' \
  -H 'Content-Type: application/json' \
  -d '{"captcha": "", "use_voice": false}'

    Ersetzen Sie {nummer} durch Ihre Nummer im Format +49171...

  3. Verifizieren Sie die Nummer mit dem empfangenen Code: 
    curl -X POST 'http://localhost:8080/v1/register/{nummer}/verify/{code}'
  4. Testen Sie die API mit einem Healthcheck: 
    curl http://localhost:8080/v1/about

Hinweis: Weitere Details zur Konfiguration finden Sie in der Signal-CLI REST API Dokumentation.

Schritt 2 — Signal in Klacks konfigurieren

  1. Navigieren Sie zu Einstellungen → Messaging-Anbieter.
  2. Klicken Sie auf Hinzufügen.
  3. Füllen Sie die Felder wie folgt aus:
FeldBeschreibungBeispiel
NameInterner eindeutiger Namesignal-main
AnzeigenameWird in der Oberfläche angezeigtSignal
AnbietertypWählen Sie SignalSignal
Signal-NummerDie registrierte Telefonnummer im internationalen Format+491711234567
API-URLURL der Signal-CLI REST APIhttp://localhost:8080
AktiviertSchaltet den Anbieter ein/ausJa
  1. Klicken Sie auf Speichern.
  2. Testen Sie die Verbindung über den Test-Button in der Anbieter-Liste.

Schritt 3 — Nachrichten über den Chatbot (Klacksy) senden

Sobald der Signal-Anbieter konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten versenden. Sie müssen keine Telefonnummern kennen — verwenden Sie einfach den Namen des Mitarbeiters oder Klienten: 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Signal-Nachricht: Die Schicht wurde getauscht."
"Benachrichtige Peter Müller, dass sein Dienst am Montag ausfällt."

Klacksy sucht automatisch die hinterlegte Telefonnummer des Empfängers und verwendet den konfigurierten Signal-Anbieter. Der Versand ist für Sie vollständig transparent — Sie arbeiten mit Namen, Klacksy kümmert sich um den Rest.

Voraussetzung: Beim Empfänger muss eine Mobilnummer in Klacks hinterlegt sein (unter Adresse → Kontaktdaten).

Schritt 4 — Eingehende Nachrichten empfangen (Webhook)

Um eingehende Signal-Nachrichten in Klacks anzuzeigen, muss ein Webhook konfiguriert werden.

  1. Gehen Sie zu Einstellungen → Messaging-Anbieter.
  2. Notieren Sie das automatisch generierte Webhook-Secret Ihres Signal-Anbieters.
  3. Konfigurieren Sie die Webhook-URL in der Signal-CLI REST API: 
    https://{ihre-domain}/api/messaging/webhook/signal
  4. Eingehende Nachrichten erscheinen nun in Echtzeit in der Messaging-Inbox.

Fehlerbehebung

ProblemMögliche UrsacheLösung
Verbindungstest schlägt fehl Signal-CLI REST API nicht erreichbar Prüfen Sie, ob der Docker-Container läuft: docker ps
Nachricht wird nicht zugestellt Signal-Nummer nicht registriert oder verifiziert Wiederholen Sie die Registrierung und Verifizierung über die API
Empfänger erhält keine Nachricht Empfänger nutzt kein Signal oder Nummer falsch Stellen Sie sicher, dass der Empfänger Signal installiert hat und die Nummer im Format +{Ländervorwahl}{Nummer} hinterlegt ist
Eingehende Nachrichten fehlen Webhook nicht konfiguriert Prüfen Sie die Webhook-URL in der Signal-CLI REST API Konfiguration
Container startet nicht Port 8080 bereits belegt Verwenden Sie einen anderen Port: -p 9090:8080 und passen Sie die API-URL in Klacks an
