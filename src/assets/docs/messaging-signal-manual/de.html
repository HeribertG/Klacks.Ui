Signal-Messaging einrichten

Voraussetzungen

Um Signal-Nachrichten über Klacks zu senden, benötigen Sie eine selbst gehostete Instanz der signal-cli-rest-api. Dabei handelt es sich um ein Open-Source-Projekt, das Signal über eine REST-Schnittstelle zugänglich macht.

  • Docker muss auf dem Server installiert sein
  • Eine Telefonnummer, die bei Signal registriert wird (dedizierte Nummer empfohlen)
  • Das Docker-Image: bbernhard/signal-cli-rest-api

Wichtig: Die Signal-Anbindung ist nur für den Versand ausgelegt. Eingehende Signal-Nachrichten werden in Klacks nicht empfangen.

Schritt 1 — signal-cli-rest-api einrichten

  1. Starten Sie den Container mit Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Verknüpfen Sie Ihre Signal-Nummer über das QR-Link-Verfahren: Öffnen Sie im Browser 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    und scannen Sie den angezeigten QR-Code mit der Signal-App auf dem Telefon, auf dem die Nummer registriert ist (Einstellungen → Gekoppelte Geräte → Gerät koppeln). Der Container wird damit als Zweitgerät verknüpft.
  3. Alternativ können Sie die Nummer eigenständig über die API registrieren — Details dazu finden Sie in der Dokumentation des Projekts.
  4. Testen Sie die API mit einem Healthcheck: 
    curl http://localhost:8080/v1/about

Hinweis: Weitere Details zur Konfiguration finden Sie in der signal-cli-rest-api Dokumentation.

Schritt 2 — Signal in Klacks konfigurieren

  1. Navigieren Sie zu Einstellungen → Messaging-Anbieter.
  2. Klicken Sie auf Hinzufügen.
  3. Füllen Sie die Felder wie folgt aus:

  1. Klicken Sie auf Speichern.
  2. Testen Sie die Verbindung über den Test-Button in der Anbieter-Liste. Der Test prüft, ob die angegebene Nummer im Container registriert ist.

Hinweis: Klacks versendet Nachrichten über den Endpunkt POST /v2/send des Containers.

Schritt 3 — Nachrichten über den Chatbot (Klacksy) senden

Sobald der Signal-Anbieter konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten versenden. Sie müssen keine Telefonnummern kennen — verwenden Sie einfach den Namen des Mitarbeiters oder Klienten: 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Signal-Nachricht: Die Schicht wurde getauscht."
"Benachrichtige Peter Müller, dass sein Dienst am Montag ausfällt."

Klacksy sucht automatisch die hinterlegte Mobilnummer des Empfängers und verwendet den konfigurierten Signal-Anbieter. Der Versand ist für Sie vollständig transparent — Sie arbeiten mit Namen, Klacksy kümmert sich um den Rest.

Voraussetzung: Beim Empfänger muss eine Mobilnummer in Klacks hinterlegt sein (unter Adresse → Kontaktdaten), im internationalen Format (z.B. +41791234567). Auch bei Broadcast-Nachrichten greift der Signal-Versand auf die hinterlegte Mobilnummer zurück.

Eingehende Nachrichten

Die Signal-Anbindung unterstützt keinen Empfang — Antworten auf versendete Nachrichten werden nicht an Klacks übertragen. Die Messaging-Inbox zeigt für diesen Anbieter daher keine eingehenden Nachrichten an.

Fehlerbehebung

Verbindungstest schlägt fehl Container nicht erreichbar Prüfen Sie, ob der Docker-Container läuft (docker ps) und ob die API-URL korrekt ist
Verbindungstest schlägt fehl Nummer nicht im Container registriert Wiederholen Sie die Verknüpfung über das QR-Link-Verfahren
Nachricht wird nicht zugestellt Empfänger nutzt kein Signal oder Nummer falsch Stellen Sie sicher, dass der Empfänger Signal installiert hat und die Nummer im Format +{Ländervorwahl}{Nummer} hinterlegt ist
