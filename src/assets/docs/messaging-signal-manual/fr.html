Configurer la messagerie Signal

Conditions préalables

Pour envoyer et recevoir des messages Signal via Klacks, vous avez besoin d'une instance en cours d'exécution de la Signal-CLI REST API. Il s'agit d'un projet open source qui rend Signal accessible via une interface REST.

  • Docker doit être installé sur le serveur
  • Un numéro de téléphone à enregistrer auprès de Signal (un numéro dédié est recommandé)
  • L'image Docker : bbernhard/signal-cli-rest-api

Étape 1 — Installer la Signal-CLI REST API

  1. Démarrez le conteneur Signal-CLI avec Docker : 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Enregistrez votre numéro de téléphone via l'API : 
    curl -X POST 'http://localhost:8080/v1/register/{numéro}' \
  -H 'Content-Type: application/json' \
  -d '{"captcha": "", "use_voice": false}'

    Remplacez {numéro} par votre numéro au format +33612...

  3. Vérifiez le numéro avec le code reçu : 
    curl -X POST 'http://localhost:8080/v1/register/{numéro}/verify/{code}'
  4. Testez l'API avec un contrôle de disponibilité : 
    curl http://localhost:8080/v1/about

Remarque : Pour plus de détails sur la configuration, consultez la documentation de Signal-CLI REST API.

Étape 2 — Configurer Signal dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  1. Cliquez sur Enregistrer.
  2. Testez la connexion à l'aide du bouton Test dans la liste des fournisseurs.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur Signal configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les numéros de téléphone — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h00. »
« Envoie à Anna Beispiel un message Signal : Le service a été échangé. »
« Informe Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement le numéro de téléphone du destinataire et utilise le fournisseur Signal configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : Le destinataire doit avoir un numéro de portable enregistré dans Klacks (sous Adresse → Coordonnées).

Étape 4 — Recevoir des messages entrants (Webhook)

Pour afficher les messages Signal entrants dans Klacks, un webhook doit être configuré.

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Notez le secret du webhook généré automatiquement pour votre fournisseur Signal.
  3. Configurez l'URL du webhook dans la Signal-CLI REST API : 
    https://{votre-domaine}/api/messaging/webhook/signal
  4. Les messages entrants apparaîtront désormais en temps réel dans la Boîte de réception.

Dépannage

ProblèmeCause possibleSolution
Le test de connexion échoue Signal-CLI REST API inaccessible Vérifiez que le conteneur Docker est en cours d'exécution : docker ps
Le message n'est pas livré Numéro Signal non enregistré ou non vérifié Répétez l'enregistrement et la vérification via l'API
Le destinataire ne reçoit pas le message Le destinataire n'utilise pas Signal ou le numéro est incorrect Assurez-vous que le destinataire a installé Signal et que le numéro est au format +{indicatif pays}{numéro}
Messages entrants manquants Webhook non configuré Vérifiez l'URL du webhook dans la configuration de Signal-CLI REST API
Le conteneur ne démarre pas Port 8080 déjà utilisé Utilisez un autre port : -p 9090:8080 et mettez à jour l'URL de l'API dans Klacks
