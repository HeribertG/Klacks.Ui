Configurer la messagerie Signal

Conditions préalables

Pour envoyer des messages Signal via Klacks, vous avez besoin d'une instance auto-hébergée de la signal-cli-rest-api. Il s'agit d'un projet open source qui rend Signal accessible via une interface REST.

  • Docker doit être installé sur le serveur
  • Un numéro de téléphone enregistré auprès de Signal (numéro dédié recommandé)
  • L'image Docker : bbernhard/signal-cli-rest-api

Important : L'intégration Signal est conçue uniquement pour l'envoi. Les messages Signal entrants ne sont pas reçus dans Klacks.

Étape 1 — Mettre en place la signal-cli-rest-api

  1. Démarrez le conteneur avec Docker : 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Liez votre numéro Signal via la méthode du lien QR : ouvrez dans le navigateur 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    et scannez le code QR affiché avec l'application Signal sur le téléphone où le numéro est enregistré (Paramètres → Appareils liés → Lier un nouvel appareil). Le conteneur est ainsi lié comme appareil secondaire.
  3. Vous pouvez également enregistrer le numéro de manière autonome via l'API — consultez la documentation du projet pour plus de détails.
  4. Testez l'API avec un contrôle de santé : 
    curl http://localhost:8080/v1/about

Remarque : vous trouverez plus de détails sur la configuration dans la documentation de la signal-cli-rest-api.

Étape 2 — Configurer Signal dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  1. Cliquez sur Enregistrer.
  2. Testez la connexion à l'aide du bouton Tester dans la liste des fournisseurs. Le test vérifie si le numéro indiqué est enregistré dans le conteneur.

Remarque : Klacks envoie les messages via le point de terminaison POST /v2/send du conteneur.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur Signal configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les numéros de téléphone — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message Signal à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement le numéro de mobile enregistré du destinataire et utilise le fournisseur Signal configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : Le destinataire doit avoir un numéro de mobile enregistré dans Klacks (sous Adresse → Coordonnées), au format international (p. ex. +41791234567). Les messages de diffusion utilisent également le numéro de mobile enregistré pour l'envoi via Signal.

Messages entrants

L'intégration Signal ne prend pas en charge la réception — les réponses aux messages envoyés ne sont pas transmises à Klacks. La boîte de réception de messagerie n'affiche donc aucun message entrant pour ce fournisseur.

Dépannage

ProblèmeCause possibleSolution
Le test de connexion échoue Conteneur inaccessible Vérifiez que le conteneur Docker est en cours d'exécution (docker ps) et que l'URL de l'API est correcte
Le test de connexion échoue Numéro non enregistré dans le conteneur Répétez la liaison via la méthode du lien QR
Le message n'est pas livré Le destinataire n'utilise pas Signal ou le numéro est incorrect Assurez-vous que le destinataire a installé Signal et que le numéro est enregistré au format +{indicatif pays}{numéro}
Liaison perdue L'appareil a été dissocié dans l'application Signal Liez à nouveau le conteneur via le lien QR
Le conteneur ne démarre pas Port 8080 déjà occupé Utilisez un autre port : -p 9090:8080 et adaptez l'URL de l'API dans Klacks
