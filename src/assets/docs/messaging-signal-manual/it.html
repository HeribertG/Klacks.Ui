Configurare la messaggistica Signal

Prerequisiti

Per inviare messaggi Signal tramite Klacks, è necessaria un'istanza self-hosted della signal-cli-rest-api. Si tratta di un progetto open source che rende Signal accessibile tramite un'interfaccia REST.

  • Docker deve essere installato sul server
  • Un numero di telefono registrato su Signal (si consiglia un numero dedicato)
  • L'immagine Docker: bbernhard/signal-cli-rest-api

Importante: l'integrazione Signal è concepita solo per l'invio. I messaggi Signal in arrivo non vengono ricevuti in Klacks.

Passo 1 — Configurare la signal-cli-rest-api

  1. Avviare il container con Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Collegare il proprio numero Signal tramite il metodo del link QR: aprire nel browser 
    http://localhost:8080/v1/qrcodelink?device_name=klacks
    e scansionare il codice QR visualizzato con l'app Signal sul telefono su cui è registrato il numero (Impostazioni → Dispositivi collegati → Collega nuovo dispositivo). Il container viene così collegato come dispositivo secondario.
  3. In alternativa è possibile registrare il numero in modo autonomo tramite l'API — per i dettagli consultare la documentazione del progetto.
  4. Testare l'API con un controllo di funzionamento: 
    curl http://localhost:8080/v1/about

Nota: ulteriori dettagli sulla configurazione sono disponibili nella documentazione della signal-cli-rest-api.

Passo 2 — Configurare Signal in Klacks

  1. Navigare su Impostazioni → Fornitori di messaggistica.
  2. Fare clic su Aggiungi.
  3. Compilare i campi come segue:
CampoDescrizioneEsempio
NomeNome interno univocosignal-main
Nome visualizzatoMostrato nell'interfaccia utenteSignal
Tipo di fornitoreSelezionare SignalSignal
Numero SignalIl numero di telefono registrato in formato internazionale+41791234567
URL API Signal CLIURL del container signal-cli-rest-api. Se il container gira sullo stesso server di Klacks, è consentito http://localhost:8080.http://localhost:8080
AttivatoAttiva o disattiva il fornitoreSì
  1. Fare clic su Salva.
  2. Testare la connessione tramite il pulsante Test nell'elenco dei fornitori. Il test verifica se il numero indicato è registrato nel container.

Nota: Klacks invia i messaggi tramite l'endpoint POST /v2/send del container.

Passo 3 — Inviare messaggi tramite il chatbot (Klacksy)

Una volta configurato e attivato il fornitore Signal, il chatbot Klacksy può inviare messaggi. Non è necessario conoscere i numeri di telefono — basta usare il nome del dipendente o del cliente: 

"Invia un messaggio a Max Muster: Il suo appuntamento è domani alle 14:00."
"Manda un messaggio Signal a Anna Beispiel: Il turno è stato scambiato."
"Avvisa Peter Müller che il suo turno di lunedì è annullato."

Klacksy cerca automaticamente il numero di cellulare registrato del destinatario e utilizza il fornitore Signal configurato. Il processo è completamente trasparente per voi — lavorate con i nomi, Klacksy si occupa del resto.

Prerequisito: Il destinatario deve avere un numero di cellulare registrato in Klacks (sotto Indirizzo → Dati di contatto), in formato internazionale (ad es. +41791234567). Anche i messaggi broadcast utilizzano il numero di cellulare registrato per l'invio tramite Signal.

Messaggi in arrivo

L'integrazione Signal non supporta la ricezione — le risposte ai messaggi inviati non vengono trasmesse a Klacks. La casella di messaggistica non mostra quindi messaggi in arrivo per questo fornitore.

Risoluzione dei problemi

ProblemaPossibile causaSoluzione
Il test di connessione fallisce Container non raggiungibile Verificare che il container Docker sia in esecuzione (docker ps) e che l'URL dell'API sia corretto
Il test di connessione fallisce Numero non registrato nel container Ripetere il collegamento tramite il metodo del link QR
Il messaggio non viene consegnato Il destinatario non usa Signal o il numero è errato Assicurarsi che il destinatario abbia installato Signal e che il numero sia registrato nel formato +{prefisso paese}{numero}
Collegamento perso Il dispositivo è stato scollegato nell'app Signal Collegare nuovamente il container tramite il link QR
Il container non si avvia Porta 8080 già occupata Utilizzare un'altra porta: -p 9090:8080 e adattare l'URL dell'API in Klacks
