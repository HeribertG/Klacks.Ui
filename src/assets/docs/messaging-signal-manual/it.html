Configurare la messaggistica Signal

Prerequisiti

Per inviare e ricevere messaggi Signal tramite Klacks, è necessaria un'istanza in esecuzione della Signal-CLI REST API. Si tratta di un progetto open source che rende Signal accessibile tramite un'interfaccia REST.

  • Docker deve essere installato sul server
  • Un numero di telefono da registrare con Signal (si consiglia un numero dedicato)
  • L'immagine Docker: bbernhard/signal-cli-rest-api

Passaggio 1 — Installare la Signal-CLI REST API

  1. Avviare il contenitore Signal-CLI con Docker: 
    docker run -d --name signal-cli-rest-api \
  --restart=unless-stopped \
  -p 8080:8080 \
  -v signal-cli-config:/home/.local/share/signal-cli \
  -e MODE=normal \
  bbernhard/signal-cli-rest-api
  2. Registrare il numero di telefono tramite l'API: 
    curl -X POST 'http://localhost:8080/v1/register/{numero}' \
  -H 'Content-Type: application/json' \
  -d '{"captcha": "", "use_voice": false}'

    Sostituire {numero} con il proprio numero nel formato +39347...

  3. Verificare il numero con il codice ricevuto: 
    curl -X POST 'http://localhost:8080/v1/register/{numero}/verify/{codice}'
  4. Testare l'API con un controllo di disponibilità: 
    curl http://localhost:8080/v1/about

Nota: Per ulteriori dettagli sulla configurazione, consultare la documentazione di Signal-CLI REST API.

Passaggio 2 — Configurare Signal in Klacks

  1. Accedere a Impostazioni → Provider di messaggistica.
  2. Fare clic su Aggiungi.
  3. Compilare i campi come segue:
CampoDescrizioneEsempio
NomeNome interno univocosignal-main
Nome visualizzatoMostrato nell'interfaccia utenteSignal
Tipo di providerSelezionare SignalSignal
Numero SignalIl numero di telefono registrato in formato internazionale+393471234567
URL APIURL della Signal-CLI REST APIhttp://localhost:8080
AttivatoAttiva/disattiva il providerSì
  1. Fare clic su Salva.
  2. Testare la connessione tramite il pulsante Test nell'elenco dei provider.

Passaggio 3 — Inviare messaggi tramite il chatbot (Klacksy)

Una volta configurato e attivato il provider Signal, il chatbot Klacksy può inviare messaggi. Non è necessario conoscere i numeri di telefono — è sufficiente utilizzare il nome del dipendente o del cliente: 

"Invia un messaggio a Max Muster: Il suo appuntamento è domani alle 14:00."
"Manda ad Anna Beispiel un messaggio Signal: Il turno è stato scambiato."
"Avvisa Peter Müller che il suo turno di lunedì è annullato."

Klacksy cerca automaticamente il numero di telefono del destinatario e utilizza il provider Signal configurato. Il processo è completamente trasparente — si lavora con i nomi, Klacksy si occupa del resto.

Prerequisito: Il destinatario deve avere un numero di cellulare registrato in Klacks (sotto Indirizzo → Dati di contatto).

Passaggio 4 — Ricevere messaggi in arrivo (Webhook)

Per visualizzare i messaggi Signal in arrivo in Klacks, è necessario configurare un webhook.

  1. Accedere a Impostazioni → Provider di messaggistica.
  2. Annotare il segreto del webhook generato automaticamente per il provider Signal.
  3. Configurare l'URL del webhook nella Signal-CLI REST API: 
    https://{vostro-dominio}/api/messaging/webhook/signal
  4. I messaggi in arrivo appariranno ora in tempo reale nella Posta in arrivo.

Risoluzione dei problemi

ProblemaPossibile causaSoluzione
Il test di connessione fallisce Signal-CLI REST API non raggiungibile Verificare che il contenitore Docker sia in esecuzione: docker ps
Il messaggio non viene consegnato Numero Signal non registrato o non verificato Ripetere la registrazione e la verifica tramite l'API
Il destinatario non riceve il messaggio Il destinatario non utilizza Signal o il numero è errato Assicurarsi che il destinatario abbia installato Signal e che il numero sia nel formato +{prefisso paese}{numero}
Messaggi in arrivo mancanti Webhook non configurato Verificare l'URL del webhook nella configurazione di Signal-CLI REST API
Il contenitore non si avvia Porta 8080 già in uso Utilizzare un'altra porta: -p 9090:8080 e aggiornare l'URL API in Klacks
