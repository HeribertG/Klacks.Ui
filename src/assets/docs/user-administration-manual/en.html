User Administration – Manual

What is user administration?

This page manages the login accounts (system users) that people use to sign in to Klacks. This is not the same as employee or address management – a login account can, but doesn't have to, be linked to an employee.

Adding a user

  • + Add User opens the creation dialog.
  • First and last name (at least 2 characters each) automatically generate a suggested username.
  • The email address is required and must contain an @ character.
  • Saving is only possible once all fields are filled in validly.
  • A password is generated automatically when the account is created. To let the person set their own password, use Reset Password in their row afterwards.

Rights: Supervisor & Admin

  • Supervisor – may create, edit and delete addresses, groups, contracts, absences and shifts, and may approve a day or group in the schedule and revoke that approval again. Simply confirming individual working times, on the other hand, requires no special role.
  • Admin – in addition to everything Supervisor can do: access to all settings (including user administration itself), can close and reopen periods, and can manage specially protected areas such as identity providers, reports and calendar rules. Admin rights automatically include supervisor rights.
  • Changes to rights take effect immediately when the dropdown is switched, without a separate save click.

Editing a user

Double-clicking a name row opens the edit dialog. There, the username can be changed afterwards – unlike when creating a user, where it is only shown as a suggestion.

Resetting a password

The Reset Password link in a user's row sends an email to the stored address, letting the person set a new password themselves.

Deleting a user

The trash icon removes a login account permanently, after confirmation in the delete dialog.

Your own account

The currently signed-in user is also shown in the list, but cannot be edited, have their rights changed, or be deleted there – these actions are disabled for your own row.
