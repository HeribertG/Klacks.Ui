Manuale Script Macro

Introduzione

L'editor di macro permette di scrivere script che servono come base di calcolo per servizi, impieghi ecc.

Esempi di applicazione:

  • Calcolo esatto delle ore per ferie o servizio militare in base al grado di occupazione
  • Calcolo dei supplementi per lavoro notturno, fine settimana e festivi
  • Adattamento flessibile a nuove esigenze

Nota: L'interprete di script viene eseguito in un ambiente sandbox sicuro senza accesso al file system o alla rete. Non è possibile eseguire codice dannoso.

Variabili e Costanti

Tutte le variabili e costanti sono senza tipo.

CONST PI = 3.1415
DIM a, b, c
IMPORT importo, sconto

Strutture di Controllo

Importante: Le parole chiave come ENDIF, ENDFUNCTION, ENDSUB devono essere scritte come unica parola (non END IF).

IF-THEN-ELSE

IF x > 10 THEN
    MESSAGE 1, "grande"
ELSEIF x > 5 THEN
    MESSAGE 1, "medio"
ELSE
    MESSAGE 1, "piccolo"
ENDIF

IF su una riga

IF x > 10 THEN MESSAGE 1, "grande" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        MESSAGE 1, "Fine settimana"
    CASE 1, 2, 3, 4, 5
        MESSAGE 1, "Giorno lavorativo"
    CASE ELSE
        MESSAGE 1, "Sconosciuto"
END SELECT

Ciclo FOR-NEXT

FOR i = 1 TO 10
    somma += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

Ciclo DO-LOOP

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Funzioni e Procedure

Importante: Le funzioni (FUNCTION) e le procedure (SUB) devono essere definite sopra la prima chiamata. L'interprete legge il codice dall'alto verso il basso – una funzione o procedura è nota solo dopo che la sua definizione è stata elaborata.

SUB (Procedura senza valore di ritorno)

SUB calcola(a, b)
    IF a = b THEN EXIT SUB ENDIF
    MESSAGE 1, a + b
ENDSUB

FUNCTION (Funzione con valore di ritorno)

FUNCTION raddoppia(x)
    raddoppia = x * 2
ENDFUNCTION

DIM risultato
risultato = raddoppia(21)
MESSAGE 1, risultato

Esempio: Calcolo Supplementi

Calcola i supplementi per notte, festivi e fine settimana con gestione corretta dei turni che attraversano mezzanotte (divisione in segmenti).

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WeekendRate

FUNCTION CalcSegment(StartTime, EndTime, HolidayFlag, WeekdayNum)
    DIM SegmentHours, NightHours, NonNightHours
    DIM NRate, DRate, HasHoliday, HasWeekend

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap("23:00", "06:00", StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    HasWeekend = WeekdayNum = 6 OrElse WeekdayNum = 7

    NRate = 0
    IF NightHours > 0 THEN NRate = NightRate ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN NRate = HolidayRate ENDIF
    IF HasWeekend AndAlso WeekendRate > NRate THEN NRate = WeekendRate ENDIF

    DRate = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN DRate = HolidayRate ENDIF
    IF HasWeekend AndAlso WeekendRate > DRate THEN DRate = WeekendRate ENDIF

    CalcSegment = NightHours * NRate + NonNightHours * DRate
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    TotalBonus = CalcSegment(FromHour, "00:00", Holiday, Weekday)
    TotalBonus = TotalBonus + CalcSegment("00:00", UntilHour, HolidayNextDay, WeekdayNextDay)
ELSE
    TotalBonus = CalcSegment(FromHour, UntilHour, Holiday, Weekday)
ENDIF

MESSAGE 1, Round(TotalBonus, 2)

Spiegazione

  • Divisione in segmenti: I turni che attraversano mezzanotte (es: 22:00-06:00) vengono divisi in due segmenti
  • CalcSegment: Calcola il supplemento per un segmento considerando i tassi notturni, festivi e di fine settimana
  • Tasso più alto: Utilizza sempre il supplemento più alto applicabile (notte vs. festivo vs. fine settimana)
  • HolidayNextDay: Considera se il giorno successivo è festivo (importante per i turni notturni)
