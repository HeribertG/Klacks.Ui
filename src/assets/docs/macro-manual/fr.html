Manuel de Script Macro

Introduction

L'éditeur de macros permet d'écrire des scripts qui servent de base de calcul pour les services, les emplois etc.

Exemples d'application:

  • Calcul exact des heures de vacances ou de service militaire selon le taux d'occupation
  • Calcul des suppléments pour le travail de nuit, les week-ends et les jours fériés
  • Adaptation flexible aux nouvelles exigences

Remarque: L'interpréteur de script s'exécute dans un environnement sandbox sécurisé sans accès au système de fichiers ou au réseau. Il n'est pas possible d'exécuter du code malveillant.

Fonction et Catégorie

Outre le nom et le contenu du script, chaque macro de la liste des macros possède deux autres propriétés définies via des menus déroulants dans l'éditeur: Catégorie et Fonction. Les deux sont de pures métadonnées – elles se situent en dehors du script et ne modifient pas son calcul, mais déterminent comment Klacks trouve et attribue automatiquement la macro appropriée.

Catégorie

La catégorie affecte une macro à un domaine d'application métier:

CatégorieUtilisation
Non spécifiéAucun domaine d'application particulier (valeur par défaut pour les nouvelles macros)
ServiceCalcul des suppléments pour les services réguliers (supplément nuit, week-end, jour férié)
VacancesCalcul des heures pour les vacances
MaladieCalcul des heures pour la maladie
AccidentCalcul des heures pour l'accident
Atelier (payé)Temps d'atelier/formation payé
Atelier (non payé)Temps d'atelier/formation non payé

La catégorie Service a un rôle particulier: les services nouvellement créés se voient automatiquement attribuer la macro standard de cette catégorie (voir « Fonction » ci-dessous). Les services déjà existants ne sont en revanche jamais modifiés a posteriori.

Fonction: Personnalisé, Standard, Standard (additif)

La fonction classe le rôle d'une macro au sein de sa catégorie:

FonctionSignification
PersonnaliséMacro libre sans rôle particulier. Un nombre illimité est possible par catégorie.
StandardLa macro standard de cette catégorie – attribuée automatiquement aux nouveaux services. Au maximum UNE macro par catégorie peut porter cette fonction.
Standard (additif)Macro standard alternative avec une logique de supplément additive (voir ci-dessous). Également au maximum une par catégorie, possible en plus de la macro « Standard ».

Important: la fonction seule ne calcule rien – c'est une étiquette. La décision de calculer les suppléments en mode « highest-wins » (seul le taux applicable le plus élevé compte) ou de manière additive (tous les taux applicables sont additionnés) revient au script lui-même. Les deux macros de la catégorie « Service » fournies illustrent cette différence sur la même structure de base:

  • « AllShift » (Fonction: Standard) – détermine, pour chaque segment horaire, le supplément applicable le plus élevé (nuit/WE1/WE2/WE3/jour férié) et n'utilise que celui-ci.
  • « AllShiftAdditive » (Fonction: Standard (additif)) – calcule le supplément de nuit, de week-end et de jour férié indépendamment les uns des autres et les additionne.

Un paramètre valable pour toute l'installation (« additif » ou « le taux le plus élevé l'emporte ») détermine laquelle des deux est attribuée automatiquement à la création d'un nouveau service. La macro peut ensuite être changée manuellement à tout moment pour chaque service – un fonctionnement mixte est donc possible.

Unicité: si vous tentez d'enregistrer une deuxième macro de la même catégorie également comme « Standard » ou « Standard (additif) », l'éditeur bloque l'enregistrement et indique le nom de la macro déjà attribuée. Réglez d'abord la fonction de celle-ci sur « Personnalisé ».

Il est déconseillé de modifier manuellement « AllShift »/« AllShiftAdditive ». Ces deux macros sont le mécanisme par lequel les adaptations spécifiques au pays et au secteur d'activité sont appliquées automatiquement: tant que vous ne les modifiez pas, Klacks les maintient automatiquement synchronisées avec les règles adaptées à votre pays et à votre secteur. Si vous modifiez l'une d'elles manuellement, elle est dès lors considérée comme propre au client – les futures mises à jour automatiques pays/secteur pour cette macro ne sont alors plus appliquées silencieusement, mais échouent avec un conflit jusqu'à ce que vous résolviez l'écart manuellement. Si vous avez besoin d'une logique de supplément personnalisée, créez plutôt une nouvelle macro avec la fonction « Personnalisé » et attribuez-la spécifiquement aux services concernés.

Structures de Contrôle

Important: Les mots-clés comme ENDIF, ENDFUNCTION, ENDSUB doivent être écrits en un seul mot (pas END IF).

IF-THEN-ELSE

IF x > 10 THEN
    OUTPUT 1, "grand"
ELSEIF x > 5 THEN
    OUTPUT 1, "moyen"
ELSE
    OUTPUT 1, "petit"
ENDIF

IF sur une ligne

IF x > 10 THEN OUTPUT 1, "grand" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        OUTPUT 1, "Week-end"
    CASE 1, 2, 3, 4, 5
        OUTPUT 1, "Jour ouvrable"
    CASE ELSE
        OUTPUT 1, "Inconnu"
END SELECT

Boucle FOR-NEXT

FOR i = 1 TO 10
    somme += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

Boucle DO-LOOP

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Fonctions et Procédures

Important: Les fonctions (FUNCTION) et procédures (SUB) doivent être définies au-dessus du premier appel. L'interpréteur lit le code de haut en bas – une fonction ou procédure n'est connue qu'après que sa définition a été traitée.

SUB (Procédure sans valeur de retour)

SUB calculer(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (Fonction avec valeur de retour)

FUNCTION doubler(x)
    doubler = x * 2
ENDFUNCTION

DIM resultat
resultat = doubler(21)
OUTPUT 1, resultat

Valeur de Retour (OUTPUT)

OUTPUT typ, wert

typ et wert sont deux expressions séparées par une virgule; les deux sont optionnelles (valeur par défaut 0 resp. "" si elles sont omises). Une macro peut contenir un nombre illimité de lignes OUTPUT – chacune produit sa propre valeur de retour. Klacks n'évalue toutefois que les types suivants:

TypeSignification
1Résultat principal (heures ou montant total) – pris en compte même avec la valeur 0
10Supplément de nuit
11Supplément pour le jour de week-end 1 (ex. samedi)
12Supplément pour le jour de week-end 2 (ex. dimanche)
13Supplément pour le jour de week-end 3 (troisième jour de week-end configurable)
14Supplément jour férié

Les lignes de supplément (types 10-14) avec la valeur 0 sont ignorées – une macro n'a donc pas besoin de produire une ligne pour chaque type de supplément, mais seulement pour les suppléments effectivement dus. Les valeurs qui ne peuvent pas être interprétées comme un nombre sont ignorées.

Lors de l'enregistrement, la macro est obligatoirement compilée et exécutée une fois à titre d'essai avec des valeurs de test neutres. Les erreurs de syntaxe et d'exécution (par ex. des parenthèses non équilibrées ou une expression en suspens) sont ainsi signalées de manière fiable, au lieu de produire silencieusement une macro non fonctionnelle.

Exemple: Calcul des Suppléments (« AllShift »)

La macro standard fournie de la catégorie « Service ». Calcule les suppléments pour la nuit, les jours fériés et les trois jours de week-end configurables, avec une gestion correcte des équipes traversant minuit (division en segments), et applique par segment le taux applicable le plus élevé (highest-wins). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

Explication

  • Division en segments: pour les équipes traversant minuit (ex. 22:00-06:00), l'équipe est divisée en deux segments (jusqu'à minuit / à partir de minuit), chacun avec son propre indicateur jour de la semaine/jour férié
  • SegBonusForType: calcule le supplément pour un segment et un type de supplément donné (10-14) en tenant compte des suppléments de nuit, de jour férié et de week-end
  • WE1/WE2/WE3 au lieu de Sam/Dim: weekendday1-3 rendent les jours de week-end configurables (tous les pays n'ont pas samedi/dimanche comme week-end)
  • Supplément le plus élevé par segment: NRate/DRate déterminent respectivement le taux applicable le plus élevé pour les heures de nuit et de jour – highest-wins, pas de cumul
  • HolidayNextDay: prend en compte si le lendemain est un jour férié (important pour les équipes de nuit traversant minuit)
  • Plusieurs lignes OUTPUT: la ligne 1 fournit le total, les lignes 10-14 fournissent les montants de supplément individuels (voir la section « Valeur de Retour »)

La variante additive (« AllShiftAdditive »)

La macro standard (additif) de la même catégorie possède des lignes IMPORT identiques et la même structure générale – seule SegBonusForType diffère: au lieu du taux le plus élevé, on calcule pour chaque type de supplément, indépendamment, s'il s'applique, et tous les montants applicables sont additionnés à la fin (plus de highest-wins): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

Si, par exemple, une équipe de nuit tombe en plus un jour férié, elle ne reçoit avec « AllShift » que le taux le plus élevé des deux, alors qu'avec « AllShiftAdditive » elle reçoit le supplément de nuit et le supplément de jour férié cumulés. Le reste du script (division en segments, sommation, lignes OUTPUT) est identique à « AllShift » ci-dessus.
