Manuel de Script Macro

Introduction

L'éditeur de macros permet d'écrire des scripts qui servent de base de calcul pour les services, les emplois etc.

Exemples d'application:

  • Calcul exact des heures de vacances ou de service militaire selon le taux d'occupation
  • Calcul des suppléments pour le travail de nuit, les week-ends et les jours fériés
  • Adaptation flexible aux nouvelles exigences

Remarque: L'interpréteur de script s'exécute dans un environnement sandbox sécurisé sans accès au système de fichiers ou au réseau. Il n'est pas possible d'exécuter du code malveillant.

Variables et Constantes

Toutes les variables et constantes sont sans type.

CONST PI = 3.1415
DIM a, b, c
IMPORT montant, rabais

Structures de Contrôle

Important: Les mots-clés comme ENDIF, ENDFUNCTION, ENDSUB doivent être écrits en un seul mot (pas END IF).

IF-THEN-ELSE

IF x > 10 THEN
    OUTPUT 1, "grand"
ELSEIF x > 5 THEN
    OUTPUT 1, "moyen"
ELSE
    OUTPUT 1, "petit"
ENDIF

IF sur une ligne

IF x > 10 THEN OUTPUT 1, "grand" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        OUTPUT 1, "Week-end"
    CASE 1, 2, 3, 4, 5
        OUTPUT 1, "Jour ouvrable"
    CASE ELSE
        OUTPUT 1, "Inconnu"
END SELECT

Boucle FOR-NEXT

FOR i = 1 TO 10
    somme += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

Boucle DO-LOOP

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Fonctions et Procédures

Important: Les fonctions (FUNCTION) et procédures (SUB) doivent être définies au-dessus du premier appel. L'interpréteur lit le code de haut en bas – une fonction ou procédure n'est connue qu'après que sa définition a été traitée.

SUB (Procédure sans valeur de retour)

SUB calculer(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (Fonction avec valeur de retour)

FUNCTION doubler(x)
    doubler = x * 2
ENDFUNCTION

DIM resultat
resultat = doubler(21)
OUTPUT 1, resultat

Exemple: Calcul des Suppléments

Calcule les suppléments pour la nuit, les jours fériés et les week-ends avec gestion correcte des équipes traversant minuit (division en segments).

IMPORT hour, fromhour, untilhour
IMPORT weekday, holiday, holidaynextday
IMPORT nightrate, holidayrate, sarate, sorate

FUNCTION CalcSegment(StartHour, EndHour, IsHoliday, WeekdayNum)
    DIM SegmentHours, NightHours, NonNightHours
    DIM NRate, DRate, HasHoliday, IsSaturday, IsSunday

    SegmentHours = EndHour - StartHour
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    ' Calculer les heures de nuit (23:00-06:00)
    NightHours = 0
    IF StartHour < 6 THEN NightHours = NightHours + IIF(EndHour < 6, EndHour, 6) - StartHour ENDIF
    IF EndHour > 23 OrElse EndHour < StartHour THEN NightHours = NightHours + IIF(StartHour > 23, 24 - StartHour, 24 - 23) ENDIF
    NonNightHours = SegmentHours - NightHours

    HasHoliday = IsHoliday
    IsSaturday = WeekdayNum = 6    ' Sam = 6 (ISO-8601)
    IsSunday = WeekdayNum = 7      ' Dim = 7 (ISO-8601)

    ' Taux le plus élevé pour les heures de nuit
    NRate = nightrate
    IF HasHoliday AndAlso holidayrate > NRate THEN NRate = holidayrate ENDIF
    IF IsSaturday AndAlso sarate > NRate THEN NRate = sarate ENDIF
    IF IsSunday AndAlso sorate > NRate THEN NRate = sorate ENDIF

    ' Taux le plus élevé pour les heures de jour
    DRate = 0
    IF HasHoliday AndAlso holidayrate > DRate THEN DRate = holidayrate ENDIF
    IF IsSaturday AndAlso sarate > DRate THEN DRate = sarate ENDIF
    IF IsSunday AndAlso sorate > DRate THEN DRate = sorate ENDIF

    CalcSegment = NightHours * NRate + NonNightHours * DRate
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay

' Calculer le jour de la semaine du lendemain (ISO-8601)
WeekdayNextDay = (weekday MOD 7) + 1

IF untilhour <= fromhour THEN
    ' Équipe traversant minuit - 2 segments
    TotalBonus = CalcSegment(fromhour, 24, holiday, weekday)
    TotalBonus = TotalBonus + CalcSegment(0, untilhour, holidaynextday, WeekdayNextDay)
ELSE
    ' Équipe de jour normale
    TotalBonus = CalcSegment(fromhour, untilhour, holiday, weekday)
ENDIF

OUTPUT 1, Round(TotalBonus, 2)

Explication

  • Division en segments: Les équipes traversant minuit (ex: 22:00-06:00) sont divisées en deux segments
  • CalcSegment: Calcule le supplément pour un segment en tenant compte des taux de nuit, jour férié et week-end
  • Taux Sam/Dim séparés: sarate et sorate permettent des suppléments différents pour samedi et dimanche
  • Taux le plus élevé: Utilise toujours le supplément le plus élevé applicable
  • holidaynextday: Considère si le lendemain est un jour férié (important pour les équipes de nuit)
