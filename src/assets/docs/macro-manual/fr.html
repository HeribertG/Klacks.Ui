Manuel de Script Macro

Introduction

L'éditeur de macros permet d'écrire des scripts qui servent de base de calcul pour les services, les emplois etc.

Exemples d'application:

  • Calcul exact des heures de vacances ou de service militaire selon le taux d'occupation
  • Calcul des suppléments pour le travail de nuit, les week-ends et les jours fériés
  • Adaptation flexible aux nouvelles exigences

Remarque: L'interpréteur de script s'exécute dans un environnement sandbox sécurisé sans accès au système de fichiers ou au réseau. Il n'est pas possible d'exécuter du code malveillant.

Variables et Constantes

Toutes les variables et constantes sont sans type.

CONST PI = 3.1415
DIM a, b, c
EXTERNAL montant, rabais

Structures de Contrôle

IF-THEN-ELSE

IF x > 10 THEN
    message 1, "grand"
ELSEIF x > 5 THEN
    message 1, "moyen"
ELSE
    message 1, "petit"
END IF

SELECT CASE

SELECT CASE jour_semaine
    CASE 1, 7
        message 1, "Week-end"
    CASE 2, 3, 4, 5, 6
        message 1, "Jour ouvrable"
    CASE ELSE
        message 1, "Inconnu"
END SELECT

Boucle FOR-NEXT

FOR i = 1 TO 10
    somme += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

Boucle DO-LOOP

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Fonctions et Procédures

SUB (Procédure sans valeur de retour)

SUB calculer(a, b)
    IF a = b THEN EXIT SUB
    message 1, a + b
END SUB

FUNCTION (Fonction avec valeur de retour)

FUNCTION doubler(x)
    doubler = x * 2
END FUNCTION

DIM resultat
resultat = doubler(21)
message 1, resultat    ' Sortie: 42

Exemple: Calcul de Vacances

EXTERNAL taux_occupation
EXTERNAL jours_vacances

DIM heures
heures = jours_vacances * 8.4 * (taux_occupation / 100)

MESSAGE 1, Round(heures, 2)
