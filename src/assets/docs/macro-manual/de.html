Macro Scripting Handbuch

Einleitung

Mit dem Macro Editor lassen sich Skripte schreiben, die als Rechengrundlage für Dienste, Beschäftigungen etc. verwendet werden.

Anwendungsbeispiele:

  • Exakte Berechnung der Stunden bei Ferien oder Militär gemäss Beschäftigungsgrad
  • Berechnung von Zuschlägen für Nachtarbeit, Wochenenden und Feiertage
  • Flexible Anpassung an neue Anforderungen

Hinweis: Der Script Interpreter läuft in einer sicheren Sandbox-Umgebung ohne Zugriff auf das Dateisystem oder Netzwerk. Es ist nicht möglich, schadhaften Code auszuführen.

Kontrollstrukturen

IF-THEN-ELSE

IF x > 10 THEN
    message 1, "gross"
ELSEIF x > 5 THEN
    message 1, "mittel"
ELSE
    message 1, "klein"
END IF

SELECT CASE

SELECT CASE weekday
    CASE 1, 7
        message 1, "Wochenende"
    CASE 2, 3, 4, 5, 6
        message 1, "Arbeitstag"
    CASE ELSE
        message 1, "Unbekannt"
END SELECT

FOR-NEXT Schleife

FOR i = 1 TO 10
    summe += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

DO-LOOP Schleife

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Funktionen und Prozeduren

SUB (Prozedur ohne Rückgabewert)

SUB berechne(a, b)
    IF a = b THEN EXIT SUB
    message 1, a + b
END SUB

FUNCTION (Funktion mit Rückgabewert)

FUNCTION verdoppeln(x)
    verdoppeln = x * 2
END FUNCTION

DIM ergebnis
ergebnis = verdoppeln(21)
message 1, ergebnis    ' Ausgabe: 42

EXTERNAL beschaeftigungsgrad
EXTERNAL ferientage

DIM stunden
stunden = ferientage * 8.4 * (beschaeftigungsgrad / 100)

MESSAGE 1, Round(stunden, 2)
