Macro Scripting Manual

Introduction

The Macro Editor allows you to write scripts that serve as calculation basis for services, employments etc.

Application examples:

  • Exact calculation of hours for vacation or military service based on employment level
  • Calculation of surcharges for night work, weekends and holidays
  • Flexible adaptation to new requirements

Note: The script interpreter runs in a secure sandbox environment without access to the file system or network. It is not possible to execute malicious code.

All variables and constants are typeless.

CONST PI = 3.1415

Control Structures

Important: Keywords like ENDIF, ENDFUNCTION, ENDSUB must be written as single words (not END IF).

IF-THEN-ELSE

IF x > 10 THEN
    OUTPUT 1, "large"
ELSEIF x > 5 THEN
    OUTPUT 1, "medium"
ELSE
    OUTPUT 1, "small"
ENDIF

Single-line IF

IF x > 10 THEN OUTPUT 1, "large" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        OUTPUT 1, "Weekend"
    CASE 1, 2, 3, 4, 5
        OUTPUT 1, "Workday"
    CASE ELSE
        OUTPUT 1, "Unknown"
END SELECT

FOR-NEXT Loop

FOR i = 1 TO 10
    sum += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

DO-LOOP Loop

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Functions and Procedures

Important: Functions (FUNCTION) and procedures (SUB) must be defined above the first call. The interpreter reads the code from top to bottom – a function or procedure is only known after its definition has been processed.

SUB (Procedure without return value)

SUB calculate(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (Function with return value)

FUNCTION double(x)
    double = x * 2
ENDFUNCTION

DIM result
result = double(21)
OUTPUT 1, result

Example: Surcharge Calculation

Calculates surcharges for night, holiday and weekend with proper handling of shifts crossing midnight (segment splitting).

IMPORT hour, fromhour, untilhour
IMPORT weekday, holiday, holidaynextday
IMPORT nightrate, holidayrate, sarate, sorate

FUNCTION CalcSegment(StartHour, EndHour, IsHoliday, WeekdayNum)
    DIM SegmentHours, NightHours, NonNightHours
    DIM NRate, DRate, HasHoliday, IsSaturday, IsSunday

    SegmentHours = EndHour - StartHour
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    ' Calculate night hours (23:00-06:00)
    NightHours = 0
    IF StartHour < 6 THEN NightHours = NightHours + IIF(EndHour < 6, EndHour, 6) - StartHour ENDIF
    IF EndHour > 23 OrElse EndHour < StartHour THEN NightHours = NightHours + IIF(StartHour > 23, 24 - StartHour, 24 - 23) ENDIF
    NonNightHours = SegmentHours - NightHours

    HasHoliday = IsHoliday
    IsSaturday = WeekdayNum = 6    ' Sat = 6 (ISO-8601)
    IsSunday = WeekdayNum = 7      ' Sun = 7 (ISO-8601)

    ' Highest rate for night hours
    NRate = nightrate
    IF HasHoliday AndAlso holidayrate > NRate THEN NRate = holidayrate ENDIF
    IF IsSaturday AndAlso sarate > NRate THEN NRate = sarate ENDIF
    IF IsSunday AndAlso sorate > NRate THEN NRate = sorate ENDIF

    ' Highest rate for day hours
    DRate = 0
    IF HasHoliday AndAlso holidayrate > DRate THEN DRate = holidayrate ENDIF
    IF IsSaturday AndAlso sarate > DRate THEN DRate = sarate ENDIF
    IF IsSunday AndAlso sorate > DRate THEN DRate = sorate ENDIF

    CalcSegment = NightHours * NRate + NonNightHours * DRate
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay

' Calculate next day weekday (ISO-8601)
WeekdayNextDay = (weekday MOD 7) + 1

IF untilhour <= fromhour THEN
    ' Shift crosses midnight - 2 segments
    TotalBonus = CalcSegment(fromhour, 24, holiday, weekday)
    TotalBonus = TotalBonus + CalcSegment(0, untilhour, holidaynextday, WeekdayNextDay)
ELSE
    ' Normal day shift
    TotalBonus = CalcSegment(fromhour, untilhour, holiday, weekday)
ENDIF

OUTPUT 1, Round(TotalBonus, 2)

Explanation

  • Segment Splitting: Shifts crossing midnight (e.g. 22:00-06:00) are split into two segments
  • CalcSegment: Calculates the surcharge for a segment considering night, holiday and weekend rates
  • Separate Sat/Sun rates: sarate and sorate allow different surcharges for Saturday and Sunday
  • Highest Rate: Always uses the highest applicable surcharge
  • holidaynextday: Considers if the next day is a holiday (important for night shifts)
