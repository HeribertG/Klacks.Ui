Macro Scripting Manual

Introduction

The Macro Editor allows you to write scripts that serve as the calculation basis for shifts, employments etc.

Application examples:

  • Exact calculation of hours for vacation or military service according to employment level
  • Calculation of surcharges for night work, weekends and holidays
  • Flexible adaptation to new requirements

Note: The script interpreter runs in a secure sandbox environment without access to the file system or network. It is not possible to execute malicious code.

Function and Category

In addition to name and script content, every macro in the macro list has two further properties that are set via dropdowns in the editor: Category and Function. Both are pure metadata – they exist outside the script and do not change its calculation, but control how Klacks automatically finds and assigns the appropriate macro.

Category

The category assigns a macro to a functional area of application:

CategoryUsage
UnspecifiedNo specific area of application (default for new macros)
ShiftSurcharge calculation for regular shifts (night, weekend, holiday surcharge)
VacationHour calculation for vacation
IllnessHour calculation for illness
AccidentHour calculation for accident
Workshop (paid)Paid workshop/training time
Workshop (unpaid)Unpaid workshop/training time

The category Shift has a special role: newly created shifts automatically get the Standard macro of this category assigned (see "Function" below). Existing shifts are never changed retroactively.

Function: Custom, Standard, Standard (additive)

The function classifies the role of a macro within its category:

FunctionMeaning
CustomFree macro without a special role. Any number possible per category.
StandardThe standard macro of this category – automatically assigned to new shifts. At most ONE macro per category may carry this function.
Standard (additive)Alternative standard macro with additive surcharge logic (see below). Likewise at most one per category, possible in addition to the "Standard" macro.

Important: The function alone calculates nothing – it is a label. Whether surcharges are calculated as "highest-wins" (only the highest applicable rate counts) or additively (all applicable rates are summed up) is decided by the script itself. The two built-in category "Shift" macros show the difference on the same basic structure:

  • "AllShift" (Function: Standard) – determines the highest applicable surcharge per time segment (night/WE1/WE2/WE3/holiday) and uses only this one.
  • "AllShiftAdditive" (Function: Standard (additive)) – calculates night, weekend and holiday surcharge independently of each other and sums them.

Which of the two is automatically assigned when a new shift is created is controlled by an installation-wide setting ("additive" or "highest rate wins"). The macro can subsequently be switched manually for each shift at any time – a mixed operation is therefore possible.

Uniqueness: If you try to save a second macro of the same category also as "Standard" or "Standard (additive)", the editor blocks saving and names the macro already assigned. Set that macro's function to "Custom" first.

Manually editing "AllShift"/"AllShiftAdditive" is discouraged. These two macros are the mechanism through which country- and industry-specific adjustments are applied automatically: as long as you leave them unchanged, Klacks keeps them automatically in sync with the rules appropriate for your country and industry. If you edit either one manually, it is from then on considered customer-owned – future automatic country/industry updates for that macro are then no longer applied silently, but fail with a conflict until you resolve the discrepancy manually. If you need custom surcharge logic, create a new macro with function "Custom" instead and assign it specifically to the affected shifts.

Control Structures

Important: Keywords like ENDIF, ENDFUNCTION, ENDSUB must be written as single words (not END IF).

IF-THEN-ELSE

IF x > 10 THEN
    OUTPUT 1, "large"
ELSEIF x > 5 THEN
    OUTPUT 1, "medium"
ELSE
    OUTPUT 1, "small"
ENDIF

Single-line IF

IF x > 10 THEN OUTPUT 1, "large" ENDIF

SELECT CASE

SELECT CASE weekday
    CASE 6, 7
        OUTPUT 1, "Weekend"
    CASE 1, 2, 3, 4, 5
        OUTPUT 1, "Workday"
    CASE ELSE
        OUTPUT 1, "Unknown"
END SELECT

FOR-NEXT Loop

FOR i = 1 TO 10
    sum += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

DO-LOOP Loop

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Functions and Procedures

Important: Functions (FUNCTION) and procedures (SUB) must be defined above the first call. The interpreter reads the code from top to bottom – a function or procedure is only known after its definition has been processed.

SUB (Procedure without return value)

SUB calculate(a, b)
    IF a = b THEN EXIT SUB ENDIF
    OUTPUT 1, a + b
ENDSUB

FUNCTION (Function with return value)

FUNCTION double(x)
    double = x * 2
ENDFUNCTION

DIM result
result = double(21)
OUTPUT 1, result

Return Value (OUTPUT)

OUTPUT typ, wert

typ and wert are two comma-separated expressions; both are optional (default 0 or "" respectively, if omitted). A macro may contain any number of OUTPUT lines – each produces its own return value. Klacks only evaluates the following types:

TypeMeaning
1Main result (hours or total amount) – is applied even at value 0
10Night surcharge
11Surcharge for weekend day 1 (e.g. Saturday)
12Surcharge for weekend day 2 (e.g. Sunday)
13Surcharge for weekend day 3 (third configurable weekend day)
14Holiday surcharge

Surcharge lines (type 10-14) with value 0 are ignored – a macro therefore does not need to output a separate line for every surcharge type, only for surcharges that actually apply. Values that cannot be interpreted as a number are skipped.

When saving, the macro is always compiled and executed once on a trial basis with neutral test values. Syntax and runtime errors (e.g. unbalanced parentheses or a dangling expression) are reliably reported instead of silently resulting in a non-functional macro.

Example: Surcharge Calculation ("AllShift")

The built-in standard macro of the category "Shift". Calculates surcharges for night, holiday and the three configurable weekend days with correct handling of shifts crossing midnight (segment splitting) and applies the highest applicable rate per segment (highest-wins). 

IMPORT Hour, FromHour, UntilHour
IMPORT Weekday, Holiday, HolidayNextDay
IMPORT NightRate, HolidayRate, WE1Rate, WE2Rate, WE3Rate
IMPORT NightStart, NightEnd
IMPORT WeekendDay1, WeekendDay2, WeekendDay3

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, NonNightHours, Amount
    DIM NRate, DRate, NType, DType
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)
    NonNightHours = SegmentHours - NightHours

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    NRate = 0
    NType = 0
    IF NightHours > 0 THEN
        NRate = NightRate
        NType = 10
    ENDIF
    IF HasHoliday AndAlso HolidayRate > NRate THEN
        NRate = HolidayRate
        NType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > NRate THEN
        NRate = WE1Rate
        NType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > NRate THEN
        NRate = WE2Rate
        NType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > NRate THEN
        NRate = WE3Rate
        NType = 13
    ENDIF

    DRate = 0
    DType = 0
    IF HasHoliday AndAlso HolidayRate > DRate THEN
        DRate = HolidayRate
        DType = 14
    ENDIF
    IF IsWE1 AndAlso WE1Rate > DRate THEN
        DRate = WE1Rate
        DType = 11
    ENDIF
    IF IsWE2 AndAlso WE2Rate > DRate THEN
        DRate = WE2Rate
        DType = 12
    ENDIF
    IF IsWE3 AndAlso WE3Rate > DRate THEN
        DRate = WE3Rate
        DType = 13
    ENDIF

    Amount = 0
    IF NType = WantType THEN Amount = Amount + NightHours * NRate ENDIF
    IF DType = WantType THEN Amount = Amount + NonNightHours * DRate ENDIF

    SegBonusForType = Amount
ENDFUNCTION

DIM TotalBonus, WeekdayNextDay
DIM BonusNight, BonusWeekend1, BonusWeekend2, BonusWeekend3, BonusHoliday

WeekdayNextDay = (Weekday MOD 7) + 1

IF TimeToHours(UntilHour) <= TimeToHours(FromHour) THEN
    BonusNight = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 10) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 10)
    BonusWeekend1 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 11) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 11)
    BonusWeekend2 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 12) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 12)
    BonusWeekend3 = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 13) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 13)
    BonusHoliday = SegBonusForType(FromHour, "00:00", Holiday, Weekday, 14) + SegBonusForType("00:00", UntilHour, HolidayNextDay, WeekdayNextDay, 14)
ELSE
    BonusNight = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 10)
    BonusWeekend1 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 11)
    BonusWeekend2 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 12)
    BonusWeekend3 = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 13)
    BonusHoliday = SegBonusForType(FromHour, UntilHour, Holiday, Weekday, 14)
ENDIF

TotalBonus = BonusNight + BonusWeekend1 + BonusWeekend2 + BonusWeekend3 + BonusHoliday

OUTPUT 1, Round(TotalBonus, 2)
OUTPUT 10, BonusNight
OUTPUT 11, BonusWeekend1
OUTPUT 12, BonusWeekend2
OUTPUT 13, BonusWeekend3
OUTPUT 14, BonusHoliday

Explanation

  • Segment splitting: For shifts crossing midnight (e.g. 22:00-06:00), the shift is split into two segments (until midnight / from midnight), each with its own weekday/holiday flag
  • SegBonusForType: Calculates the surcharge for a segment and a specific surcharge type (10-14) taking night, holiday and weekend surcharges into account
  • WE1/WE2/WE3 instead of Sat/Sun: weekendday1-3 make the weekend days configurable (not every country has Saturday/Sunday as the weekend)
  • Highest surcharge per segment: NRate/DRate each determine the highest applicable rate for night or day hours respectively – highest-wins, no stacking
  • HolidayNextDay: Takes into account whether the next day is a holiday (important for night shifts crossing midnight)
  • Multiple OUTPUT lines: line 1 provides the total sum, lines 10-14 provide the individual surcharge amounts (see the "Return Value" section)

The additive variant ("AllShiftAdditive")

The Standard (additive) macro of the same category has identical IMPORT lines and the same overall structure – only SegBonusForType differs: instead of the highest rate, it is calculated independently for each surcharge type whether it applies, and all applicable amounts are summed up at the end (no more highest-wins): 

FUNCTION SegBonusForType(StartTime, EndTime, HolidayFlag, WeekdayNum, WantType)
    DIM SegmentHours, NightHours, Amount
    DIM HasHoliday, IsWE1, IsWE2, IsWE3

    SegmentHours = TimeToHours(EndTime) - TimeToHours(StartTime)
    IF SegmentHours < 0 THEN SegmentHours = SegmentHours + 24 ENDIF

    NightHours = TimeOverlap(NightStart, NightEnd, StartTime, EndTime)

    HasHoliday = HolidayFlag = 1
    IsWE1 = WeekdayNum = WeekendDay1
    IsWE2 = WeekdayNum = WeekendDay2
    IsWE3 = WeekdayNum = WeekendDay3

    Amount = 0
    IF WantType = 10 THEN
        Amount = NightHours * NightRate
    ENDIF
    IF WantType = 11 THEN
        IF IsWE1 THEN Amount = SegmentHours * WE1Rate ENDIF
    ENDIF
    IF WantType = 12 THEN
        IF IsWE2 THEN Amount = SegmentHours * WE2Rate ENDIF
    ENDIF
    IF WantType = 13 THEN
        IF IsWE3 THEN Amount = SegmentHours * WE3Rate ENDIF
    ENDIF
    IF WantType = 14 THEN
        IF HasHoliday THEN Amount = SegmentHours * HolidayRate ENDIF
    ENDIF

    SegBonusForType = Amount
ENDFUNCTION

If, for example, a night shift additionally falls on a holiday, with "AllShift" it only receives the higher of the two rates, whereas with "AllShiftAdditive" it receives both the night and holiday surcharge together. The rest of the script (segment splitting, summation, OUTPUT lines) is identical to "AllShift" above.
