Macro Scripting Manual

Introduction

The Macro Editor allows you to write scripts that serve as calculation basis for services, employments etc.

Application examples:

  • Exact calculation of hours for vacation or military service based on employment level
  • Calculation of surcharges for night work, weekends and holidays
  • Flexible adaptation to new requirements

Note: The script interpreter runs in a secure sandbox environment without access to the file system or network. It is not possible to execute malicious code.

Variables and Constants

All variables and constants are typeless.

CONST PI = 3.1415
DIM a, b, c
EXTERNAL amount, discount

Control Structures

IF-THEN-ELSE

IF x > 10 THEN
    message 1, "large"
ELSEIF x > 5 THEN
    message 1, "medium"
ELSE
    message 1, "small"
END IF

SELECT CASE

SELECT CASE weekday
    CASE 1, 7
        message 1, "Weekend"
    CASE 2, 3, 4, 5, 6
        message 1, "Workday"
    CASE ELSE
        message 1, "Unknown"
END SELECT

FOR-NEXT Loop

FOR i = 1 TO 10
    sum += i
NEXT

FOR i = 10 TO 1 STEP -1
    IF x > y THEN EXIT FOR
NEXT

DO-LOOP Loop

DO WHILE a > 0
    a -= 1
LOOP

DO
    x += 1
LOOP UNTIL x >= 10

Functions and Procedures

SUB (Procedure without return value)

SUB calculate(a, b)
    IF a = b THEN EXIT SUB
    message 1, a + b
END SUB

FUNCTION (Function with return value)

FUNCTION double(x)
    double = x * 2
END FUNCTION

DIM result
result = double(21)
message 1, result    ' Output: 42

Example: Vacation Calculation

EXTERNAL employment_level
EXTERNAL vacation_days

DIM hours
hours = vacation_days * 8.4 * (employment_level / 100)

MESSAGE 1, Round(hours, 2)
