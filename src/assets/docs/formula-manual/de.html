Formelfeld Handbuch

Grundsyntax

Jedes Formelfeld gibt das Ergebnis mit dem output-Befehl aus:

output 1, <Ausdruck>

Der erste Parameter 1 ist der Nachrichtentyp und muss immer 1 sein. Der zweite Parameter ist der auszugebende Wert.

Einfache Beispiele:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " Einträge"

Verfügbare Variablen

Die verfügbaren Variablen sind im Tab Variablen aufgelistet und können dort mit Testwerten belegt werden. Je nach Report-Typ stehen unterschiedliche Variablen zur Verfügung:

Bedingte Logik

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "viele Einträge"
ELSEIF totalRows > 0 THEN
    output 1, "wenige Einträge"
ELSE
    output 1, "keine Einträge"
ENDIF

Einzeiliges IF

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (Kurzform)

output 1, IIF(totalRows > 0, "OK", "Leer")

Variablen und Schleifen

DIM i, summe
summe = 0
FOR i = 1 TO totalRows
    summe = summe + 1
NEXT
output 1, CStr(summe)

Praktische Beispiele

Anzahl Einträge mit Text

output 1, CStr(totalRows) & " Einträge"

Gerundeter Wert (1 Stelle)

output 1, CStr(Round(totalValue, 1))

Stunden als h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

Bedingte Ausgabe

IF totalRows = 0 THEN
    output 1, "Keine Abwesenheiten"
ELSE
    output 1, CStr(totalRows) & " Abwesenheiten (Total: " & CStr(totalValue) & ")"
ENDIF

Durchschnitt berechnen

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/Tag"
ELSE
    output 1, "-"
ENDIF
