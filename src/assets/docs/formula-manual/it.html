Manuale Campo Formula

Sintassi di base

Ogni campo formula visualizza il risultato con il comando output:

output 1, <espressione>

Il primo parametro 1 è il tipo di messaggio e deve essere sempre 1. Il secondo parametro è il valore da visualizzare.

Esempi semplici:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " voci"

Variabili disponibili

Le variabili disponibili sono elencate nella scheda Variabili. Le variabili dipendono dal tipo di report:

Tipo di reportPiè di tabella
Orario di lavorototalRows, totalHours, totalSurcharges, totalWorkDays
AssenzetotalRows, totalValue
IndirizzitotalRows
GruppitotalRows

Logica condizionale

IF totalRows > 0 THEN
    output 1, CStr(totalRows) & " voci"
ELSE
    output 1, "Nessuna voce"
ENDIF

IIF (forma breve)

output 1, IIF(totalRows > 0, "OK", "Vuoto")

Esempi pratici

Valore arrotondato

output 1, CStr(Round(totalValue, 1))

Ore in h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"
Nota: L'interprete degli script viene eseguito in una sandbox sicura senza accesso al file system o alla rete.
