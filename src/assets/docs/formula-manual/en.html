Formula Field Manual

Basic Syntax

Every formula field outputs its result using the output command:

output 1, <expression>

The first parameter 1 is the message type and must always be 1. The second parameter is the value to output.

Simple examples:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " entries"

Conditional Logic

IF-THEN-ELSE

IF totalRows > 10 THEN
    output 1, "many entries"
ELSEIF totalRows > 0 THEN
    output 1, "few entries"
ELSE
    output 1, "no entries"
ENDIF

Single-line IF

IF totalValue > 0 THEN output 1, CStr(totalValue) ENDIF

IIF (short form)

output 1, IIF(totalRows > 0, "OK", "Empty")

Variables and Loops

DIM i, total
total = 0
FOR i = 1 TO totalRows
    total = total + 1
NEXT
output 1, CStr(total)

Practical Examples

Row count with label

output 1, CStr(totalRows) & " entries"

Rounded value (1 decimal)

output 1, CStr(Round(totalValue, 1))

Hours as h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"

Conditional output

IF totalRows = 0 THEN
    output 1, "No absences"
ELSE
    output 1, CStr(totalRows) & " absences (Total: " & CStr(totalValue) & ")"
ENDIF

Calculate average

IF totalRows > 0 THEN
    output 1, CStr(Round(totalHours / totalRows, 2)) & " h/day"
ELSE
    output 1, "-"
ENDIF
Note: The script interpreter runs in a secure sandbox without access to the file system or network.
