Manuel Champ Formule

Syntaxe de base

Chaque champ formule affiche son résultat avec la commande output:

output 1, <expression>

Le premier paramètre 1 est le type de message et doit toujours être 1. Le second paramètre est la valeur à afficher.

Exemples simples:

output 1, totalRows
output 1, totalValue * 2
output 1, CStr(totalRows) & " entrées"

Variables disponibles

Les variables disponibles sont listées dans l'onglet Variables. Les variables dépendent du type de rapport:

Type de rapportPied de tableau
PlanningtotalRows, totalHours, totalSurcharges, totalWorkDays
AbsencestotalRows, totalValue
AdressestotalRows
GroupestotalRows

Mathématiques

FonctionDescription

Round(x, n)Arrondir à n décimales
Int(x)Arrondir vers le bas

Logique conditionnelle

IF totalRows > 0 THEN
    output 1, CStr(totalRows) & " entrées"
ELSE
    output 1, "Aucune entrée"
ENDIF

IIF (forme courte)

output 1, IIF(totalRows > 0, "OK", "Vide")

Exemples pratiques

Valeur arrondie

output 1, CStr(Round(totalValue, 1))

Heures en h:mm

DIM h, m
h = Int(totalHours)
m = Round((totalHours - h) * 60, 0)
output 1, CStr(h) & "h " & CStr(m) & "min"
Remarque: L'interpréteur s'exécute dans un environnement sandbox sécurisé.
