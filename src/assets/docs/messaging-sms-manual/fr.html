Configurer un fournisseur SMS

Conditions préalables

Pour envoyer et recevoir des messages SMS via Klacks, vous avez besoin d'un compte auprès d'un fournisseur de passerelle SMS. Klacks prend en charge tous les fournisseurs proposant une API REST, par exemple :

  • Twilio — présent dans le monde entier, paiement à l'usage
  • Vonage (Nexmo) — fournisseur européen, conforme au RGPD
  • MessageBird — fournisseur néerlandais, centres de données dans l'UE

Remarque : les étapes ci-dessous utilisent Twilio comme exemple. Les intitulés peuvent varier chez d'autres fournisseurs, mais le principe reste le même.

Étape 1 — Créer un compte chez le fournisseur SMS

  1. Inscrivez-vous auprès du fournisseur de votre choix (p. ex. twilio.com).
  2. Vérifiez votre numéro de téléphone et votre adresse e-mail.
  3. Achetez un numéro d'expéditeur. Ce numéro apparaîtra comme expéditeur pour les SMS sortants.
  4. Notez la clé API (API Key / Auth Token) depuis le tableau de bord du fournisseur.
  5. Notez l'URL de la passerelle (point d'accès API) du fournisseur.
FournisseurURL de la passerelle
Twiliohttps://api.twilio.com/2010-04-01/Accounts/{AccountSID}/Messages.json
Vonagehttps://rest.nexmo.com/sms/json
MessageBirdhttps://rest.messagebird.com/messages

Étape 2 — Configurer le fournisseur SMS dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  1. Cliquez sur Enregistrer.
  2. Testez la connexion à l'aide du bouton Tester dans la liste des fournisseurs.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur SMS configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les numéros de téléphone — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement le numéro de téléphone du destinataire et utilise le fournisseur SMS configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : Le destinataire doit avoir un numéro de mobile enregistré dans Klacks (sous Adresse → Coordonnées).

Étape 4 — Recevoir des SMS entrants (Webhook)

Pour afficher les SMS entrants dans Klacks, un webhook doit être configuré auprès du fournisseur SMS.

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Notez le secret du webhook généré automatiquement pour votre fournisseur SMS.
  3. Configurez l'URL du webhook dans le tableau de bord de votre fournisseur SMS : 
    https://{votre-domaine}/api/messaging/webhook/sms
  4. Les SMS entrants apparaîtront désormais en temps réel dans la boîte de réception de messagerie.

Dépannage

ProblèmeCause possibleSolution
Le test de connexion échoue Clé API ou URL de la passerelle incorrecte Vérifiez les identifiants dans le tableau de bord du fournisseur
Le SMS n'est pas livré Numéro d'expéditeur non vérifié Assurez-vous que le numéro est activé auprès du fournisseur
Le destinataire ne reçoit pas le SMS Numéro de téléphone pas au format international Utilisez le format +{indicatif pays}{numéro} (p. ex. +41791234567)
Les SMS entrants manquent Webhook non configuré Vérifiez l'URL du webhook dans le tableau de bord du fournisseur
Solde du compte épuisé Budget de paiement à l'usage épuisé Rechargez votre solde auprès du fournisseur
