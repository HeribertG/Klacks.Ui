Setting up an SMS Provider

Prerequisites

To send SMS messages through Klacks, you need an account with Twilio or a Twilio-compatible SMS gateway. Klacks uses the Twilio REST API (Messages endpoint with basic authentication).

Important: The SMS integration is designed for sending only. Incoming SMS are not received in Klacks.

Step 1 — Set up a Twilio account

  1. Sign up on twilio.com and verify your phone number and email address.
  2. Open the Twilio Console. On the dashboard, under Account Info, you will find the two required credentials:
    • Account SID — starts with AC
    • Auth Token — click "Show"
  3. Purchase a sender number under Phone Numbers → Buy a number (SMS-capable). This number appears as the sender for outgoing SMS.
  4. Trial accounts: With a free trial account, SMS can only be sent to previously verified numbers and include a trial notice.

Note: Treat the Auth Token like a password. Do not share it publicly and store it securely.

Step 2 — Configure the SMS provider in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:
FieldDescriptionExample

Account SIDAccount SID from the Twilio ConsoleACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Auth TokenAuth Token from the Twilio Consolea1b2c3d4e5f6...
Sender NumberYour purchased phone number in international format+41791234567
Gateway URL (optional)Only for Twilio-compatible alternative gateways — leave empty for Twiliohttps://api.twilio.com
EnabledTurns the provider on/offYes
  1. Click Save.
  2. Test the connection using the Test button in the provider list.

Note on the Gateway URL: Leave the field empty if you use Twilio — Klacks then automatically uses https://api.twilio.com. Only enter a URL if you use an alternative gateway with a Twilio-compatible API.

Step 3 — Send messages via the chatbot (Klacksy)

Once the SMS provider is configured and enabled, the chatbot Klacksy can send messages. You don't need to know any phone numbers — simply use the name of the employee or client: 

"Send an SMS to Max Muster: Your appointment is tomorrow at 2 PM."
"Send Anna Beispiel an SMS: The shift has been swapped."
"Notify Peter Müller via SMS that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's stored mobile number and uses the configured SMS provider. The process is fully transparent to you — you work with names, Klacksy takes care of the rest.

Prerequisite: The recipient must have a mobile number stored in Klacks (under Address → Contact Details), in international format (e.g. +41791234567).

Incoming messages

The SMS integration does not support receiving — replies to sent SMS are not transferred to Klacks. The Messaging Inbox therefore does not show any incoming messages for this provider.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails Account SID or Auth Token incorrect Check both values on the dashboard of the Twilio Console
SMS not delivered Sender number not SMS-capable or not activated Check the number under Phone Numbers in the Twilio Console
Recipient does not receive SMS (trial account) Recipient number not verified Verify the number in the Twilio Console or switch to a paid account
Recipient does not receive SMS Phone number not in international format Use the format +{country code}{number} (e.g. +41791234567)
Error "Permission to send an SMS has not been enabled" Destination country not enabled in the geo permissions Enable the country under Messaging → Geographic Permissions in the Twilio Console
Account balance depleted Pay-per-use budget exhausted Top up your balance in the Twilio Console
