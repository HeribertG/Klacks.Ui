Setting up an SMS Provider

Prerequisites

To send and receive SMS messages through Klacks, you need an account with an SMS gateway provider. Klacks supports any provider offering a REST API, for example:

  • Twilio — globally established, pay-per-use
  • Vonage (Nexmo) — European provider, GDPR-compliant
  • MessageBird — Dutch provider, EU data centres

Note: The steps below use Twilio as an example. Other providers may use different labels, but the principle remains the same.

Step 1 — Create an account with the SMS provider

  1. Sign up with the provider of your choice (e.g. twilio.com).
  2. Verify your phone number and email address.
  3. Purchase a sender number. This number will appear as the sender for outgoing SMS.
  4. Note down the API key (API Key / Auth Token) from the provider dashboard.
  5. Note down the gateway URL (API endpoint) of the provider.
ProviderGateway URL
Twiliohttps://api.twilio.com/2010-04-01/Accounts/{AccountSID}/Messages.json
Vonagehttps://rest.nexmo.com/sms/json
MessageBirdhttps://rest.messagebird.com/messages

Step 2 — Configure the SMS provider in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:
FieldDescriptionExample
NameUnique internal namesms-twilio
Display NameShown in the user interfaceSMS (Twilio)
Provider TypeSelect SMSSMS
API KeyAuth Token / API Key from the providersk_live_abc123...
Sender NumberYour purchased phone number in international format+41791234567
Gateway URLAPI endpoint of the SMS providerhttps://api.twilio.com/...
EnabledTurns the provider on/offYes
  1. Click Save.
  2. Test the connection using the Test button in the provider list.

Step 3 — Send messages via the chatbot (Klacksy)

Once the SMS provider is configured and enabled, the chatbot Klacksy can send messages. You don't need to know any phone numbers — simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Müller that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's phone number and uses the configured SMS provider. The process is fully transparent to you — you work with names, Klacksy takes care of the rest.

Prerequisite: The recipient must have a mobile number stored in Klacks (under Address → Contact Details).

Step 4 — Receive incoming SMS (Webhook)

To display incoming SMS in Klacks, a webhook must be configured with the SMS provider.

  1. Go to Settings → Messaging Providers.
  2. Note the automatically generated webhook secret of your SMS provider.
  3. Configure the webhook URL in your SMS provider dashboard: 
    https://{your-domain}/api/messaging/webhook/sms
  4. Incoming SMS will now appear in real time in the Messaging Inbox.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails API key or gateway URL incorrect Check the credentials in the provider dashboard
SMS not delivered Sender number not verified Make sure the number is activated with the provider
Recipient does not receive SMS Phone number not in international format Use the format +{country code}{number} (e.g. +41791234567)
Incoming SMS missing Webhook not configured Check the webhook URL in the provider dashboard
Account balance depleted Pay-per-use budget exhausted Top up your balance with the provider
