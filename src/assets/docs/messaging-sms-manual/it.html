Configurare un fornitore SMS

Prerequisiti

Per inviare e ricevere messaggi SMS tramite Klacks, è necessario un account presso un fornitore di gateway SMS. Klacks supporta tutti i fornitori che offrono un'API REST, ad esempio:

  • Twilio — diffuso a livello globale, pagamento a consumo
  • Vonage (Nexmo) — fornitore europeo, conforme al GDPR
  • MessageBird — fornitore olandese, data center nell'UE

Nota: i passaggi seguenti utilizzano Twilio come esempio. Altri fornitori possono utilizzare denominazioni diverse, ma il principio resta lo stesso.

Passo 1 — Creare un account presso il fornitore SMS

  1. Registrarsi presso il fornitore scelto (ad es. twilio.com).
  2. Verificare il numero di telefono e l'indirizzo e-mail.
  3. Acquistare un numero mittente. Questo numero apparirà come mittente per gli SMS in uscita.
  4. Annotare la chiave API (API Key / Auth Token) dalla dashboard del fornitore.
  5. Annotare l'URL del gateway (endpoint API) del fornitore.
FornitoreURL del gateway
Twiliohttps://api.twilio.com/2010-04-01/Accounts/{AccountSID}/Messages.json
Vonagehttps://rest.nexmo.com/sms/json
MessageBirdhttps://rest.messagebird.com/messages

Passo 2 — Configurare il fornitore SMS in Klacks

  1. Navigare su Impostazioni → Fornitori di messaggistica.
  2. Fare clic su Aggiungi.
  3. Compilare i campi come segue:
CampoDescrizioneEsempio
NomeNome interno univocosms-twilio
Nome visualizzatoMostrato nell'interfaccia utenteSMS (Twilio)
Tipo di fornitoreSelezionare SMSSMS
Chiave APIAuth Token / Chiave API dal fornitoresk_live_abc123...
Numero mittenteIl numero di telefono acquistato in formato internazionale+41791234567
URL del gatewayEndpoint API del fornitore SMShttps://api.twilio.com/...
AttivatoAttiva o disattiva il fornitoreSì
  1. Fare clic su Salva.
  2. Testare la connessione tramite il pulsante Test nell'elenco dei fornitori.

Passo 3 — Inviare messaggi tramite il chatbot (Klacksy)

Una volta configurato e attivato il fornitore SMS, il chatbot Klacksy può inviare messaggi. Non è necessario conoscere i numeri di telefono — basta usare il nome del dipendente o del cliente: 

"Invia un messaggio a Max Muster: Il suo appuntamento è domani alle 14:00."
"Manda un messaggio a Anna Beispiel: Il turno è stato scambiato."
"Avvisa Peter Müller che il suo turno di lunedì è annullato."

Klacksy cerca automaticamente il numero di telefono del destinatario e utilizza il fornitore SMS configurato. Il processo è completamente trasparente per voi — lavorate con i nomi, Klacksy si occupa del resto.

Prerequisito: Il destinatario deve avere un numero di cellulare registrato in Klacks (sotto Indirizzo → Dati di contatto).

Passo 4 — Ricevere SMS in arrivo (Webhook)

Per visualizzare gli SMS in arrivo in Klacks, è necessario configurare un webhook presso il fornitore SMS.

  1. Andare su Impostazioni → Fornitori di messaggistica.
  2. Annotare il segreto del webhook generato automaticamente per il fornitore SMS.
  3. Configurare l'URL del webhook nella dashboard del fornitore SMS: 
    https://{il-vostro-dominio}/api/messaging/webhook/sms
  4. Gli SMS in arrivo appariranno ora in tempo reale nella casella di messaggistica.

Risoluzione dei problemi

ProblemaPossibile causaSoluzione
Il test di connessione fallisce Chiave API o URL del gateway errati Verificare le credenziali nella dashboard del fornitore
L'SMS non viene consegnato Numero mittente non verificato Assicurarsi che il numero sia attivato presso il fornitore
Il destinatario non riceve l'SMS Numero di telefono non in formato internazionale Utilizzare il formato +{prefisso paese}{numero} (ad es. +41791234567)
SMS in arrivo mancanti Webhook non configurato Verificare l'URL del webhook nella dashboard del fornitore
Credito dell'account esaurito Budget a consumo esaurito Ricaricare il credito presso il fornitore
