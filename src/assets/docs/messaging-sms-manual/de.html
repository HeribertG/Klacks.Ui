SMS-Anbieter einrichten

Voraussetzungen

Um SMS-Nachrichten über Klacks zu senden, benötigen Sie ein Konto bei Twilio oder einem Twilio-kompatiblen SMS-Gateway. Klacks verwendet die Twilio-REST-API (Messages-Endpunkt mit Basic-Authentifizierung).

Wichtig: Die SMS-Anbindung ist nur für den Versand ausgelegt. Eingehende SMS werden in Klacks nicht empfangen.

Schritt 1 — Twilio-Konto einrichten

  1. Registrieren Sie sich auf twilio.com und verifizieren Sie Ihre Telefonnummer und E-Mail-Adresse.
  2. Öffnen Sie die Twilio Console. Auf dem Dashboard finden Sie unter Account Info die beiden benötigten Zugangsdaten:
    • Account SID — beginnt mit AC
    • Auth Token — auf „Anzeigen" klicken
  3. Erwerben Sie eine Absendernummer unter Phone Numbers → Buy a number (SMS-fähig). Diese Nummer erscheint als Absender bei ausgehenden SMS.
  4. Testkonten: Mit einem kostenlosen Trial-Konto können SMS nur an vorher verifizierte Nummern gesendet werden und enthalten einen Trial-Hinweis.

Hinweis: Behandeln Sie das Auth Token wie ein Passwort. Teilen Sie es nicht öffentlich und speichern Sie es sicher.

Schritt 2 — SMS-Anbieter in Klacks konfigurieren

  1. Navigieren Sie zu Einstellungen → Messaging-Anbieter.
  2. Klicken Sie auf Hinzufügen.
  3. Füllen Sie die Felder wie folgt aus:

Schritt 3 — Nachrichten über den Chatbot (Klacksy) senden

Sobald der SMS-Anbieter konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten versenden. Sie müssen keine Telefonnummern kennen — verwenden Sie einfach den Namen des Mitarbeiters oder Klienten: 

"Sende eine SMS an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine SMS: Die Schicht wurde getauscht."
"Benachrichtige Peter Müller per SMS, dass sein Dienst am Montag ausfällt."

Klacksy sucht automatisch die hinterlegte Mobilnummer des Empfängers und verwendet den konfigurierten SMS-Anbieter. Der Versand ist für Sie vollständig transparent — Sie arbeiten mit Namen, Klacksy kümmert sich um den Rest.

Voraussetzung: Beim Empfänger muss eine Mobilnummer in Klacks hinterlegt sein (unter Adresse → Kontaktdaten), im internationalen Format (z.B. +41791234567).

Eingehende Nachrichten

Die SMS-Anbindung unterstützt keinen Empfang — Antworten auf versendete SMS werden nicht an Klacks übertragen. Die Messaging-Inbox zeigt für diesen Anbieter daher keine eingehenden Nachrichten an.
