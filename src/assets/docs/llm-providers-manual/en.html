Search for LLM Providers — Manual

What is this for?

This view suggests LLM providers you don't yet have in your list and adds the selected ones with a single click, so you don't have to type the name and base URL by hand. Only OpenAI-compatible API providers are suggested — exactly the kind of service your already configured providers use too.

The table columns

Provider Name

The display name of the provider (e.g. "OpenRouter", "xAI (Grok)").

Base URL

The API address used to talk to the provider (e.g. https://api.x.ai/v1/). This exact URL is used when the provider is created.

Source

Indicates where the suggestion comes from:

  • Catalog — from a built-in, vetted list of known providers. The base URLs are verified and therefore reliable.
  • Web — found via internet search and evaluated automatically. These entries only appear when web search is configured in the settings. They are helpful, but when in doubt you should double-check the base URL.

Reachability

Before being shown, each suggestion is tested live (a call to the /models endpoint):

  • Reachable — the API responds, the provider works.
  • Reachable (key required) — the API is there but requires an API key, so the address is correct.
  • Not reachable — the address does not respond. Such entries cannot be selected.

Adding providers

Tick one or more providers and click "Add selected" at the bottom. The chosen providers are created disabled and without an API key. Providers that already exist are not suggested in the first place.

Next steps after adding

A newly added provider is not active yet. Open it in the list, enter the API key and enable it. After that it works just like your other providers. The individual models of a provider are still maintained separately via the model management.
