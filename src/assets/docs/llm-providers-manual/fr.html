Rechercher des fournisseurs LLM — Manuel

À quoi sert cette fonction ?

Cette vue te propose des fournisseurs LLM que tu n'as pas encore dans ta liste et ajoute ceux que tu sélectionnes en un clic, t'évitant de saisir le nom et l'URL de base à la main. Seuls des fournisseurs d'API compatibles OpenAI sont proposés — exactement le type de service qu'utilisent aussi tes fournisseurs déjà configurés.

Les colonnes du tableau

Nom du fournisseur

Le nom d'affichage du fournisseur (p. ex. « OpenRouter », « xAI (Grok) »).

URL de base

L'adresse de l'API utilisée pour communiquer avec le fournisseur (p. ex. https://api.x.ai/v1/). C'est cette URL qui sera utilisée lors de la création.

Source

Indique d'où provient la suggestion :

  • Catalogue — d'une liste intégrée et vérifiée de fournisseurs connus. Les URL de base sont vérifiées et donc fiables.
  • Web — trouvé via une recherche Internet et évalué automatiquement. Ces entrées n'apparaissent que si la recherche web est configurée dans les paramètres. Elles sont utiles, mais en cas de doute vérifie l'URL de base.

Accessibilité

Avant l'affichage, chaque suggestion est testée en direct (appel du point de terminaison /models) :

  • Accessible — l'API répond, le fournisseur fonctionne.
  • Accessible (clé requise) — l'API est présente mais exige une clé API ; l'adresse est donc correcte.
  • Non accessible — l'adresse ne répond pas. Ces entrées ne peuvent pas être sélectionnées.

Ajouter des fournisseurs

Coche un ou plusieurs fournisseurs et clique en bas sur « Ajouter la sélection ». Les fournisseurs choisis sont créés désactivés et sans clé API. Les fournisseurs déjà présents ne sont pas proposés.

Étapes suivantes après l'ajout

Un fournisseur nouvellement ajouté n'est pas encore actif. Ouvre-le dans la liste, saisis la clé API et active-le. Il fonctionnera alors comme tes autres fournisseurs. Les modèles d'un fournisseur se gèrent toujours séparément via la gestion des modèles.
