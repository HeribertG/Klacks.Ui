Cerca provider LLM — Manuale

A cosa serve questa funzione?

Questa vista ti propone provider LLM che non hai ancora nel tuo elenco e aggiunge quelli selezionati con un clic, così non devi inserire nome e URL di base a mano. Vengono proposti esclusivamente provider con API compatibili OpenAI — esattamente il tipo di servizio che usano anche i provider che hai già configurato.

Le colonne della tabella

Nome provider

Il nome visualizzato del provider (es. «OpenRouter», «xAI (Grok)»).

URL di base

L'indirizzo dell'API usato per comunicare con il provider (es. https://api.x.ai/v1/). È proprio questo URL che verrà usato alla creazione.

Origine

Indica da dove proviene il suggerimento:

  • Catalogo — da un elenco integrato e verificato di provider noti. Gli URL di base sono verificati e quindi affidabili.
  • Web — trovato tramite ricerca su Internet e valutato automaticamente. Queste voci compaiono solo se la ricerca web è configurata nelle impostazioni. Sono utili, ma in caso di dubbio controlla l'URL di base.

Raggiungibilità

Prima della visualizzazione ogni suggerimento viene testato in tempo reale (chiamata all'endpoint /models):

  • Raggiungibile — l'API risponde, il provider funziona.
  • Raggiungibile (chiave necessaria) — l'API c'è ma richiede una chiave API, quindi l'indirizzo è corretto.
  • Non raggiungibile — l'indirizzo non risponde. Queste voci non possono essere selezionate.

Aggiungere provider

Spunta uno o più provider e clicca in basso su «Aggiungi selezionati». I provider scelti vengono creati disattivati e senza chiave API. I provider già presenti non vengono proposti.

Passaggi successivi dopo l'aggiunta

Un provider appena aggiunto non è ancora attivo. Aprilo nell'elenco, inserisci la chiave API e attivalo. Dopodiché funziona come gli altri tuoi provider. I singoli modelli di un provider si gestiscono sempre separatamente tramite la gestione dei modelli.
