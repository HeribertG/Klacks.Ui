Importazione collaboratori – Manuale

Cos'è l'importazione dei collaboratori?

L'importazione dei collaboratori riprende un intero elenco del personale da un file Excel (.xlsx) o un file CSV (.csv) con una riga per persona, invece di inserire ogni persona a mano. Klacks riconosce automaticamente le colonne, mostra in un'anteprima come apparirà ogni record e salva solo dopo la conferma. Oltre ai collaboratori, lo stesso file può contenere anche collaboratori esterni e clienti.

  • Chi può importare: solo gli amministratori. La scheda Importa collaboratori si trova nelle impostazioni, sezione Importazione; questa sezione compare solo se l'interruttore Expert Mode in alto nella pagina delle impostazioni è attivo. La scheda ha le linguette Importazione e Manuale; l'importazione inizia direttamente sulla scheda. Gli altri utenti non vedono la scheda e per l'importazione devono rivolgersi a un amministratore.
  • Protezione dei dati: il file stesso non viene salvato. Viene soltanto letto; vengono create solo le righe confermate nell'anteprima.
  • Come funziona: il file va trascinato sulla zona di caricamento della scheda. Si apre poi una finestra con tre passi: Associazione & regole → Anteprima → Risultato. Il presente manuale si trova nella linguetta Manuale della scheda; nella finestra il pulsante Manuale lo apre in una seconda finestra, senza perdere l'importazione in corso.

File supportati

  • Excel (.xlsx) e CSV (.csv); un file .txt viene letto come un file CSV. Il vecchio formato Excel .xls non è supportato – salvare prima il file in formato .xlsx in Excel.
  • Cartelle di lavoro Excel: vengono letti solo i fogli visibili, per impostazione predefinita il primo. Per una cartella di lavoro con più fogli, nel passo Associazione & regole viene offerta la scelta Foglio. Di una formula viene importato il risultato calcolato. Le celle formattate come data vengono lette come date. I numeri nelle celle con formato «Generale» perdono gli zeri iniziali (l'NPA 01234 diventa 1234) – formattare tali colonne come testo (il modello lo fa già).
  • Codifica dei file CSV: vengono riconosciuti UTF-8 (con o senza indicatore dell'ordine dei byte) e UTF-16 con indicatore dell'ordine dei byte; qualsiasi altro file viene letto come Windows-1252 (il consueto formato «ANSI» di Excel per Windows in Europa occidentale), quindi dieresi e accenti dell'Europa occidentale vengono resi correttamente senza alcuna impostazione. Per tutte le altre scritture e lettere (ad esempio ł, ř, ș, greco, arabo, ebraico, cinese, giapponese, coreano o thailandese), salvare il file come «CSV UTF-8» oppure usare .xlsx.
  • Separatore dei file CSV: punto e virgola, virgola, tabulazione o barra verticale (|) vengono rilevati automaticamente. I valori tra virgolette possono contenere il separatore e interruzioni di riga.
  • Riga di intestazione: la prima riga con i nomi delle colonne deve trovarsi entro le prime 10 righe non vuote e contenere almeno due celle di testo. Le righe soprastanti (ad esempio un titolo) e le righe vuote vengono ignorate.
  • Formati della data: giorno, mese e anno separati da punto, barra o trattino, ad esempio 31.12.1990, 12/31/1990 o 1990-12-31; un orario dopo la data viene ignorato. Un valore che inizia con un anno a quattro cifre viene sempre letto come anno-mese-giorno. Se dal file non si capisce se viene prima il giorno o il mese (nessun valore superiore a 12), Klacks presuppone giorno/mese/anno e chiede di verificare il formato della data nel passo Associazione & regole. I nomi dei mesi (ad esempio «31 dic 1990») non vengono riconosciuti.
  • Anni a due cifre: gli anni fino alle ultime due cifre dell'anno in corso valgono come 20xx, quelli superiori come 19xx (nel 2026: «26» = 2026, «27» = 1927). L'anteprima segnala ciascuna di queste date con un avviso, affinché il secolo possa essere verificato.

Limiti ed elenchi di grandi dimensioni

  • Al massimo 5 MB per file.
  • Al massimo 1000 righe per importazione – contano le righe di dati sotto la riga di intestazione, senza le righe vuote.
  • Al massimo 60 colonne. In Excel conta l'ultima colonna utilizzata: un solo valore dimenticato molto a destra rende il file troppo largo.
  • Una cella può contenere al massimo 1000 caratteri; un contenuto più lungo viene troncato. Nome, cognome, titolo e azienda possono avere al massimo 100 caratteri ciascuno, così come indirizzo e-mail, numero di telefono e numero di cellulare.
  • Un file Excel può contenere al massimo 20 MB una volta decompresso (protezione contro i file manipolati).

Elenchi di grandi dimensioni: suddividere l'elenco in più file di al massimo 1000 righe ciascuno; ogni file deve avere la propria riga di intestazione. Le colonne non necessarie possono essere eliminate in precedenza. Importare quindi i file uno dopo l'altro. Le persone già importate da un file precedente vengono riconosciute come duplicati se hanno un indirizzo e-mail o una data di nascita (vedi Duplicati).

Modello

Il pulsante Scarica il modello sulla scheda fornisce un file Excel nella lingua dell'utente (nome del file klacks-employee-import-it.xlsx). Con il modello tutte le colonne vengono riconosciute con certezza. La sua riga di intestazione è in grassetto e bloccata, tutte le colonne sono formattate come testo (zeri iniziali e date restano come digitati) e l'intestazione della colonna Tipo contiene una nota con i valori ammessi. Il modello non ha una riga di esempio, perché verrebbe importata.

Colonne del modello, in questo ordine: Nome, Cognome, Titolo, Azienda, Tipo, Sesso, Data di nascita, Via, Complemento indirizzo, CAP, Località, Cantone, Paese, Posta elettronica, Telefono, Cellulare, Data di entrata, Data di uscita, Contratto, Gruppo, Osservazioni. Funzionano anche elenchi propri – Klacks riconosce i nomi delle colonne anche in tutte le 25 lingue di Klacks e in molte varianti consuete (ad esempio «Nominativo», «Codice postale», «Data di assunzione»).

Scegliere il file

  • Trascinare il file nella zona di caricamento della scheda oppure fare clic sulla zona per scegliere un file. Klacks legge il file e apre la finestra con il passo 1.
  • Un problema con il file (formato errato, file troppo grande, troppe righe o colonne, nessuna riga di intestazione) viene mostrato direttamente sotto la zona di caricamento e la finestra non si apre; vedi Errori frequenti e soluzioni.

Passo 1 – Associazione & regole

Associa le colonne

  • Ogni colonna del file compare su una riga con fino a tre valori di esempio, il campo proposto da Klacks (Importa come) e il grado di certezza della proposta (Affidabilità).
  • Ogni proposta può essere modificata nel menu a tendina. Una colonna che non deve essere importata viene impostata su Non importare. Ogni campo può essere assegnato a una sola colonna.
  • Formato data compare quando il file contiene date; se dal file non si ricava l'ordine di giorno e mese, la selezione deve essere verificata.
  • Ordine nel campo del nome compare per una colonna con il nome completo: Nome Cognome o Cognome Nome. Una virgola («Rossi, Anna») significa sempre che il cognome viene per primo. Il nome completo compila solo un nome o un cognome che non ha una colonna propria o che è vuoto in una riga.

Regole per le informazioni mancanti

Queste regole valgono per tutte le righe:

  • Contratto se non indicato e Gruppo se non indicato – utilizzati per le righe senza contratto o gruppo, oppure con un nome che non esiste.
  • Data di entrata se non indicata – vuoto significa oggi. La data è anche l'inizio del contratto, dell'assegnazione al gruppo e dell'indirizzo.
  • Paese se non indicato – predefinito Paese dell'installazione.
  • Salva gli indirizzi e-mail come, Salva i numeri di telefono come, Salva i numeri di cellulare come – privato o aziendale; vale per tutte le righe.
  • Ex collaboratori (uscita nel passato) – Saltare (predefinito) o Importare con la data di uscita. Una data di uscita pari a oggi o successiva viene sempre importata.
  • Possibili duplicati – Saltare (predefinito) o Creare comunque.

I pulsanti si trovano in basso nella finestra: Continua all'anteprima prosegue; Scegli un altro file chiude la finestra e ricomincia sulla scheda con un file diverso.

Passo 2 – Anteprima

  • Un riepilogo conta le righe: totali, pronte, saltate, con errori, duplicati e con avvisi. Le note che riguardano tutte le righe o molte di esse compaiono una sola volta sopra la tabella, insieme alle colonne che non vengono importate.
  • La tabella mostra ogni riga così come verrà salvata, prima gli errori, poi gli avvisi e le indicazioni. Mostra solo le righe con problemi restringe l'elenco.
  • Per ogni riga: Salta esclude la riga; Selezioni imposta il sesso di una riga che ne è priva; Crea comunque mantiene una riga riconosciuta come duplicato.
  • Gli altri valori non possono essere modificati nell'anteprima. Per correggerli, modificare l'associazione con Indietro, oppure sistemare il file e sceglierlo di nuovo con Indietro e Scegli un altro file.
  • Il pulsante di importazione in basso nella finestra indica quante persone verranno create (ad esempio Importa 25 collaboratori). Resta disattivato finché una riga presenta ancora un errore: correggere la riga o saltarla.

Passo 3 – Risultato

Mostra quante persone sono state create, quante righe sono state saltate e quanti indirizzi vengono localizzati sulla mappa in background. All'elenco dei collaboratori apre l'elenco, Importa un altro file chiude la finestra per il file successivo.

Chiudere la finestra

La × in alto a destra e il tasto Esc chiudono subito la finestra, senza chiedere conferma. Durante l'associazione e l'anteprima non è ancora stato salvato nulla, quindi l'importazione viene semplicemente scartata. Mentre l'importazione viene salvata, la finestra non può essere chiusa. In seguito la scheda mostra di nuovo la zona di caricamento.

Tipo e azienda

  • La colonna Tipo indica per ogni riga se si tratta di un collaboratore, di un collaboratore esterno o di un cliente. Valori riconosciuti sono ad esempio Collaboratore, Collaboratrice, Dipendente (collaboratore), Esterno, Esterna, Collaboratore esterno (collaboratore esterno) e Cliente (cliente); funzionano anche i termini corrispondenti di tutte le altre lingue di Klacks e i numeri 0, 1 e 2. Maiuscole e minuscole non hanno importanza.
  • Una cella vuota o un file senza colonna del tipo significa collaboratore. Un valore sconosciuto è un errore nell'anteprima.
  • Cliente con azienda: creato come azienda (persona giuridica), non come persona. Nome e cognome sono facoltativi e vengono mantenuti come persona di contatto (l'anteprima li contrassegna con Persona di contatto:); un sesso indicato nella riga viene ignorato. Una tale riga richiede un indirizzo con NPA, località e paese (vale il paese predefinito).
  • Cliente senza azienda: creato come persona – nome, cognome e sesso sono obbligatori.
  • Collaboratore o collaboratore esterno con azienda: resta una persona; il nome dell'azienda viene salvato con la persona.
  • I clienti non ricevono mai un contratto – né dal file (avviso, il valore non viene importato) né dalle regole. Un gruppo viene invece assegnato anche ai clienti.

Sesso e appellativo

  • Le persone necessitano di un sesso: Femminile, Maschile o Diverso. Viene ricavato dalla colonna Sesso; se questa è vuota, dalla colonna Appellativo (l'anteprima lo segnala). In assenza di entrambe, il sesso viene scelto riga per riga nell'anteprima (Selezioni).
  • Valori riconosciuti sono ad esempio Signora, Sig.ra, Signorina, Donna (femminile), Signore, Sig., Uomo (maschile) e Diverso, Intersessuale, Altro (diverso) – oltre ai termini corrispondenti di tutte le altre lingue di Klacks, come Herr/Frau o Monsieur/Madame.
  • Maiuscole e minuscole, accenti e punteggiatura non hanno importanza; per un appellativo più lungo conta la prima parola («Signore Dr.» = maschile).
  • Un'azienda (cliente con azienda) non necessita di un sesso.

Contratto e gruppo

  • Un valore del file viene confrontato con i nomi dei contratti e dei gruppi esistenti; maiuscole e minuscole e spazi all'inizio o alla fine non hanno importanza.
  • Se il nome non esiste, esiste più volte o è vuoto, viene utilizzato il contratto o il gruppo delle regole e l'anteprima lo segnala. Senza regola la riga non riceve alcun contratto o alcun gruppo.
  • L'importazione non crea contratti né gruppi. Crearli prima nelle impostazioni e nella pagina dei gruppi, poi importare.
  • Contratto e gruppo iniziano alla data di entrata e terminano alla data di uscita, se presente.

Numero del personale

Klacks assegna sempre autonomamente il numero del personale. Una colonna con il numero del personale nel file viene riconosciuta ma ignorata; l'anteprima mostra un'indicazione. Per conservare i numeri di un altro sistema, la colonna può essere associata a Nota nel passo Associazione & regole, purché nessun'altra colonna venga importata come nota.

Duplicati

  • Persone: una riga è considerata un duplicato se l'indirizzo e-mail è uguale, oppure se nome, cognome e data di nascita sono uguali. Maiuscole e minuscole, accenti e trattini vengono ignorati («Müller» = «Muller», «Hans-Peter» = «Hanspeter»).
  • Aziende (clienti con azienda): stessa azienda, stesso NPA e stessa via.
  • Le righe vengono confrontate con le persone già presenti in Klacks e con le righe precedenti dello stesso file. I clienti vengono confrontati solo con clienti, collaboratori e collaboratori esterni tra loro.
  • I duplicati vengono saltati con la regola Possibili duplicati = Saltare. Con Creare comunque – come regola per tutte le righe o riga per riga nell'anteprima – vengono comunque creati.
  • Solo un'indicazione, senza esclusione: stesso nome senza data di nascita corrispondente, oppure stessa azienda a un altro indirizzo. Verificare tali righe prima dell'importazione.

Salvataggio e indirizzi

  • Tutto o niente: l'importazione salva tutte le righe pronte in un'unica operazione. Se qualcosa non riesce, non viene salvato nulla. Prima del salvataggio Klacks verifica di nuovo tutte le righe rispetto ai dati attuali.
  • Per ogni riga vengono creati: la persona (o l'azienda), il periodo di impiego dalla data di entrata alla data di uscita, l'indirizzo, l'indirizzo e-mail, i numeri di telefono e di cellulare, il contratto, il gruppo e la nota.
  • La stessa importazione non può essere salvata due volte; un secondo tentativo indica che l'importazione è già stata eseguita.
  • Mappa: dopo l'importazione, gli indirizzi con NPA e località vengono localizzati sulla mappa in background, uno dopo l'altro. Con molti indirizzi ciò può richiedere alcuni minuti; nel frattempo le persone possono già essere utilizzate.

Errori frequenti e soluzioni

Messaggio Causa Soluzione
Questo formato di file non è supportato. Utilizzi un file .xlsx o .csv. .xls, .ods, PDF o un file danneggiato. Salvare il file in Excel come .xlsx o esportarlo come CSV.
Il file è troppo grande (massimo 5 MB). File superiore a 5 MB, ad esempio a causa di immagini o fogli inutilizzati. Rimuovere immagini e fogli inutilizzati, oppure suddividere l'elenco.
Il file contiene troppe righe (massimo 1000 persone per importazione). Più di 1000 righe di dati. Suddividere l'elenco in più file (vedi Limiti ed elenchi di grandi dimensioni).
Il file contiene troppe colonne (massimo 60). Più di 60 colonne, spesso a causa di un valore isolato molto a destra. Eliminare le colonne inutilizzate, comprese quelle apparentemente vuote sul bordo destro.
Nelle prime righe non è stata trovata alcuna riga di intestazione con i nomi delle colonne. Nessuna riga con almeno due nomi di colonna entro le prime 10 righe. Inserire una riga di intestazione con i nomi delle colonne sopra i dati.
Il file non contiene dati. File vuoto, solo una riga di intestazione o nessun foglio visibile. Verificare il file; scoprire il foglio nascosto in Excel.
Manca il sesso – selezioni. Sesso o appellativo assente o non riconosciuto. Scegliere il sesso nell'anteprima, oppure compilare la colonna nel file.
Manca il nome. / Manca il cognome. Colonna del nome vuota o non associata; un nome completo composto da una sola parola. Verificare l'associazione nel passo Associazione & regole o completare il file.
Data non valida: «…». Data illeggibile, data di nascita nel futuro o data di uscita anteriore alla data di entrata. Verificare il formato della data nel passo Associazione & regole o correggere il valore nel file.
Tipo «…» sconosciuto – usare dipendente, esterno o cliente. Valore nella colonna del tipo non riconosciuto. Utilizzare uno dei valori indicati nella nota del modello, oppure lasciare la cella vuota (= collaboratore).
Un cliente con azienda richiede un indirizzo con CAP, località e paese. Riga di un'azienda senza indirizzo completo. Completare NPA e località; indicare un paese nel file o nelle regole.
Valore troppo lungo (al massimo … caratteri). Nome, titolo, azienda, e-mail o telefono più lunghi di 100 caratteri. Accorciare il valore nel file.
Contratto «…» non trovato. / Gruppo «…» non trovato. Il nome non corrisponde ai contratti e ai gruppi presenti in Klacks. Correggere il nome, oppure creare prima il contratto o il gruppo; altrimenti si applica la regola.
Alcune righe contengono ancora errori. Le corregga o salti queste righe, poi riprovi. Almeno una riga presenta un errore. Utilizzare Mostra solo le righe con problemi, quindi correggere o saltare tali righe.
Una delle regole per le informazioni mancanti non è più valida … Un contratto o un gruppo scelto nelle regole è stato eliminato nel frattempo. Verificare le regole nel passo Associazione & regole.

Dopo l'importazione

  • Le persone importate sono normali record. Gli errori si correggono o si eliminano nella pagina della persona; non esiste un «annulla» per l'intera importazione.
  • Importando lo stesso file una seconda volta, le righe con un indirizzo e-mail o una data di nascita vengono di nuovo riconosciute come duplicati. Le righe con il solo nome vengono soltanto segnalate – verificarle prima di importare una seconda volta.
  • Una singola persona si crea a mano nella pagina dei collaboratori; una directory aziendale può essere sincronizzata da un amministratore tramite le impostazioni del provider di identità.
