Configurer la messagerie KakaoTalk

Conditions préalables

Pour envoyer des messages via KakaoTalk, vous avez besoin d'une application sur developers.kakao.com (Kakao Developers). KakaoTalk est le messager dominant en Corée du Sud. L'intégration Klacks utilise l'API développeur de Kakao (« envoyer un message aux amis »).

Limitations importantes de l'API développeur Kakao :

  • L'intégration est conçue uniquement pour l'envoi — pas de réception.
  • Le token d'accès est de courte durée (env. 6 heures) et doit être renouvelé en dehors de Klacks puis saisi à nouveau.
  • Les messages ne peuvent être envoyés qu'aux utilisateurs connectés comme « amis » Kakao de l'application et ayant consenti à la réception de messages.
  • Pour les messages professionnels en production (AlimTalk), un canal business via des agences autorisées est requis en Corée — cette intégration ne couvre pas cela ; elle utilise l'API développeur.

Étape 1 — Configurer une application Kakao Developers

  1. Créez une application sur developers.kakao.com.
  2. Activez Kakao Login pour l'application.
  3. Activez les scopes talk_message et friends.
  4. Obtenez un token d'accès via le flux OAuth de Kakao Login (l'utilisateur au nom duquel les messages sont envoyés doit consentir aux scopes).

Remarque : traitez le token d'accès comme un mot de passe. Ne le partagez pas publiquement et conservez-le en lieu sûr.

Étape 2 — Configurer KakaoTalk dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  1. Cliquez sur Enregistrer.
  2. Testez la connexion à l'aide du bouton Tester dans la liste des fournisseurs.

Important : Le token d'accès expire après env. 6 heures. Klacks ne le renouvelle pas automatiquement — vous devez le renouveler en externe (flux refresh token de Kakao) et le saisir à nouveau dans Klacks.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur KakaoTalk configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les ID — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement l'identifiant enregistré du destinataire et utilise le fournisseur KakaoTalk configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : L'UUID d'ami (friend UUID) issu de l'API friends de Kakao doit être enregistré dans Klacks pour le destinataire (sous Adresse → Coordonnées). Le destinataire doit être connecté comme « ami » Kakao de l'application — il est impossible d'envoyer à d'autres utilisateurs.

Messages entrants

L'intégration KakaoTalk ne prend pas en charge la réception — les réponses aux messages envoyés ne sont pas transmises à Klacks. La boîte de réception de messagerie n'affiche donc aucun message entrant pour ce fournisseur.
