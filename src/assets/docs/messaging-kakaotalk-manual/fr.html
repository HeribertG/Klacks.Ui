Configurer KakaoTalk

Conditions préalables

Pour envoyer et recevoir des messages via KakaoTalk avec Klacks, vous avez besoin d'un compte Kakao Developers et d'un Kakao Talk Channel enregistré. KakaoTalk est le messageur dominant en Corée du Sud avec environ 93% de part de marché.

Remarque : un Kakao Talk Channel est requis pour les messages professionnels. Les messages privés sans channel ne sont pas possibles.

Étape 1 — Créer un compte Kakao Developers

  1. Inscrivez-vous sur developers.kakao.com.
  2. Créez une nouvelle application (app) dans le tableau de bord développeur.
  3. Notez la clé d'application (App Key) dans les paramètres de l'app.
  4. Enregistrez un Kakao Talk Channel et associez-le à votre application.
  5. Créez un modèle de message (template) et notez l'ID du template.

Étape 2 — Configurer KakaoTalk dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  2. Testez la connexion à l'aide du bouton Tester dans la liste des fournisseurs.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur KakaoTalk configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les numéros de téléphone — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement le numéro de téléphone du destinataire et utilise le fournisseur KakaoTalk configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : Le destinataire doit avoir un numéro de mobile enregistré dans Klacks (sous Adresse → Coordonnées).

Étape 4 — Recevoir des messages entrants (Webhook)

Pour afficher les messages KakaoTalk entrants dans Klacks, un webhook doit être configuré.

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Notez le secret du webhook généré automatiquement pour votre fournisseur KakaoTalk.
  3. Configurez l'URL du webhook dans le tableau de bord Kakao Developers : 
    https://{votre-domaine}/api/messaging/webhook/kakaotalk
  4. Les messages entrants apparaîtront désormais en temps réel dans la boîte de réception de messagerie.

Dépannage

ProblèmeCause possibleSolution
Le test de connexion échoue Clé d'application ou ID du template incorrect Vérifiez les identifiants dans le tableau de bord Kakao Developers
Le message n'est pas livré Kakao Talk Channel non associé Assurez-vous que le channel est connecté à l'application
Le destinataire ne reçoit pas le message Numéro de mobile non enregistré ou destinataire non utilisateur de KakaoTalk Vérifiez si le destinataire utilise KakaoTalk et que le numéro est correct
Les messages entrants manquent Webhook non configuré Vérifiez l'URL du webhook dans le tableau de bord Kakao Developers
Erreur de template Template non approuvé ou ID incorrect Vérifiez le statut du template dans le tableau de bord Kakao Developers
