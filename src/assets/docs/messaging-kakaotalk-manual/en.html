Setting up KakaoTalk

Prerequisites

To send and receive messages via KakaoTalk through Klacks, you need a Kakao Developers account and a registered Kakao Talk Channel. KakaoTalk is the dominant messenger in South Korea with approximately 93% market share.

Note: A Kakao Talk Channel is required for business messages. Private messages without a channel are not possible.

Step 1 — Create a Kakao Developers account

  1. Sign up at developers.kakao.com.
  2. Create a new application (app) in the developer dashboard.
  3. Note down the App Key from the app settings.
  4. Register a Kakao Talk Channel and link it to your app.
  5. Create a message template and note down the Template ID.

Step 2 — Configure KakaoTalk in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:
FieldDescriptionExample
NameUnique internal namekakaotalk-main
Display NameShown in the user interfaceKakaoTalk
Provider TypeSelect KakaoTalkKakaoTalk
App KeyApp Key from the Kakao Developers dashboardabc123def456...
Template IDID of the message template12345
EnabledTurns the provider on/offYes
  1. Click Save.
  2. Test the connection using the Test button in the provider list.

Step 3 — Send messages via the chatbot (Klacksy)

Once the KakaoTalk provider is configured and enabled, the chatbot Klacksy can send messages. You don't need to know any phone numbers — simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Müller that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's phone number and uses the configured KakaoTalk provider. The process is fully transparent to you — you work with names, Klacksy takes care of the rest.

Prerequisite: The recipient must have a mobile number stored in Klacks (under Address → Contact Details).

Step 4 — Receive incoming messages (Webhook)

To display incoming KakaoTalk messages in Klacks, a webhook must be configured.

  1. Go to Settings → Messaging Providers.
  2. Note the automatically generated webhook secret of your KakaoTalk provider.
  3. Configure the webhook URL in the Kakao Developers dashboard: 
    https://{your-domain}/api/messaging/webhook/kakaotalk
  4. Incoming messages will now appear in real time in the Messaging Inbox.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails App Key or Template ID incorrect Check the credentials in the Kakao Developers dashboard
Message not delivered Kakao Talk Channel not linked Make sure the channel is connected to the app
Recipient does not receive message Mobile number not registered or recipient not a KakaoTalk user Check if the recipient uses KakaoTalk and the number is correct
Incoming messages missing Webhook not configured Check the webhook URL in the Kakao Developers dashboard
Template error Template not approved or ID incorrect Check the template status in the Kakao Developers dashboard
