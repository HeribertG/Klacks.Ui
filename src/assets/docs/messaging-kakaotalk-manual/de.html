KakaoTalk einrichten

Voraussetzungen

Um Nachrichten über KakaoTalk mit Klacks zu senden und zu empfangen, benötigen Sie ein Kakao Developers Konto und einen registrierten Kakao Talk Channel. KakaoTalk ist der dominierende Messenger in Südkorea mit ca. 93% Marktanteil.

Hinweis: Für Business-Nachrichten ist ein Kakao Talk Channel erforderlich. Privatnachrichten ohne Channel sind nicht möglich.

Schritt 1 — Kakao Developers Konto erstellen

  1. Registrieren Sie sich auf developers.kakao.com.
  2. Erstellen Sie eine neue Anwendung (App) im Developer-Dashboard.
  3. Notieren Sie sich den App-Schlüssel (App Key) aus den App-Einstellungen.
  4. Registrieren Sie einen Kakao Talk Channel und verknüpfen Sie ihn mit Ihrer App.
  5. Erstellen Sie ein Nachrichten-Template und notieren Sie die Template-ID.

Schritt 2 — KakaoTalk in Klacks konfigurieren

  1. Navigieren Sie zu Einstellungen → Messaging-Anbieter.
  2. Klicken Sie auf Hinzufügen.
  3. Füllen Sie die Felder wie folgt aus:

AnbietertypWählen Sie KakaoTalkKakaoTalk
App-SchlüsselApp Key aus dem Kakao Developers Dashboardabc123def456...
Template-IDID des Nachrichten-Templates12345
AktiviertSchaltet den Anbieter ein/ausJa
  1. Klicken Sie auf Speichern.
  2. Testen Sie die Verbindung über den Test-Button in der Anbieter-Liste.

Schritt 3 — Nachrichten über den Chatbot (Klacksy) senden

Sobald der KakaoTalk-Anbieter konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten versenden. Sie müssen keine Telefonnummern kennen — verwenden Sie einfach den Namen des Mitarbeiters oder Klienten: 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht: Die Schicht wurde getauscht."
"Benachrichtige Peter Müller, dass sein Dienst am Montag ausfällt."

Klacksy sucht automatisch die hinterlegte Telefonnummer des Empfängers und verwendet den konfigurierten KakaoTalk-Anbieter. Der Versand ist für Sie vollständig transparent — Sie arbeiten mit Namen, Klacksy kümmert sich um den Rest.

Voraussetzung: Beim Empfänger muss eine Mobilnummer in Klacks hinterlegt sein (unter Adresse → Kontaktdaten).

Schritt 4 — Eingehende Nachrichten empfangen (Webhook)

Um eingehende KakaoTalk-Nachrichten in Klacks anzuzeigen, muss ein Webhook konfiguriert werden.

  1. Gehen Sie zu Einstellungen → Messaging-Anbieter.
  2. Notieren Sie das automatisch generierte Webhook-Secret Ihres KakaoTalk-Anbieters.
  3. Konfigurieren Sie im Kakao Developers Dashboard die Webhook-URL: 
    https://{ihre-domain}/api/messaging/webhook/kakaotalk
  4. Eingehende Nachrichten erscheinen nun in Echtzeit in der Messaging-Inbox.

Fehlerbehebung

ProblemMögliche UrsacheLösung
Verbindungstest schlägt fehl App-Schlüssel oder Template-ID falsch Prüfen Sie die Zugangsdaten im Kakao Developers Dashboard
Nachricht wird nicht zugestellt Kakao Talk Channel nicht verknüpft Stellen Sie sicher, dass der Channel mit der App verbunden ist
Empfänger erhält keine Nachricht Mobilnummer nicht registriert oder Empfänger kein KakaoTalk-Nutzer Prüfen Sie, ob der Empfänger KakaoTalk nutzt und die Nummer korrekt ist
Eingehende Nachrichten fehlen Webhook nicht konfiguriert Prüfen Sie die Webhook-URL im Kakao Developers Dashboard
Template-Fehler Template nicht genehmigt oder ID falsch Prüfen Sie den Template-Status im Kakao Developers Dashboard
