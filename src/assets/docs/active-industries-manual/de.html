Aktive Branchen

Klacks liefert Vorlagen-Inhalte für fünf Branchen mit: Spitex/Pflege zu Hause, Gesundheitswesen, Sicherheit, Facility Services und Logistik. Diese Karte legt fest, welches Planungsprofil für Ihr Unternehmen gilt — genau eine Branche oder eine eigene Planungsregel.

Was die Auswahl bewirkt

Nur Vorlagen der gewählten Branche (zum Beispiel Planungsregel- und Qualifikations-Vorlagen) erscheinen in den Auswahllisten der Anwendung. Vorlagen der übrigen Branchen bleiben erhalten — es wird nichts gelöscht.

Über den Pfeil neben jeder Branche lässt sich eine Vorschau aufklappen, die zeigt, welche Planungsregeln und Qualifikationen diese Branche mitbringt.

Eigene Planungsregel

Passt keine der fünf Branchenvorlagen, wählen Sie „Eigene Planungsregel". Es wird keine Branchenvorlage übernommen; Klacksy hilft beim Einrichten einer auf Ihren Betrieb zugeschnittenen Regel, sobald diese Funktion verfügbar ist.

Bestandsdaten

Wurde zuvor eine Mehrfachauswahl gespeichert (ältere Version dieser Karte) oder wurde noch nie gespeichert, ist zunächst keine Option vorausgewählt. Ein Hinweis erscheint, bis Sie explizit ein Profil wählen — erst dann wird der neue Einzelwert gespeichert.
