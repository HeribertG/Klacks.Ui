Active industries

Klacks ships preset content for five industries: home care, healthcare, security, facility services and logistics. This card defines which single planning profile applies to your company — exactly one industry, or a custom planning rule.

What the selection affects

Only presets of the selected industry (for example scheduling rule presets and qualification presets) appear in selection lists throughout the application. Presets of the other industries are kept — nothing is deleted.

Use the arrow next to each industry to expand a preview showing which scheduling rules and qualifications it brings along.

Custom planning rule

If none of the five industry presets fit, choose "Custom planning rule". No industry preset is applied; Klacksy will help you set up a rule tailored to your company once that capability is available.

Existing data

If a multi-selection was saved previously (older version of this card), or the setting was never saved, no option is preselected. A hint is shown until you explicitly choose a profile — only then is the new single value saved.
