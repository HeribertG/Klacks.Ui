Setting up LINE Messaging

Prerequisites

To send and receive messages via LINE, you need a LINE Official Account with a Messaging API channel in the LINE Developers Console. LINE is particularly widespread in Japan, Taiwan, and Thailand.

Note: Push messages have a monthly quota depending on your LINE plan (the free plan is limited). Check the current conditions of your Official Account plan.

Step 1 — Create a LINE Official Account and Messaging API channel

  1. Create a LINE Official Account (via the LINE Official Account Manager).
  2. Open the LINE Developers Console (developers.line.biz) and create a Messaging API channel or link your Official Account to the Messaging API.
  3. In the Messaging API tab, issue a long-lived channel access token.
  4. Note down the channel secret from the Basic Settings tab.

Note: Treat the channel access token and channel secret like passwords. Do not share them publicly and store them securely.

Step 2 — Configure LINE in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:

Step 3 — Send messages via the chatbot (Klacksy)

Once the LINE provider is configured and enabled, the chatbot Klacksy can send messages. You do not need to know any LINE user IDs — simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2:00 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Müller that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's stored LINE user ID and uses the configured LINE provider. The process is fully transparent for you — you work with names, Klacksy takes care of the rest.

Prerequisite: The recipient's LINE user ID (starts with U…) must be stored in Klacks (under Address → Contact Details). The user ID becomes known through incoming messages (visible in the messaging inbox) — for this, the recipient must have added your Official Account as a friend and sent it a message.

Step 4 — Receive incoming messages (webhook)

To display incoming LINE messages in Klacks, the webhook URL must be entered manually in the LINE Developers Console.

  1. Copy the webhook URL displayed in Klacks from the provider settings: 
    https://{your-domain}/api/messaging/webhook/line
  2. Enter this URL in the LINE Developers Console under Messaging API → Webhook settings as the Webhook URL.
  3. Enable the "Use webhook" option.
  4. Make sure your Klacks instance is publicly reachable via HTTPS.
  5. Incoming messages now appear in real time in the messaging inbox.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails Channel access token invalid Issue a new token in the LINE Developers Console
Message is not delivered Recipient has not added the Official Account as a friend or has blocked it The recipient must add the account as a friend in LINE
Sending fails Monthly push quota exhausted Check your plan's quota in the LINE Official Account Manager
Recipient not found LINE user ID not stored Enter the user ID from the messaging inbox under Address → Contact Details
Incoming messages missing Webhook URL not entered or "Use webhook" disabled Check the webhook settings in the LINE Developers Console
