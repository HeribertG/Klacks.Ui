Setting up LINE Messaging API

Prerequisites

To send and receive messages via LINE, you need a LINE Official Account with the Messaging API enabled. LINE is the dominant messenger in Japan, Taiwan and Thailand.

Note: The first 500 messages per month are free of charge. Beyond that, charges apply. For more information, visit developers.line.biz.

Step 1 — Create a LINE Official Account and Messaging API Channel

  1. Sign up at developers.line.biz.
  2. Create a LINE Official Account and enable the Messaging API.
  3. Create a Messaging API Channel in the LINE Developers Console.
  4. Note down the Channel Access Token (long-lived).
  5. Note down the Channel Secret from the channel settings.

Step 2 — Configure LINE in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:
FieldDescriptionExample
NameUnique internal nameline-messaging
Display NameShown in the user interfaceLINE
Provider TypeSelect LINELINE
Channel Access TokenThe long-lived token from the LINE Developers ConsoleeyJhbGci...
Channel SecretThe Channel Secret from the channel settingsa1b2c3d4...
EnabledTurns the provider on/offYes
  1. Click Save.
  2. Test the connection using the Test button in the provider list.

Step 3 — Send messages via the chatbot (Klacksy)

Once the LINE provider is configured and enabled, the chatbot Klacksy can send messages. You don't need to know any LINE User IDs — simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Müller that his shift on Monday is cancelled."

Klacksy automatically looks up the recipient's LINE User ID and uses the configured LINE provider. The process is fully transparent to you — you work with names, Klacksy takes care of the rest.

Prerequisite: The recipient must have a LINE User ID stored in Klacks (under Address → Contact Details).

Step 4 — Receive incoming messages (Webhook)

To display incoming LINE messages in Klacks, a webhook must be configured in the LINE Developers Console.

  1. Go to Settings → Messaging Providers.
  2. Note the automatically generated webhook secret of your LINE provider.
  3. Configure the webhook URL in your LINE Developers Console: 
    https://{your-domain}/api/messaging/webhook/line
  4. Incoming messages will now appear in real time in the Messaging Inbox.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails Channel Access Token or Channel Secret incorrect Check the credentials in the LINE Developers Console
Message not delivered LINE User ID invalid Make sure the LINE User ID is correctly stored
Recipient does not receive the message Recipient has not added the Official Account The recipient must add your LINE Official Account as a friend
Incoming messages missing Webhook not configured Check the webhook URL in the LINE Developers Console
Message limit reached Monthly free quota (500 messages) exhausted Upgrade your LINE plan or wait for the next month
