LINE Messaging API einrichten

Voraussetzungen

Um Nachrichten über LINE zu senden und zu empfangen, benötigen Sie einen LINE Official Account mit aktivierter Messaging API. LINE ist der dominante Messenger in Japan, Taiwan und Thailand.

Hinweis: Die ersten 500 Nachrichten pro Monat sind kostenfrei. Darüber hinaus fallen Kosten an. Weitere Informationen finden Sie auf developers.line.biz.

Schritt 1 — LINE Official Account und Messaging API Channel erstellen

  1. Registrieren Sie sich auf developers.line.biz.
  2. Erstellen Sie einen LINE Official Account und aktivieren Sie die Messaging API.
  3. Erstellen Sie einen Messaging API Channel in der LINE Developers Console.
  4. Notieren Sie sich den Channel Access Token (Long-lived).
  5. Notieren Sie sich das Channel Secret aus den Channel-Einstellungen.

Schritt 2 — LINE in Klacks konfigurieren

  1. Navigieren Sie zu Einstellungen → Messaging-Anbieter.
  2. Klicken Sie auf Hinzufügen.
  3. Füllen Sie die Felder wie folgt aus:

Schritt 3 — Nachrichten über den Chatbot (Klacksy) senden

Sobald der LINE-Anbieter konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten versenden. Sie müssen keine LINE User IDs kennen — verwenden Sie einfach den Namen des Mitarbeiters oder Klienten: 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht: Die Schicht wurde getauscht."
"Benachrichtige Peter Müller, dass sein Dienst am Montag ausfällt."

Klacksy sucht automatisch die hinterlegte LINE User ID des Empfängers und verwendet den konfigurierten LINE-Anbieter. Der Versand ist für Sie vollständig transparent — Sie arbeiten mit Namen, Klacksy kümmert sich um den Rest.

Voraussetzung: Beim Empfänger muss eine LINE User ID in Klacks hinterlegt sein (unter Adresse → Kontaktdaten).

Schritt 4 — Eingehende Nachrichten empfangen (Webhook)

Um eingehende LINE-Nachrichten in Klacks anzuzeigen, muss in der LINE Developers Console ein Webhook konfiguriert werden.

  1. Gehen Sie zu Einstellungen → Messaging-Anbieter.
  2. Notieren Sie das automatisch generierte Webhook-Secret Ihres LINE-Anbieters.
  3. Konfigurieren Sie in der LINE Developers Console die Webhook-URL: 
    https://{ihre-domain}/api/messaging/webhook/line
  4. Eingehende Nachrichten erscheinen nun in Echtzeit in der Messaging-Inbox.
