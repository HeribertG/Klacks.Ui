LINE-Messaging einrichten

Voraussetzungen

Um Nachrichten über LINE zu senden und zu empfangen, benötigen Sie einen LINE Official Account mit einem Messaging-API-Channel in der LINE Developers Console. LINE ist besonders verbreitet in Japan, Taiwan und Thailand.

Hinweis: Push-Nachrichten haben je nach LINE-Tarif ein monatliches Kontingent (der kostenlose Plan ist begrenzt). Prüfen Sie die aktuellen Konditionen Ihres Official-Account-Plans.

Schritt 1 — LINE Official Account und Messaging-API-Channel erstellen

  1. Erstellen Sie einen LINE Official Account (über den LINE Official Account Manager).
  2. Öffnen Sie die LINE Developers Console (developers.line.biz) und erstellen Sie einen Messaging-API-Channel bzw. verknüpfen Sie Ihren Official Account mit der Messaging API.
  3. Stellen Sie im Tab Messaging API einen langlebigen Channel-Access-Token aus (Issue).
  4. Notieren Sie sich das Channel-Secret aus dem Tab Basic Settings.

Hinweis: Behandeln Sie Channel-Access-Token und Channel-Secret wie Passwörter. Teilen Sie sie nicht öffentlich und speichern Sie sie sicher.

Schritt 3 — Nachrichten über den Chatbot (Klacksy) senden

Sobald der LINE-Anbieter konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten versenden. Sie müssen keine LINE-User-IDs kennen — verwenden Sie einfach den Namen des Mitarbeiters oder Klienten: 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht: Die Schicht wurde getauscht."
"Benachrichtige Peter Müller, dass sein Dienst am Montag ausfällt."

Klacksy sucht automatisch die hinterlegte LINE-User-ID des Empfängers und verwendet den konfigurierten LINE-Anbieter. Der Versand ist für Sie vollständig transparent — Sie arbeiten mit Namen, Klacksy kümmert sich um den Rest.

Voraussetzung: Beim Empfänger muss die LINE-User-ID (beginnt mit U…) in Klacks hinterlegt sein (unter Adresse → Kontaktdaten). Die User-ID wird über eingehende Nachrichten bekannt (sichtbar in der Messaging-Inbox) — der Empfänger muss dazu Ihren Official Account als Freund hinzugefügt und ihm eine Nachricht gesendet haben.

Schritt 4 — Eingehende Nachrichten empfangen (Webhook)

Um eingehende LINE-Nachrichten in Klacks anzuzeigen, muss die Webhook-URL manuell in der LINE Developers Console eingetragen werden.

  1. Kopieren Sie die in Klacks angezeigte Webhook-URL aus den Anbieter-Einstellungen: 
    https://{ihre-domain}/api/messaging/webhook/line
  2. Tragen Sie diese URL in der LINE Developers Console unter Messaging API → Webhook settings als Webhook URL ein.
  3. Aktivieren Sie die Option „Use webhook".
  4. Stellen Sie sicher, dass Ihre Klacks-Instanz öffentlich über HTTPS erreichbar ist.
  5. Eingehende Nachrichten erscheinen nun in Echtzeit in der Messaging-Inbox.
