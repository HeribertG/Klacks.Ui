Configurer la messagerie LINE

Conditions préalables

Pour envoyer et recevoir des messages via LINE, vous avez besoin d'un LINE Official Account avec un canal Messaging API dans la LINE Developers Console. LINE est particulièrement répandu au Japon, à Taïwan et en Thaïlande.

Remarque : les messages push ont un quota mensuel selon votre forfait LINE (le forfait gratuit est limité). Vérifiez les conditions actuelles de votre forfait Official Account.

Étape 1 — Créer un LINE Official Account et un canal Messaging API

  1. Créez un LINE Official Account (via le LINE Official Account Manager).
  2. Ouvrez la LINE Developers Console (developers.line.biz) et créez un canal Messaging API ou liez votre Official Account à la Messaging API.
  3. Dans l'onglet Messaging API, émettez un channel access token de longue durée (Issue).
  4. Notez le channel secret depuis l'onglet Basic Settings.

Remarque : traitez le channel access token et le channel secret comme des mots de passe. Ne les partagez pas publiquement et conservez-les en lieu sûr.

Étape 2 — Configurer LINE dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur LINE configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les ID utilisateur LINE — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement l'ID utilisateur LINE enregistré du destinataire et utilise le fournisseur LINE configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : L'ID utilisateur LINE du destinataire (commence par U…) doit être enregistré dans Klacks (sous Adresse → Coordonnées). L'ID utilisateur devient connu via les messages entrants (visible dans la boîte de réception de messagerie) — pour cela, le destinataire doit avoir ajouté votre Official Account comme ami et lui avoir envoyé un message.

Étape 4 — Recevoir les messages entrants (webhook)

Pour afficher les messages LINE entrants dans Klacks, l'URL du webhook doit être saisie manuellement dans la LINE Developers Console.

  1. Copiez l'URL du webhook affichée dans Klacks depuis les paramètres du fournisseur : 
    https://{votre-domaine}/api/messaging/webhook/line
  2. Saisissez cette URL dans la LINE Developers Console sous Messaging API → Webhook settings comme Webhook URL.
  3. Activez l'option « Use webhook ».
  4. Assurez-vous que votre instance Klacks est accessible publiquement via HTTPS.
  5. Les messages entrants apparaissent désormais en temps réel dans la boîte de réception de messagerie.

Dépannage

ProblèmeCause possibleSolution
Le test de connexion échoue Channel access token invalide Émettez un nouveau token dans la LINE Developers Console
Le message n'est pas livré Le destinataire n'a pas ajouté l'Official Account comme ami ou l'a bloqué Le destinataire doit ajouter le compte comme ami dans LINE
L'envoi échoue Quota mensuel de messages push épuisé Vérifiez le quota de votre forfait dans le LINE Official Account Manager
Destinataire introuvable ID utilisateur LINE non enregistré Saisissez l'ID utilisateur depuis la boîte de réception sous Adresse → Coordonnées
Messages entrants manquants URL du webhook non saisie ou « Use webhook » désactivé Vérifiez les Webhook settings dans la LINE Developers Console
