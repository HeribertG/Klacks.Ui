Configurer l'API de messagerie LINE

Conditions préalables

Pour envoyer et recevoir des messages via LINE, vous avez besoin d'un compte LINE Official avec l'API de messagerie activée. LINE est le messager dominant au Japon, à Taïwan et en Thaïlande.

Remarque : les 500 premiers messages par mois sont gratuits. Au-delà, des frais s'appliquent. Pour plus d'informations, consultez developers.line.biz.

Étape 1 — Créer un compte LINE Official et un canal Messaging API

  1. Inscrivez-vous sur developers.line.biz.
  2. Créez un compte LINE Official et activez la Messaging API.
  3. Créez un canal Messaging API dans la console LINE Developers.
  4. Notez le Channel Access Token (longue durée).
  5. Notez le Channel Secret depuis les paramètres du canal.

Étape 2 — Configurer LINE dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur LINE configuré et activé, le chatbot Klacksy peut envoyer des messages. Vous n'avez pas besoin de connaître les LINE User ID — utilisez simplement le nom de l'employé ou du client : 

« Envoie un message à Max Muster : Votre rendez-vous est demain à 14h. »
« Envoie un message à Anna Beispiel : Le service a été échangé. »
« Préviens Peter Müller que son service de lundi est annulé. »

Klacksy recherche automatiquement le LINE User ID du destinataire et utilise le fournisseur LINE configuré. Le processus est entièrement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition préalable : Le destinataire doit avoir un LINE User ID enregistré dans Klacks (sous Adresse → Coordonnées).

Étape 4 — Recevoir des messages entrants (Webhook)

Pour afficher les messages LINE entrants dans Klacks, un webhook doit être configuré dans la console LINE Developers.

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Notez le secret du webhook généré automatiquement pour votre fournisseur LINE.
  3. Configurez l'URL du webhook dans la console LINE Developers : 
    https://{votre-domaine}/api/messaging/webhook/line
  4. Les messages entrants apparaîtront désormais en temps réel dans la boîte de réception de messagerie.
