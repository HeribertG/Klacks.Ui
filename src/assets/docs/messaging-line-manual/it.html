Configurare la messaggistica LINE

Prerequisiti

Per inviare e ricevere messaggi tramite LINE, è necessario un LINE Official Account con un canale Messaging API nella LINE Developers Console. LINE è particolarmente diffuso in Giappone, Taiwan e Thailandia.

Nota: i messaggi push hanno una quota mensile a seconda del piano LINE (il piano gratuito è limitato). Verificare le condizioni attuali del proprio piano Official Account.

Passo 1 — Creare un LINE Official Account e un canale Messaging API

  1. Creare un LINE Official Account (tramite il LINE Official Account Manager).
  2. Aprire la LINE Developers Console (developers.line.biz) e creare un canale Messaging API oppure collegare il proprio Official Account alla Messaging API.
  3. Nella scheda Messaging API emettere un channel access token di lunga durata (Issue).
  4. Annotare il channel secret dalla scheda Basic Settings.

Nota: trattare il channel access token e il channel secret come password. Non condividerli pubblicamente e conservarli in modo sicuro.

Passo 2 — Configurare LINE in Klacks

  1. Navigare su Impostazioni → Fornitori di messaggistica.
  2. Fare clic su Aggiungi.

Passo 3 — Inviare messaggi tramite il chatbot (Klacksy)

Una volta configurato e attivato il fornitore LINE, il chatbot Klacksy può inviare messaggi. Non è necessario conoscere gli ID utente LINE — basta usare il nome del dipendente o del cliente: 

"Invia un messaggio a Max Muster: Il suo appuntamento è domani alle 14:00."
"Manda un messaggio a Anna Beispiel: Il turno è stato scambiato."
"Avvisa Peter Müller che il suo turno di lunedì è annullato."

Klacksy cerca automaticamente l'ID utente LINE registrato del destinatario e utilizza il fornitore LINE configurato. Il processo è completamente trasparente per voi — lavorate con i nomi, Klacksy si occupa del resto.

Prerequisito: l'ID utente LINE del destinatario (inizia con U…) deve essere registrato in Klacks (sotto Indirizzo → Dati di contatto). L'ID utente diventa noto tramite i messaggi in arrivo (visibile nella casella di messaggistica) — a tal fine il destinatario deve aver aggiunto il vostro Official Account come amico e avergli inviato un messaggio.

Passo 4 — Ricevere i messaggi in arrivo (webhook)

Per visualizzare i messaggi LINE in arrivo in Klacks, l'URL del webhook deve essere inserito manualmente nella LINE Developers Console.

  1. Copiare l'URL del webhook mostrato in Klacks dalle impostazioni del fornitore: 
    https://{vostro-dominio}/api/messaging/webhook/line
  2. Inserire questo URL nella LINE Developers Console sotto Messaging API → Webhook settings come Webhook URL.
  3. Attivare l'opzione "Use webhook".
  4. Assicurarsi che la propria istanza Klacks sia raggiungibile pubblicamente tramite HTTPS.
  5. I messaggi in arrivo appaiono ora in tempo reale nella casella di messaggistica.

Risoluzione dei problemi

ProblemaPossibile causaSoluzione
Il test di connessione fallisce Channel access token non valido Emettere un nuovo token nella LINE Developers Console
Il messaggio non viene consegnato Il destinatario non ha aggiunto l'Official Account come amico o lo ha bloccato Il destinatario deve aggiungere l'account come amico in LINE
L'invio fallisce Quota mensile di messaggi push esaurita Verificare la quota del proprio piano nel LINE Official Account Manager
Destinatario non trovato ID utente LINE non registrato Inserire l'ID utente dalla casella di messaggistica sotto Indirizzo → Dati di contatto
Messaggi in arrivo mancanti URL del webhook non inserito o "Use webhook" disattivato Verificare le Webhook settings nella LINE Developers Console
