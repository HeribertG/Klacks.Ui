Configurare l'API di messaggistica LINE

Prerequisiti

Per inviare e ricevere messaggi tramite LINE, è necessario un account LINE Official con la Messaging API attivata. LINE è il messenger dominante in Giappone, Taiwan e Thailandia.

Nota: i primi 500 messaggi al mese sono gratuiti. Oltre tale limite vengono addebitati dei costi. Per ulteriori informazioni, visitare developers.line.biz.

Passo 1 — Creare un account LINE Official e un canale Messaging API

  1. Registrarsi su developers.line.biz.
  2. Creare un account LINE Official e attivare la Messaging API.
  3. Creare un canale Messaging API nella console LINE Developers.
  4. Annotare il Channel Access Token (long-lived).
  5. Annotare il Channel Secret dalle impostazioni del canale.

Passo 2 — Configurare LINE in Klacks

  1. Navigare su Impostazioni → Fornitori di messaggistica.
  2. Fare clic su Aggiungi.
  3. Compilare i campi come segue:

Passo 3 — Inviare messaggi tramite il chatbot (Klacksy)

Una volta configurato e attivato il fornitore LINE, il chatbot Klacksy può inviare messaggi. Non è necessario conoscere i LINE User ID — basta usare il nome del dipendente o del cliente: 

"Invia un messaggio a Max Muster: Il suo appuntamento è domani alle 14:00."
"Manda un messaggio a Anna Beispiel: Il turno è stato scambiato."
"Avvisa Peter Müller che il suo turno di lunedì è annullato."

Klacksy cerca automaticamente il LINE User ID del destinatario e utilizza il fornitore LINE configurato. Il processo è completamente trasparente per voi — lavorate con i nomi, Klacksy si occupa del resto.

Prerequisito: Il destinatario deve avere un LINE User ID registrato in Klacks (sotto Indirizzo → Dati di contatto).

Passo 4 — Ricevere messaggi in arrivo (Webhook)

Per visualizzare i messaggi LINE in arrivo in Klacks, è necessario configurare un webhook nella console LINE Developers.

  1. Andare su Impostazioni → Fornitori di messaggistica.
  2. Annotare il segreto del webhook generato automaticamente per il fornitore LINE.
  3. Configurare l'URL del webhook nella console LINE Developers: 
    https://{il-vostro-dominio}/api/messaging/webhook/line
  4. I messaggi in arrivo appariranno ora in tempo reale nella casella di messaggistica.
