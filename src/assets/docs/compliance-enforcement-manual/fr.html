Application de la conformité – Explications

Cette carte contrôle avec quelle rigueur Klacks traite les infractions aux règles de temps de travail et de repos, et le délai avec lequel les plannings doivent être publiés.

Mode par défaut

Définit le comportement global en cas d'infraction à une règle, sauf si une règle est redéfinie individuellement :

  • Avertir : l'infraction est signalée, mais la planification reste possible.
  • Bloquer : l'action est empêchée jusqu'à ce que l'infraction soit corrigée.

Par défaut : Avertir.

Autoriser la dérogation par les supérieurs

Lorsqu'elle est activée, les supérieurs autorisés peuvent délibérément passer outre un blocage. Lorsqu'elle est désactivée, un blocage s'applique sans exception. Par défaut : activée.

Mode par règle

Le mode peut être défini individuellement pour chacune des onze règles de conformité :

  • Hériter du défaut : le mode par défaut choisi ci-dessus s'applique.
  • Avertir : simple avertissement pour cette règle.
  • Bloquer : blocage strict pour cette règle.

Les onze règles sont :

  • Heures quotidiennes maximales – limite supérieure des heures de travail par jour.
  • Heures hebdomadaires maximales – limite supérieure des heures de travail par semaine.
  • Repos minimal (heures) – repos continu minimal entre deux affectations.
  • Jours de repos minimaux – nombre minimal de jours libres dans la période de référence.
  • Jours de travail consécutifs maximaux – limite supérieure des jours de travail consécutifs.
  • Plafond de période – limite d'heures sur une période définie.
  • Moyenne glissante – heures hebdomadaires moyennes maximales sur une fenêtre glissante.
  • Rotation des jours de repos – alternance requise des jours de repos.
  • Règle de compteur – compteurs d'événements personnalisés (p. ex. postes de nuit par période).
  • Repos compensateur – octroi du repos compensateur dans les délais.
  • Fenêtre horaire restreinte – périodes pendant lesquelles la planification est interdite.

Par défaut : Hériter du défaut pour les onze règles.

Délai de publication du planning

Détermine combien de temps à l'avance un planning doit être publié avant son début.

  • Délai minimal (jours) : nombre de jours devant s'écouler au minimum entre la publication et le début du planning. Par défaut : 0.
  • Compter uniquement les jours ouvrés : lorsqu'elle est activée, seuls les jours ouvrés sont comptés pour le délai, et non les week-ends et jours fériés. Par défaut : désactivée.
