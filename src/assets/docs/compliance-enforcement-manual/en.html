Compliance Enforcement – Explanations

This card controls how strictly Klacks treats violations of working-time and rest rules, and how far in advance rosters must be published.

Default mode

Defines the global behaviour when a rule is violated, unless a rule is overridden individually:

  • Warn: the violation is shown, but planning remains possible.
  • Block: the action is prevented until the violation is resolved.

Default: Warn.

Allow supervisor override

When enabled, authorised supervisors may deliberately override a block. When disabled, a block applies without exception. Default: enabled.

Mode per rule

The mode can be set individually for each of the eleven compliance rules:

  • Inherit default: the default mode selected above applies.
  • Warn: a notice only for this rule.
  • Block: a hard block for this rule.

The eleven rules are:

  • Maximum daily hours – upper limit of working hours per day.
  • Maximum weekly hours – upper limit of working hours per week.
  • Minimum rest hours – minimum continuous rest between two assignments.
  • Minimum rest days – minimum number of free days in the reference period.
  • Maximum consecutive workdays – upper limit of workdays in a row.
  • Period cap – hour limit over a defined period.
  • Rolling average – maximum average weekly hours over a rolling window.
  • Rest-day rotation – required rotation of rest days.
  • Counter rule – custom event counters (e.g. night shifts per period).
  • Compensatory rest – timely granting of compensatory rest.
  • Restricted time window – periods in which planning is not allowed.

Default: Inherit default for all eleven rules.

Roster publication lead time

Determines how early a roster must be published before it starts.

  • Minimum lead days: the number of days that must lie between publication and the roster start. Default: 0.
  • Count workdays only: when enabled, only workdays are counted for the lead time, not weekends and holidays. Default: disabled.
