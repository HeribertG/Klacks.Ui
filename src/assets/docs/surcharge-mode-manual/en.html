Surcharge Mode – Explanations

This card defines how surcharges for night, holiday and weekend work are calculated and represented. The settings act as the basis for new shifts; existing shifts keep the values already stored on them.

Surcharge Modes (Rate Modes)

For every category – night, holiday and the three weekend tiers WE1, WE2 and WE3 – the rate mode determines how the configured rate is interpreted:

  • Multiplier: the rate is a factor applied to the hourly wage (e.g. 1.5 = 150%).
  • Fixed amount per hour: a fixed amount is added for every hour worked.
  • Fixed amount per shift: a fixed amount is added once per shift.

Default: Multiplier for all five categories.

WE3 surcharge (%)

Percentage surcharge rate for the WE3 weekend tier. The value is entered as a percentage (e.g. 100 = 100%) and stored internally as a factor. Default: 0.

Minimum amounts per hour

Optional minimum amount per hour for night, holiday, WE1, WE2 and WE3. When a value is set, the surcharge per hour never falls below this amount. If the field is left empty, no minimum applies. Default: empty (no minimum).

Night window

Start and end of the time window during which work counts as night work. The window may cross midnight. Default: 23:00 to 06:00.

Stacking mode

Determines how several surcharges that apply at the same time (e.g. night and holiday) are combined:

  • Highest wins: only the highest applicable surcharge is applied.
  • Additive: all applicable surcharges are added together.

Default: Highest wins. Note: this setting only selects the default macro for new shifts; existing shifts are not affected.
