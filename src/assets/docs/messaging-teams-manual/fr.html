Configurer Microsoft Teams

Conditions préalables

Pour envoyer des messages depuis Klacks vers un canal Microsoft Teams, vous avez besoin d'un compte Microsoft 365 avec une licence Teams. L'intégration s'effectue via un workflow Teams (Power Automate) avec webhook entrant — aucune inscription d'application Azure ni aucun service de bot n'est nécessaire.

Important : L'intégration Teams est conçue uniquement pour l'envoi. Tous les messages sont postés dans le seul canal défini dans le workflow — les messages directs (chats 1:1) à des personnes individuelles ne sont pas possibles, et les messages Teams entrants ne sont pas reçus dans Klacks.

Étape 1 — Créer un workflow Teams avec webhook

  1. Ouvrez Microsoft Teams et recherchez l'application Workflows dans la barre latérale gauche (ou via Apps).
  2. Cliquez sur Nouveau flux et choisissez le modèle « Post to a channel when a webhook request is received » (en français : « Publier dans un canal lors de la réception d'une demande de webhook »). Vous trouverez également ce modèle sur make.powerautomate.com.
  3. Connectez-vous si vous y êtes invité et sélectionnez l'équipe et le canal dans lesquels les messages doivent être postés.
  4. Cliquez sur Créer un flux.
  5. Copiez l'URL HTTP générée (commence par https://prod-XX.westeurope.logic.azure.com/workflows/...). Cette URL ne s'affiche qu'une seule fois — conservez-la en lieu sûr.

Remarque : traitez l'URL du webhook comme un mot de passe. Toute personne connaissant l'URL peut envoyer des messages dans le canal.

Étape 2 — Configurer Microsoft Teams dans Klacks

  1. Accédez à Paramètres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

  1. Cliquez sur Enregistrer.
  2. Testez la connexion à l'aide du bouton Tester dans la liste des fournisseurs. Attention : le test envoie un message de test visible (Klacks connection test) dans le canal configuré.

Étape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur Teams configuré et activé, le chatbot Klacksy peut poster des messages dans le canal Teams : 

« Poste dans Teams : Les plannings de la semaine prochaine sont prêts. »
« Envoie un message Teams : La réunion d'équipe commence à 15h. »

Le message est posté sous forme d'Adaptive Card dans le canal défini dans le workflow. Un nom de destinataire éventuellement indiqué est ignoré — tous les messages arrivent dans le même canal. Pour plusieurs canaux, créez simplement plusieurs workflows et autant de fournisseurs Teams correspondants dans Klacks.

Messages entrants

Le webhook du workflow est un simple canal d'entrée vers Teams — les réponses ou les messages provenant de Teams ne sont pas transmis à Klacks. La boîte de réception de messagerie n'affiche donc aucun message entrant pour ce fournisseur.

Dépannage

ProblèmeCause possibleSolution
Le test de connexion échoue URL du webhook incorrecte ou copiée de manière incomplète Copiez à nouveau l'URL HTTP complète depuis le workflow (avec tous les paramètres)
Erreur 401/403 lors de l'envoi L'URL du workflow a été renouvelée ou le workflow a été recréé Copiez l'URL actuelle depuis le workflow et mettez-la à jour dans Klacks
Le message n'apparaît pas dans le canal Workflow désactivé ou en échec Vérifiez l'état du workflow et l'historique d'exécution dans l'application Workflows ou sur make.powerautomate.com
Le message apparaît dans le mauvais canal Un autre canal est défini dans le workflow Modifiez le workflow et ajustez l'équipe et le canal dans l'action de publication
Aucun message entrant dans Klacks Ce n'est pas une erreur — l'approche par workflow ne prend pas en charge la réception Pour une communication bidirectionnelle, utilisez un autre fournisseur (p. ex. Telegram ou Slack)
