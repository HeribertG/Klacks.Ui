Configurer Microsoft Teams

Conditions prealables

Pour envoyer et recevoir des messages via Microsoft Teams avec Klacks, vous avez besoin d'un compte Microsoft 365 Business avec une licence Teams active. L'integration se fait via une Azure App Registration et le service Azure Bot.

Remarque : le service Azure Bot est gratuit pour les canaux standard (y compris Teams). Il n'y a pas de frais supplementaires pour le service de bot. Cependant, une licence Microsoft 365 Business est requise.

Etape 1 — Creer une Azure App Registration et un Bot

  1. Connectez-vous au portail Azure (portal.azure.com).
  2. Naviguez vers App registrations et cliquez sur New registration.
  3. Saisissez un nom (p. ex. Klacks-Teams-Bot) et selectionnez le type de compte approprie.
  4. Notez l'Application (client) ID — c'est votre Client-ID.
  5. Notez le Directory (tenant) ID — c'est votre Tenant-ID.
  6. Sous Certificates & secrets, creez un nouveau Client Secret et notez la valeur.
  7. Naviguez vers Azure Bot (anciennement Bot Channel Registration) et creez un nouveau bot.
  8. Associez le bot a l'App Registration creee.
  9. Sous Channels, activez le canal Microsoft Teams.

Etape 2 — Configurer Microsoft Teams dans Klacks

  1. Accedez a Parametres → Fournisseurs de messagerie.
  2. Cliquez sur Ajouter.
  3. Remplissez les champs comme suit :

Etape 3 — Envoyer des messages via le chatbot (Klacksy)

Une fois le fournisseur Teams configure et active, le chatbot Klacksy peut envoyer des messages via Microsoft Teams. Utilisez simplement le nom de l'employe ou du client : 

« Envoie un message a Max Muster : Votre rendez-vous est demain a 14h. »
« Envoie un message a Anna Beispiel : Le service a ete echange. »
« Previens Peter Muller que son service de lundi est annule. »

Klacksy recherche automatiquement l'utilisateur Teams associe et envoie le message via Microsoft Teams. Le processus est entierement transparent pour vous — vous travaillez avec des noms, Klacksy s'occupe du reste.

Condition prealable : L'utilisateur Teams doit etre associe au contact Klacks correspondant (sous Adresse → Coordonnees).

Etape 4 — Recevoir des messages entrants (Webhook)

Pour afficher les messages Teams entrants dans Klacks, un webhook doit etre configure.

  1. Accedez a Parametres → Fournisseurs de messagerie.
  2. Notez le secret du webhook genere automatiquement pour votre fournisseur Teams.
  3. Configurez l'URL du point de terminaison de messagerie dans le portail Azure sous votre bot : 
    https://{votre-domaine}/api/messaging/webhook/teams
  4. Les messages entrants apparaitront desormais en temps reel dans la boite de reception de messagerie.

Depannage

ProblemeCause possibleSolution
Le test de connexion echoue Client-ID, Tenant-ID ou Client-Secret incorrect Verifiez les identifiants dans le portail Azure
Le message n'est pas livre Canal Teams non active dans le bot Activez le canal Teams dans la configuration Azure Bot
Le destinataire ne recoit pas le message Utilisateur Teams non associe au contact Klacks Associez l'utilisateur Teams sous Adresse → Coordonnees
Les messages entrants manquent URL du webhook non configuree Verifiez l'URL du point de terminaison dans le portail Azure
Erreur d'authentification (401/403) Client-Secret expire Creez un nouveau Client-Secret dans le portail Azure et mettez-le a jour dans Klacks
