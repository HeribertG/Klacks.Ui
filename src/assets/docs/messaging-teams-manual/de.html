Microsoft Teams einrichten

Voraussetzungen

Um Nachrichten uber Microsoft Teams mit Klacks zu senden und zu empfangen, benotigen Sie ein Microsoft 365 Business Konto mit aktiver Teams-Lizenz. Die Integration erfolgt uber eine Azure App Registration und den Azure Bot Service.

Hinweis: Der Azure Bot Service ist fur Standard-Channels (einschliesslich Teams) kostenlos. Es fallen keine zusatzlichen Kosten fur den Bot-Dienst an. Eine Microsoft 365 Business Lizenz ist jedoch erforderlich.

Schritt 1 — Azure App Registration und Bot erstellen

  1. Melden Sie sich im Azure Portal an (portal.azure.com).
  2. Navigieren Sie zu App registrations und klicken Sie auf New registration.
  3. Vergeben Sie einen Namen (z.B. Klacks-Teams-Bot) und wahlen Sie den passenden Kontotyp.
  4. Notieren Sie sich die Application (client) ID — dies ist Ihre Client-ID.
  5. Notieren Sie sich die Directory (tenant) ID — dies ist Ihre Tenant-ID.
  6. Erstellen Sie unter Certificates & secrets ein neues Client Secret und notieren Sie den Wert.
  7. Navigieren Sie zu Azure Bot (ehemals Bot Channel Registration) und erstellen Sie einen neuen Bot.
  8. Verknupfen Sie den Bot mit der erstellten App Registration.
  9. Aktivieren Sie unter Channels den Microsoft Teams-Kanal.

Schritt 2 — Microsoft Teams in Klacks konfigurieren

  1. Navigieren Sie zu Einstellungen → Messaging-Anbieter.
  2. Klicken Sie auf Hinzufugen.
  3. Fullen Sie die Felder wie folgt aus:

Schritt 3 — Nachrichten uber den Chatbot (Klacksy) senden

Sobald der Teams-Anbieter konfiguriert und aktiviert ist, kann der Chatbot Klacksy Nachrichten uber Microsoft Teams versenden. Verwenden Sie einfach den Namen des Mitarbeiters oder Klienten: 

"Sende eine Nachricht an Max Muster: Ihr Termin ist morgen um 14:00 Uhr."
"Schicke Anna Beispiel eine Nachricht: Die Schicht wurde getauscht."
"Benachrichtige Peter Muller, dass sein Dienst am Montag ausfallt."

Klacksy sucht automatisch den verknupften Teams-Benutzer und sendet die Nachricht uber Microsoft Teams. Der Versand ist fur Sie vollstandig transparent — Sie arbeiten mit Namen, Klacksy kummert sich um den Rest.

Voraussetzung: Der Teams-Benutzer muss mit dem entsprechenden Klacks-Kontakt verknupft sein (unter Adresse → Kontaktdaten).

Schritt 4 — Eingehende Nachrichten empfangen (Webhook)

Um eingehende Teams-Nachrichten in Klacks anzuzeigen, muss ein Webhook konfiguriert werden.

  1. Gehen Sie zu Einstellungen → Messaging-Anbieter.
  2. Notieren Sie das automatisch generierte Webhook-Secret Ihres Teams-Anbieters.
  3. Konfigurieren Sie im Azure Portal unter Ihrem Bot die Messaging-Endpoint-URL: 
    https://{ihre-domain}/api/messaging/webhook/teams
  4. Eingehende Nachrichten erscheinen nun in Echtzeit in der Messaging-Inbox.

Fehlerbehebung

ProblemMogliche UrsacheLosung
Verbindungstest schlagt fehl Client-ID, Tenant-ID oder Client-Secret falsch Prufen Sie die Zugangsdaten im Azure Portal
Nachricht wird nicht zugestellt Teams-Kanal im Bot nicht aktiviert Aktivieren Sie den Teams-Channel in der Azure Bot-Konfiguration
Empfanger erhalt keine Nachricht Teams-Benutzer nicht mit Klacks-Kontakt verknupft Verknupfen Sie den Teams-Benutzer unter Adresse → Kontaktdaten
Eingehende Nachrichten fehlen Webhook-URL nicht konfiguriert Prufen Sie die Messaging-Endpoint-URL im Azure Portal
Authentifizierungsfehler (401/403) Client-Secret abgelaufen Erstellen Sie ein neues Client-Secret im Azure Portal und aktualisieren Sie es in Klacks
