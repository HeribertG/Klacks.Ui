Setting up Microsoft Teams

Prerequisites

To send messages from Klacks to a Microsoft Teams channel, you need a Microsoft 365 account with a Teams licence. The integration is done through a Teams workflow (Power Automate) with an incoming webhook — no Azure app registration and no bot service is required.

Important: The Teams integration is designed for sending only. All messages are posted to the one channel configured in the workflow — direct messages (1:1 chats) to individual people are not possible, and incoming Teams messages are not received in Klacks.

Step 1 — Create a Teams workflow with a webhook

  1. Open Microsoft Teams and find the Workflows app in the left sidebar (or via Apps).
  2. Click New flow and select the template "Post to a channel when a webhook request is received". Alternatively, you can also find the template at make.powerautomate.com.
  3. Sign in when prompted and select the team and the channel the messages should be posted to.
  4. Click Create flow.
  5. Copy the generated HTTP URL (starts with https://prod-XX.westeurope.logic.azure.com/workflows/...). This URL is only shown once — store it securely.

Note: Treat the webhook URL like a password. Anyone who knows the URL can send messages to the channel.

Step 2 — Configure Microsoft Teams in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.
  3. Fill in the fields as follows:
FieldDescriptionExample
NameUnique internal nameteams-main
Display NameShown in the user interfaceMicrosoft Teams
Provider TypeSelect MicrosoftTeamsMicrosoftTeams
Workflow Webhook URLThe HTTP URL of the workflow copied in Step 1 (must start with https://)https://prod-XX.westeurope.logic.azure.com/workflows/...
EnabledTurns the provider on/offYes
  1. Click Save.
  2. Test the connection using the Test button in the provider list. Caution: The test sends a visible test message (Klacks connection test) to the configured channel.

Step 3 — Send messages via the chatbot (Klacksy)

Once the Teams provider is configured and enabled, the chatbot Klacksy can post messages to the Teams channel: 

"Post in Teams: The schedules for next week are ready."
"Send a Teams message: The team meeting starts at 3 PM."

The message is posted as an Adaptive Card to the channel configured in the workflow. A specified recipient name is ignored — all messages end up in the same channel. For multiple channels, simply create multiple workflows and correspondingly multiple Teams providers in Klacks.

Incoming messages

The workflow webhook is a one-way inbound channel for Teams — replies or messages from Teams are not transferred to Klacks. The Messaging Inbox therefore does not show any incoming messages for this provider.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails Webhook URL incorrect or copied incompletely Copy the complete HTTP URL from the workflow again (including all parameters)
Error 401/403 when sending Workflow URL was regenerated or the workflow was recreated Copy the current URL from the workflow and update it in Klacks
Message does not appear in the channel Workflow disabled or failed Check the workflow status and run history in the Workflows app or at make.powerautomate.com
Message appears in the wrong channel A different channel is configured in the workflow Edit the workflow and adjust the team and channel in the post action
No incoming messages in Klacks Not an error — the workflow approach does not support receiving Use a different provider for bidirectional communication (e.g. Telegram or Slack)
