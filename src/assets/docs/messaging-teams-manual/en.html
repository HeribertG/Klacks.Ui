Setting up Microsoft Teams

Prerequisites

To send and receive messages via Microsoft Teams through Klacks, you need a Microsoft 365 Business account with an active Teams licence. The integration is done through an Azure App Registration and the Azure Bot Service.

Note: The Azure Bot Service is free for standard channels (including Teams). There are no additional costs for the bot service. However, a Microsoft 365 Business licence is required.

Step 1 — Create an Azure App Registration and Bot

  1. Sign in to the Azure Portal (portal.azure.com).
  2. Navigate to App registrations and click New registration.
  3. Enter a name (e.g. Klacks-Teams-Bot) and select the appropriate account type.
  4. Note down the Application (client) ID — this is your Client ID.
  5. Note down the Directory (tenant) ID — this is your Tenant ID.
  6. Under Certificates & secrets, create a new Client Secret and note down the value.
  7. Navigate to Azure Bot (formerly Bot Channel Registration) and create a new bot.
  8. Link the bot with the created App Registration.
  9. Under Channels, enable the Microsoft Teams channel.

Step 2 — Configure Microsoft Teams in Klacks

  1. Navigate to Settings → Messaging Providers.
  2. Click Add.

Step 3 — Send messages via the chatbot (Klacksy)

Once the Teams provider is configured and enabled, the chatbot Klacksy can send messages via Microsoft Teams. Simply use the name of the employee or client: 

"Send a message to Max Muster: Your appointment is tomorrow at 2 PM."
"Send Anna Beispiel a message: The shift has been swapped."
"Notify Peter Mueller that his shift on Monday is cancelled."

Klacksy automatically looks up the linked Teams user and sends the message via Microsoft Teams. The process is fully transparent to you — you work with names, Klacksy takes care of the rest.

Prerequisite: The Teams user must be linked to the corresponding Klacks contact (under Address → Contact Details).

Step 4 — Receive incoming messages (Webhook)

To display incoming Teams messages in Klacks, a webhook must be configured.

  1. Go to Settings → Messaging Providers.
  2. Note the automatically generated webhook secret of your Teams provider.
  3. Configure the messaging endpoint URL in the Azure Portal under your bot: 
    https://{your-domain}/api/messaging/webhook/teams
  4. Incoming messages will now appear in real time in the Messaging Inbox.

Troubleshooting

ProblemPossible CauseSolution
Connection test fails Client ID, Tenant ID or Client Secret incorrect Check the credentials in the Azure Portal
Message not delivered Teams channel not enabled in bot Enable the Teams channel in the Azure Bot configuration
Recipient does not receive message Teams user not linked to Klacks contact Link the Teams user under Address → Contact Details
Incoming messages missing Webhook URL not configured Check the messaging endpoint URL in the Azure Portal
Authentication error (401/403) Client Secret expired Create a new Client Secret in the Azure Portal and update it in Klacks
